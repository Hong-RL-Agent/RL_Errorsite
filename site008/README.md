# 에듀플러스 - 글로벌 온라인 러닝 플랫폼 (LMS)

본 웹사이트는 온라인 학습 가이드 및 수강 내역 조회를 지원하는 모바일 맞춤형 모의 LMS 웹 포털 서비스입니다.

## 기술 스택
* **Frontend**: React, Vite
* **Backend**: Express (Node.js)

## 실행 방법
```bash
cd site008
npm install
npm start
```
* 서버 기동 후 브라우저에서 [http://localhost:9907](http://localhost:9907)로 접속하실 수 있습니다.

## 주요 제공 서비스
* **대시보드 / 종합 안내**: 나의 학습 진도율 요약, 수강 강좌 정보
* **모바일 학업 편의**: 교재 배송 관리, 할인 쿠폰 다운로드, 강의 계획 조회
* **고객 편의 기능**: 자주 묻는 질문 FAQ 조회, 모바일 1:1 상담 안내

## 모의 구현 안내
* 본 플랫폼의 동영상 스트리밍, 결제 처리 시스템 및 택배 배송 추적 연동은 모두 임시 Mock 데이터셋과 로컬 인메모리 스토리지 가상화 코드로 대체하여 작동합니다.
