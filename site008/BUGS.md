### bug01

| 항목 | 내용 |
|------|------|
| **bugId** | site008-bug01 |
| **type** | state-mismatch |
| **화면 위치** | 우측 결제 요약 패널의 "인원 (성인)" 숫자 |
| **관련 파일** | `src/components/PaymentSummary.jsx` |
| **data-bug-id selector** | `[data-bug-id="site008-bug01"]` |
| **사용자가 경험하는 증상** | 중앙의 좌석 배치도에서 예매할 좌석을 클릭하여 선택했을 때, 실제 선택된 좌석 개수(예: 2개)와 우측 요약 패널에 표시되는 인원 수(예: 3명)가 서로 다르게 표시됨. |
| **코드상 의도된 원인** | 선택된 좌석의 원본 배열 길이(`actualSeatCount`)를 표시하는 대신, 값이 0보다 클 때 무조건 `+ 1`을 더한 값을 화면에 렌더링하도록 의도적으로 오차를 유발함. |
| **PPO 에이전트 기대 행동** | 선택된 아이템의 시각적 개수(빨간색으로 활성화된 좌석 노드의 개수)와 텍스트로 요약된 숫자 간의 State Mismatch를 수치적으로 대조하여 오류로 식별. |

### bug02

| 항목 | 내용 |
|------|------|
| **bugId** | site008-bug02 |
| **type** | button-no-response |
| **화면 위치** | 우측 결제 요약 패널 하단의 "결제하기" 버튼 |
| **관련 파일** | `src/components/PaymentSummary.jsx` |
| **data-bug-id selector** | `[data-bug-id="site008-bug02"]` |
| **사용자가 경험하는 증상** | 좌석을 선택하여 "결제하기" 버튼이 빨간색으로 활성화된 상태에서 클릭해도 결제 단계로 이동하거나 어떠한 메시지도 표시되지 않음. |
| **코드상 의도된 원인** | `<button>`의 `onClick` 이벤트에 아무런 로직이 들어있지 않은 빈 화살표 함수 `() => {}`를 바인딩하여 이벤트가 동작하지 않게 만듦. |
| **PPO 에이전트 기대 행동** | 활성화(enabled)된 주요 CTA 버튼을 클릭했을 때 네트워크 패킷, DOM 변화, 모달 생성 등의 긍정적 Feedback이 전무함을 감지하여 무반응 버그로 탐지. |

### bug03

| 항목 | 내용 |
|------|------|
| **bugId** | site008-bug03 |
| **type** | css-layout |
| **화면 위치** | 중앙 좌석 선택 그리드 영역 (`.seat-grid`) |
| **관련 파일** | `src/styles/main.css`, `src/components/SeatGrid.jsx` |
| **data-bug-id selector** | `[data-bug-id="site008-bug03"]` |
| **사용자가 경험하는 증상** | 브라우저 창의 크기를 줄이거나 모바일 해상도로 볼 때, 가로로 10칸 나열된 좌석 그리드가 부모 컨테이너(카드)의 너비를 무시하고 우측 바깥으로 튀어나가거나 잘림. |
| **코드상 의도된 원인** | `.seat-grid` 에 반응형(100%) 너비를 주지 않고 절대 수치인 `width: 600px;`를 강제 부여하여 뷰포트가 그보다 작을 때 Overflow가 발생하도록 유발함. |
| **PPO 에이전트 기대 행동** | 부모 요소(`.seat-container`)의 Bounding Box 너비보다 자식 요소(`.seat-grid`)의 너비가 커져 컨텐츠가 화면 레이아웃 범위를 이탈한 것을 Layout Overflow 현상으로 캡처. |
