# Azure Spa - site040

프리미엄 호텔 스파 및 웰니스 예약 플랫폼입니다. PPO 강화학습 모델의 GUI 오류 탐지를 위해 제작되었습니다.

## 프로젝트 정보
- **사이트 ID**: site040
- **포트 번호**: 9259
- **기술 스택**: React, Vite, Express, Lucide-React
- **주제**: 호텔 스파 패키지 및 테라피스트 예약

## 실행 방법
1. 폴더 이동: `cd site040`
2. 패키지 설치: `npm install`
3. 프론트엔드 빌드: `npm run build`
4. 서버 실행: `npm start`
5. 접속: `http://localhost:9259`

## API 엔드포인트
- `GET /api/health`: 서버 상태 확인
- `GET /api/spa-packages`: 스파 패키지 목록
- `GET /api/therapists`: 테라피스트 목록

## 정상 작동 기능 (10+ Interactions)
1. 스파 카테고리 필터링 (Massage, Facial 등)
2. 날짜 선택 (그리드 클릭)
3. 시간 선택 (그리드 클릭)
4. 테라피스트 선택 (카드 클릭 시 강조 효과)
5. 패키지 상세 모달 오픈 및 닫기
6. 정상 패키지 선택 시 예약 요약 업데이트
7. 예약 요약 패널 내 합계 금액 계산
8. 멤버십 혜택 아코디언 토글
9. 히어로 섹션 스크롤 이동 버튼
10. 예약 확정 알림창 (필수 항목 선택 후)
11. 푸터 링크 호버 애니메이션
