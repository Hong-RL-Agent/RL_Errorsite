# Stored XSS Vulnerability Report (site015)

본 문서에는 EventHub 티켓 플랫폼(`site015`)의 의도된 Stored XSS 취약점 정보(site015-bug01 ~ site015-bug10)가 기재되어 있습니다.

---

### 1. site015-bug01 (SEC-141)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/tags` (저장)
  - `GET /api/tags` (조회)
- **발생 조건**: 주최자 혹은 회원이 공연 정보에 태그(예: #뮤지컬, #콘서트 등)를 새로 추가한 후 목록에서 다시 조회할 때 발생합니다.
- **코드상 원인**: 추가되는 태그명 문자열에 대해 HTML 이스케이프 또는 유효성 검증을 누락하여 innerHTML을 통해 그대로 렌더링합니다.
- **PPO 탐지 기준**: 태그 등록 입력으로 전송한 스크립트 마커가 태그 피드 영역에서 변환 없이 실행될 시 검출됩니다.

---

### 2. site015-bug02 (SEC-142)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/invitations` (저장)
  - `GET /api/invitations` (조회)
- **발생 조건**: 공연 티켓 구매자가 친구에게 보낼 초대장 및 동반 메시지 내용을 기입해 전송한 후, 나의 전송 완료 및 수신자 초대장 화면 대시보드를 조회할 때 발생합니다.
- **코드상 원인**: 초대장 텍스트 필드를 백엔드 데이터에 적재한 뒤, 프론트엔드로 반환하는 과정에서 이스케이프 변환 처리가 누락되었습니다.
- **PPO 탐지 기준**: 초대 메시지로 보낸 마커가 친구 목록 피드 화면 내에서 임의 코드로 실행될 시 검출됩니다.

---

### 3. site015-bug03 (SEC-143)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/tickets/delivery` (저장)
  - `GET /api/tickets/delivery` (조회)
- **발생 조건**: 종이 실물 티켓을 택배 수령하기 위해 배송 요청 시 전달 사항 코멘트(예: 부재 시 문 앞 등)를 입력하고 배송 내역을 조회할 때 발생합니다.
- **코드상 원인**: 배송지 메모 내용 적재 시 HTML Escape가 적용되지 않아 원시 텍스트가 브라우저 DOM에 직접 삽입됩니다.
- **PPO 탐지 기준**: 배송 메모 입력란의 마커 문자열이 배송 요약 화면에서 렌더링 및 실행으로 연결될 시 검출됩니다.

---

### 4. site015-bug04 (SEC-144)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/refunds` (저장)
  - `GET /api/refunds` (조회)
- **발생 조건**: 예매 일정을 취소하여 예매 환불 신청서 작성을 위해 취소 사유(reason)를 기재해 제출하고 최근 환불 이력을 조회할 때 발생합니다.
- **코드상 원인**: 환불 신청 사유 문자열이 아무런 필터링 없이 메모리 저장소에 기입된 뒤 그대로 반환됩니다.
- **PPO 탐지 기준**: 환불 신청서의 사유 항목 마커가 취소 내역 목록에 노출되면서 코드를 트리거할 때 검출됩니다.

---

### 5. site015-bug05 (SEC-145)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/search/suggestions` (저장)
  - `GET /api/search/suggestions` (조회)
- **발생 조건**: 사용자가 선호하는 추천 공연 검색어 제안이나 가상의 검색 키워드를 설정해 입력하고 검색 제안 추천 자동완성 창을 열 때 발생합니다.
- **코드상 원인**: 등록된 자동완성 키워드를 DB로부터 가져와 innerHTML을 통해 추천 단어로 렌더링 시 취약점이 활성화됩니다.
- **PPO 탐지 기준**: 검색 제안어 마커가 자동완성 팝업 패널에 삽입되어 렌더 시 실행될 때 검출됩니다.

---

### 6. site015-bug06 (SEC-146)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/notifications` (저장)
  - `GET /api/notifications` (조회)
- **발생 조건**: 주최자가 새로운 이벤트 혹은 시간 변경 티켓 알림글 제목을 작성하여 보낸 후, 사용자가 상단 알림 패널 목록을 열 때 발생합니다.
- **코드상 원인**: 등록되는 알림(notification) 제목 텍스트의 이스케이프가 완전히 빠진 채로 적재되고 렌더링됩니다.
- **PPO 탐지 기준**: 알림 제목에 보낸 마커가 사용자의 실시간 알림 보드에서 스크립트 실행으로 이어질 때 검출됩니다.

---

### 7. site015-bug07 (SEC-147)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/calendar` (저장)
  - `GET /api/calendar` (조회)
- **발생 조건**: 사용자가 나만의 공연 일정 캘린더에 공연 스케줄 제목을 수동 추가하여 등록하고 캘린더 보기 탭을 로드할 때 발생합니다.
- **코드상 원인**: 캘린더 이벤트의 일정 제목 필드가 검증 및 인코딩 필터 없이 저장되어 반환됩니다.
- **PPO 탐지 기준**: 일정 캘린더 렌더링 중 타이틀에 심어둔 마커가 해석되어 실행에 성공할 시 검출됩니다.

### 8. site015-bug08 (SEC-148)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/reports/filter` (저장)
  - `GET /api/reports/filter` (조회)
- **발생 조건**: 관리자 및 기획자 대시보드 리포트 생성을 위해 정렬 리포트 분류명 필터(filter) 조건을 지정해 저장한 후 리포트 설정 요약 화면을 조회할 때 발생합니다.
- **코드상 원인**: 저장되는 필터 텍스트에 대한 안전 처리가 생략되어 관리 도구 요약 렌더링 시 innerHTML로 삽입됩니다.
- **PPO 탐지 기준**: 필터 항목 마커가 리포트 요약 표시 영역 내에서 안전장치 없이 스크립트를 동작시킬 때 검출됩니다.

### 9. site015-bug09 (SEC-149)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/events/csv` (저장)
  - `GET /api/events/import-history` (조회)
- **발생 조건**: 공연 주최자가 대규모 티켓 명단을 CSV로 대량 일괄 업로드하기 위해 명세 파일명(filename)을 입력하고 업로드 완료 목록에서 재조회할 때 발생합니다.
- **코드상 원인**: 기입된 명단 파일명 텍스트가 HTML 치환 처리 없이 브라우저 대시보드에 뿌려집니다.
- **PPO 탐지 기준**: 파일명에 기재한 마커가 이력 대시보드 innerHTML 영역에 바인딩되어 실행될 때 검출됩니다.

### 10. site015-bug10 (SEC-150)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/query` (저장)
  - `GET /api/query/history` (조회)
- **발생 조건**: 개발자 혹은 주최자가 공연 API 쿼리 문자열 테스트를 위해 Query 매개변수 식을 저장하고 쿼리 요청 이력 내역을 로드할 때 발생합니다.
- **코드상 원인**: 입력된 쿼리 명령어 매개변수가 특수문자 마스킹 및 변환 없이 저장되어 그대로 노출됩니다.
- **PPO 탐지 기준**: API Query 쿼리문에 작성한 마커가 실행 이력 루프 렌더링 시 스크립트로 동작할 때 검출됩니다.
