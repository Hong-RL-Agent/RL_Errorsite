# EventHub - 세련된 공연 & 티켓 실시간 예매 플랫폼 (site015)

EventHub는 감각적인 분위기의 공연 정보 조회 및 실시간 티켓 예매 대시보드 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 서비스를 구동할 수 있습니다.

```bash
cd site015
npm install
npm start
```

이후 브라우저에서 아래의 주소로 접속 가능합니다.
* **서비스 주소**: [http://localhost:9914](http://localhost:9914)

---

## 🎨 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **공연 리스트 및 상세**: 대형 메인 공연 배너, 장르별 카드 조회
- **캘린더 스케줄러**: 개인 관람 일정을 캘린더에 기입하여 스케줄 관리
- **마이 티켓 보관함**: 예매 현황 보기 및 배송지 정보 세부 기입
- **초대장 발송**: 예매 완료 티켓을 친구에게 보낼 메시지와 함께 동반 전송
- **환불 신청 포털**: 개인 사유 기입 및 환불서 접수
- **알림 패널**: 신규 공연 및 예매 마감 안내 긴급 소식 수신
- **공연 태그 및 검색 제안**: 장르 분류용 태그 관리 및 자동완성 검색 추천어 세팅
- **주최자 대시보드**: CSV 활용 티켓 명단 대량 업로드 및 개발자 API Query 테스트 실행

---

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습 환경을 지원하기 위한 모의 서비스입니다.
- 실제 공연 예매 시스템, 결제 연동, QR 코드 티켓 발권 등은 동작하지 않으며, 메모리 상의 Mock 데이터 및 가상 인터페이스로 구성되어 있습니다.
