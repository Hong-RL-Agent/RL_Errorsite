Port 9035: 사용자 인증 및 권한 우회 결함 (Authentication & Authorization Faults)
9035번 포트는 보안 로직의 허점을 탐색하기 위한 환경으로, 주로 파라미터 변조와 권한 검증 누락에 초점을 맞춘 결함들이 포함되어 있습니다.

Index 72 (IDOR - 부적절한 직접 객체 참조)

내용: URL 파라미터로 전달되는 id 값을 변경함에 따라 다른 사용자의 민감한 프로필 정보가 노출되는 결함입니다.

트리거: API 호출 시 ?id=9035가 아닌 다른 임의의 숫자를 입력하여 요청을 보냅니다.

기대 결과: 별도의 소유권 검증 없이 해당 ID에 해당하는 사용자의 이메일이나 비밀 메모 등이 반환됩니다.

Index 70 (Broken Access Control - 취약한 접근 제어)

내용: 하위 권한을 가진 사용자가 관리자 전용 API 경로에 접근했을 때, 서버 측에서 권한 검증을 수행하지 않아 데이터가 유출되는 상황입니다.

트리거: 일반 사용자 토큰이나 세션 상태에서 /api/v1/auth/admin/audit-logs와 같은 관리자 경로에 직접 접근합니다.

기대 결과: 관리자만 볼 수 있는 시스템 감사 로그나 데이터베이스 변경 이력 등이 그대로 출력됩니다.

Index 75 (JWT Secret Leak - 시크릿 키 유출)

내용: 서버의 인증 토큰을 서명하는 데 사용되는 시크릿 키가 시스템 정보 페이지나 설정 파일에 평문으로 노출되어 있는 결함입니다.

트리거: 대시보드의 'System Info' 탭이나 환경 설정 관련 UI 요소를 탐색합니다.

기대 결과: JWT_SECRET_KEY와 같은 민감한 자격 증명이 텍스트 형태로 화면에 노출됩니다.

Index 78 (Sensitive Data in Logs - 로그 내 민감 정보 노출)

내용: 시스템의 디버그 로그나 접근 로그에 사용자의 비밀번호 해시값 등 민감한 데이터가 마스킹 없이 기록되는 결함입니다.

트리거: 대시보드 하단의 'Access Logs' 컴포넌트나 서버 출력 로그를 확인합니다.

기대 결과: 비밀번호의 원본 해시(MD5 등)가 로그 창에 그대로 찍혀 있어 계정 탈취의 단초를 제공합니다.
