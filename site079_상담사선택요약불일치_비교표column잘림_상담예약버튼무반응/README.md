# site079 - SureCare 보험 상담 예약 서비스

'SureCare'는 고객의 상황에 맞는 최적의 보험 설계를 돕는 온라인 보험 상담 예약 데스크톱 웹사이트입니다. 이 프로젝트는 PPO(강화학습) 모델의 GUI 오류 탐지 학습을 위해 제작되었습니다.

## 기술 스택
- **Frontend**: Vanilla HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Port**: 9298

## 실행 방법
```bash
cd site079
npm install
npm start
```
접속 주소: `http://localhost:9298`

## API 엔드포인트
- `GET /api/health`: 서버 상태 확인
- `GET /api/insurance-types`: 보험 유형 목록 (생명, 건강, 자동차 등)
- `GET /api/advisors`: 상담사 프로필 및 가능 시간 데이터

## 주요 기능
- **보험 유형별 선택**: 원하는 보험 종류를 선택하여 상담 예약
- **상담사 프로필 조회**: 전문 분야 및 경력을 확인하고 상담사 선택
- **보장 비교표**: 플랜별 보장 항목 및 금액 비교 (탭 전환 지원)
- **FAQ 아코디언**: 자주 묻는 질문 확인
- **실시간 예약 요약**: 선택한 보험 및 상담사 정보를 Sticky 패널에서 확인

## 의도된 프론트엔드 GUI 오류 (3개)
1. **상담사 선택 요약 불일치** (`site079-bug01`): 상담사를 변경하여 선택해도 우측 예약 요약 패널에는 처음에 선택한 상담사 이름만 계속 표시됨.
2. **보장 비교표 column 잘림** (`site079-bug02`): 비교표의 너비가 컨테이너를 초과하지만 가로 스크롤이 없어 마지막 '마스터 플랜' 컬럼이 잘려 보임.
3. **상담 예약 버튼 무반응** (`site079-bug03`): '자동차보험' 카드의 상담 예약 버튼은 클릭해도 예약 요약에 반영되지 않음.
