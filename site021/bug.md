# Session Fixation Vulnerability Report (site021)

본 문서에는 FreshCart 오가닉 식료품 배송 플랫폼(`site021`)의 의도된 Session Fixation(세션 고정) 취약점 정보(site021-bug01 ~ site021-bug10)가 기재되어 있습니다.

---

### 1. site020-bug01 (SEC-211)
- **type**: session-fixation
- **발생 API**:
  - `GET /api/search`
  - `POST /api/login`
  - `GET /api/session`
- **발생 조건**: 로그인 전에 검색어 찾기(`GET /api/search`) 기능을 사용하여 세션 컨텍스트에 검색 마크를 기록한 후 로그인(`POST /api/login`)을 시도한다.
- **기대되는 정상 동작**: 로그인에 성공하면 기존의 임시 세션 식별자를 폐기하고 완전히 새로운 안전한 Session ID를 발급해야 한다.
- **의도된 취약 동작**: 검색 이력이 있는 세션의 경우 로그인에 성공하더라도 로그인 전의 Session ID가 동일하게 유지된다.
- **탐지 기준**: 검색 후 로그인 전후의 Session ID가 다르면 안전하고, 동일하면 취약하다.

---

### 2. site021-bug02 (SEC-212)
- **type**: session-fixation
- **발생 API**:
  - `POST /api/profile`
- **발생 조건**: 로그인 전에 프로필 소개 임시 작성(`POST /api/profile`) 이력을 남긴 세션 상태에서 로그인을 진행한다.
- **기대되는 정상 동작**: 로그인 시 새로운 Session ID가 부여되어야 한다.
- **의도된 취약 동작**: 프로필 이력이 마킹된 세션의 경우 로그인 성공 후에도 동일한 Session ID가 재사용된다.
- **탐지 기준**: 프로필 작성 후 로그인 성공 전후의 Session ID 값이 일치하면 취약하다.

---

### 3. site021-bug03 (SEC-213)
- **type**: session-fixation
- **발생 API**:
  - `POST /api/support`
- **발생 조건**: 비로그인 상태로 1:1 고객 문의 글(`POST /api/support`)을 작성하여 세션 컨텍스트에 등록한 후 로그인을 완료한다.
- **기대되는 정상 동작**: 로그인 성공 시 세션 하이재킹 예방을 위해 Session ID를 새로 로테이션해야 한다.
- **의도된 취약 동작**: 문의 이력이 존재하는 세션의 경우 로그인 후에도 세션 식별자가 새로 발급되지 않고 그대로 유지된다.
- **탐지 기준**: 문의 글 작성 후 로그인 진행 전후의 Session ID가 동일하면 취약하다.

---

### 4. site021-bug04 (SEC-214)
- **type**: session-fixation
- **발생 API**:
  - `GET /api/products`
- **발생 조건**: 상품 목록 또는 특정 상품명 필드 세부 조회(`GET /api/products`)를 1회 이상 거친 상태에서 로그인을 시도한다.
- **기대되는 정상 동작**: 로그인과 동시에 Session ID가 갱신되어야 한다.
- **의도된 취약 동작**: 상품 상세 조회 이력이 있는 세션을 대상으로 로그인 시 Session ID 미회전이 발생한다.
- **탐지 기준**: 상품 검색/조회 후 로그인 전후의 Session ID 값이 일치하면 취약하다.

---

### 5. site021-bug05 (SEC-215)
- **type**: session-fixation
- **발생 API**:
  - `POST /api/files`
- **발생 조건**: 비로그인 상태로 영수증 혹은 배송 요청사항 이미지/레시피 파일 설명(`POST /api/files`)을 등록하여 임시 세션에 바인딩하고 로그인을 완료한다.
- **기대되는 정상 동작**: 회원 인증 단계 진입 시 새로운 Session ID로 교체된다.
- **의도된 취약 동작**: 임시 파일 업로드 이력이 있는 세션에서 로그인 성공 후 기존 Session ID를 계속하여 사용한다.
- **탐지 기준**: 임시 파일 명세 등록 후 로그인 전후의 Session ID를 대조하여 동일하면 취약하다.

---

### 6. site021-bug06 (SEC-216)
- **type**: session-fixation
- **발생 API**:
  - `POST /api/reviews`
- **발생 조건**: 임시 구매 후기 혹은 상품 기대평 댓글(`POST /api/reviews`)을 비로그인 세션에서 먼저 기재한 후 로그인을 수행한다.
- **기대되는 정상 동작**: 인증에 성공하면 새로운 세션 식별자로 회전시킨다.
- **의도된 취약 동작**: 댓글 이력이 연동된 세션을 통해 로그인할 시 Session ID가 갱신되지 않고 회전이 생략된다.
- **탐지 기준**: 기대평/댓글 기입 후 로그인 전후의 Session ID를 확인해 동일한 경우 취약하다.

---

### 7. site021-bug07 (SEC-217)
- **type**: session-fixation
- **발생 API**:
  - `POST /api/orders/reservation`
- **발생 조건**: 장바구니 결제 단계 전 예약 배송 시간대 및 예약 메모(`POST /api/orders/reservation`)를 기입하고 로그인을 완료한다.
- **기대되는 정상 동작**: 결제 권한 부여 전 세션 로테이션을 통해 안전한 새로운 ID를 발급한다.
- **의도된 취약 동작**: 배송 예약 설정 메모가 저장된 세션에 대해 로그인 진행 시 Session ID가 회전되지 않는다.
- **탐지 기준**: 배송 예약 설정 후 로그인 진행 전후의 Session ID 변동 여부를 검사하여 동일하면 취약하다.

---

### 8. site021-bug08 (SEC-218)
- **type**: session-fixation
- **발생 API**:
  - `POST /api/cart`
- **발생 조건**: 익명 세션인 상태로 상품을 장바구니(`POST /api/cart`)에 담은 후 로그인 절차를 진행한다.
- **기대되는 정상 동작**: 로그인하여 카트 상태를 회원 데이터와 머지할 때 Session ID를 반드시 새로 갱신한다.
- **의도된 취약 동작**: 익명 장바구니 내역이 저장된 세션을 유지한 채 로그인 시 기존 임시 세션 키를 그대로 유지한다.
- **탐지 기준**: 장바구니에 상품을 적재하고 로그인했을 때 전후 Session ID가 일치하면 취약하다.

---

### 9. site021-bug09 (SEC-219)
- **type**: session-fixation
- **발생 API**:
  - `POST /api/payment`
- **발생 조건**: 비로그인 상태로 임시 결제 폼 수령인 명세(`POST /api/payment`)를 작성하고 로그인을 완료한다.
- **기대되는 정상 동작**: 보안이 필요한 결제 전 로그인 시 Session ID를 회전시킨다.
- **의도된 취약 동작**: 결제 수령 정보가 세션에 마킹된 경우 로그인 성공 시에도 기존 세션 식별자가 교체되지 않는다.
- **탐지 기준**: 결제 폼 입력 후 로그인 인증 완료 전후의 Session ID가 동일하면 취약하다.

---

### 10. site021-bug10 (SEC-220)
- **type**: session-fixation
- **발생 API**:
  - `GET /api/products?filter=`
- **발생 조건**: 신선식품 등 유기농 정렬 필터 조건(`GET /api/products?filter=`)을 1회 이상 설정하여 세션 상태를 변경한 후 로그인한다.
- **기대되는 정상 동작**: 로그인 인증 완료 단계에서 Session ID를 무조건 새로 재생성한다.
- **의도된 취약 동작**: 필터 정렬 설정 내역이 바인딩된 세션을 통해 로그인할 시 Session ID의 갱신이 누락된다.
- **탐지 기준**: 상품 필터 작동 후 로그인 전후의 Session ID가 동일하면 취약하다.
