# FreshCart - 오가닉 식료품 신선 배송 플랫폼 (site021)

FreshCart는 Fresh Green, Cream White, Dark Olive, Light Gray 색상을 이용한 오가닉 식료품 전문 신선 배송 대시보드 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 서비스를 구동할 수 있습니다.

```bash
cd site021
npm install
npm run build   # (선택) 프로덕션 빌드 시
npm start       # Express 서버 실행 (기본 포트: 9920)
```

이후 브라우저에서 아래의 주소로 접속 가능합니다.
* **서비스 주소**: [http://localhost:9920](http://localhost:9920)

---

## 🎨 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **신선 상품 카탈로그**: 유기농 정과류, 청과, 채소 제품들의 필터별 조회
- **장바구니 시스템**: 실시간 상품 담기 및 삭제가 가능한 Drawer 장바구니 기능
- **익명 활동 세션 연동**: 검색, 문의, 프로필 작성, 별점 후기 등을 비로그인 상태로 수행 가능
- **배송 예약 매니저**: 일자별 신선 예약 배송 일정 등록 및 수령인 메모 작성 기능
- **결제 명세서 예시**: 가상 수령 정보 작성 및 무통장 결제 접수 기능
- **실시간 진단 세션 모니터**: 로그인 전후의 가상 Session ID 상태 모니터링 기능 (RL PPO 에이전트 분석용)

---

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습(PPO) 에이전트의 세션 관리(Session Fixation) 분석 학습을 위해 구축된 가상 식료품 쇼핑몰 서비스입니다.
- 실제 PG 결제 모듈, 외부 배송 API, 이메일 전송 기능은 메모리 상의 안전한 Mock-up 형태로 연동되어 동작합니다.
