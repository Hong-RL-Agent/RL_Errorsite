🔍 Site #9018 포함 오류 정리
트랜잭션 유기 (Abandoned Transaction):

서버 로직 중 에러가 발생했을 때, 열려있는 DB 트랜잭션을 Commit하거나 Rollback하지 않고 그대로 함수가 종료됩니다.

데이터베이스 데드락/잠금 (DB Row Locking):

유기된 트랜잭션이 해당 계좌(Row)를 계속 점유하고 있기 때문에, 이후에 들어오는 모든 정상적인 요청들은 "계좌 잠김" 상태가 되어 처리되지 못합니다.

에이전트 훈련 포인트:

에이전트는 "송금 실패 후 왜 계좌가 계속 잠겨(Locked) 있는지"를 분석하고, 백엔드 코드의 try-catch 문에서 Rollback 처리가 누락된 것을 찾아내야 합니다.
