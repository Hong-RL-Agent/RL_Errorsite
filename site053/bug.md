# bug.md — site053 (NearBuy) 오류 요약

이 문서는 PPO 학습 에이전트 및 평가 파이프라인을 위해 site053에 존재하는 의도적 오류 5개의 핵심 요약 정보를 제공합니다.

---

### SEC-441
* **SEC ID**: SEC-441
* **오류 유형**: 선행 0이 포함된 가격 입력의 정규화 과정에서 표시값과 저장값이 달라지는 문제
* **재현 조건**: 상품 등록 시 가격에 `050000`과 같이 0으로 시작하는 문자열을 입력할 때
* **재현 절차**:
  1. 판매하기(`/sell`) 화면으로 이동
  2. 상품명 및 카테고리 입력
  3. 가격란에 `050000` 입력 (화면에는 50,000원으로 포맷팅되어 표시됨)
  4. 상품 등록 완료 버튼 클릭
  5. 등록된 상품 상세 또는 목록에서 실제 저장된 가격이 `5,000원`으로 등록된 것 확인
* **관찰되는 증상**: 화면에는 50,000원으로 보이지만 실제 서버에는 5,000원으로 10배 작게 저장됨
* **정상 동작**: `050000` 입력 시 선행 0이 제거된 `50000`원으로 정확히 저장되어야 함
* **오류 발생 원인**: 선행 0 처리 시 자릿수 계산 및 정수 파싱 오류
* **PPO가 탐색해야 하는 행동**: 가격 입력 시 선행 0 포함 값 입력 후 서버 저장 데이터와의 일치 여부 비교

### SEC-442
* **SEC ID**: SEC-442
* **오류 유형**: 상품 설명의 줄바꿈이 상세 화면에서 사라지는 문제
* **재현 조건**: 판매글 작성 시 설명란에 여러 줄의 텍스트(Enter 입력)를 작성하여 등록할 때
* **재현 절차**:
  1. 판매하기(`/sell`) 화면으로 이동
  2. 상품 설명란에 줄바꿈이 포함된 2줄 이상의 텍스트 작성
  3. 상품 등록 완료
  4. 생성된 상품 상세 페이지(`/products/:id`) 진입
  5. 상품 설명 영역에서 줄바꿈이 모두 공백으로 대체되어 한 줄로 뭉개져 렌더링되는 현상 확인
* **관찰되는 증상**: 단락 구분 및 줄바꿈이 무시되고 텍스트가 이어져 출력됨
* **정상 동작**: `\n` 개행 문자가 보존되어 줄바꿈이 그대로 표시되어야 함
* **오류 발생 원인**: 텍스트 저장 시 개행 정규식이 공백으로 치환됨
* **PPO가 탐색해야 하는 행동**: 멀티라인 텍스트 작성 -> 상세 페이지 렌더링 구조 비교

### SEC-443
* **SEC ID**: SEC-443
* **오류 유형**: 이미지 삭제 후 미리보기 인덱스가 실제 이미지와 어긋나는 문제
* **재현 조건**: 사진 3장 이상 업로드 후 중간 사진을 삭제하고 특정 사진을 대표 이미지로 선택할 때
* **재현 절차**:
  1. 판매하기(`/sell`) 화면에서 3장의 이미지 추가 (A, B, C)
  2. 2번째 이미지(B)의 삭제 버튼 클릭
  3. 남아있는 2번째 이미지(C)를 클릭하여 대표 이미지로 지정
  4. 상품 등록 완료
  5. 등록된 상품의 대표 이미지가 선택한 C가 아닌 다른 이미지로 지정되는 현상 확인
* **관찰되는 증상**: UI에서 선택한 대표 이미지와 실제 상품에 반영된 대표 이미지가 불일치
* **정상 동작**: 이미지 삭제 후에도 선택 인덱스가 올바르게 재계산되어야 함
* **오류 발생 원인**: 배열 요소 삭제 후 `selectedCoverIndex` 상태 비동기화
* **PPO가 탐색해야 하는 행동**: 다중 이미지 업로드 -> 중간 삭제 -> 대표 이미지 선택 -> 결과 확인

### SEC-444
* **SEC ID**: SEC-444
* **오류 유형**: 신고 라디오 선택값과 서버 전송값이 서로 다른 문제
* **재현 조건**: 상품 상세에서 신고 모달을 열고 "사기 의심" 사유를 라디오로 선택하여 제출할 때
* **재현 절차**:
  1. 임의의 상품 상세 페이지 진입
  2. 하단 "신고하기" 버튼 클릭
  3. 사유 목록 중 "사기 의심" 라디오 선택
  4. "신고 접수" 버튼 클릭
  5. 접수 결과 및 서버에 저장된 사유가 "부적절한 내용"으로 잘못 전송/저장된 현상 확인
* **관찰되는 증상**: 라디오에서 선택한 값과 서버 전송 페이로드의 값이 다름
* **정상 동작**: 선택한 "사기 의심" 사유가 서버에 정확히 전달되어야 함
* **오류 발생 원인**: 라디오 옵션 인덱스 매핑 시프트 오류
* **PPO가 탐색해야 하는 행동**: 신고 모달 -> 사유 라디오 선택 -> 전송 페이로드/결과 검증

### SEC-445
* **SEC ID**: SEC-445
* **오류 유형**: 브라우저 뒤로가기 후 판매글 작성 상태와 미리보기 상태가 불일치하는 문제
* **재현 조건**: 판매글 작성 중 미리보기를 확인한 뒤 뒤로가기 버튼으로 돌아와 수정할 때
* **재현 절차**:
  1. 판매하기(`/sell`)에서 상품명/가격/설명 입력 (예: 300,000원)
  2. "미리보기" 버튼 클릭
  3. 브라우저 뒤로가기 또는 "수정하기" 클릭하여 작성 폼으로 복귀
  4. 작성 폼의 가격이 이전 상태(30,000원)로 돌아가 있거나 미리보기와 불일치하는 상태 확인
* **관찰되는 증상**: 작성 폼과 미리보기가 서로 다른 draft 상태를 참조함
* **정상 동작**: 뒤로가기 후에도 사용자가 직전에 수정한 form state가 온전히 유지되어야 함
* **오류 발생 원인**: Navigation 시 form draft 동기화 누락
* **PPO가 탐색해야 하는 행동**: 폼 작성 -> 미리보기 -> 뒤로가기 -> 폼 데이터 정합성 검증
