# Midnight Cinema - 영화 예매 사이트

## 사이트 정보

| 항목 | 내용 |
|------|------|
| **사이트 이름** | Midnight Cinema |
| **사이트 ID** | site008 |
| **포트** | 9227 |
| **기술 스택** | React 18 + Vite 5 + Express 4 + Lucide React |
| **주제** | 다크 시네마 테마의 영화 및 좌석 예매 시스템 |

## 실행 방법

```bash
cd site008
npm install
npm run build   # React 앱 빌드
npm start       # Express 서버 실행 (포트 9227)
```

## API 엔드포인트

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/health` | 서버 상태 확인 |
| GET | `/api/movies` | 상영 중인 영화 목록, 시간표 데이터 조회 |

## 정상 작동 기능

- ✅ 가로 스크롤 가능한 영화 포스터 리스트 (선택 시 활성화 이펙트)
- ✅ 선택한 영화에 따른 상영 시간 동적 변경
- ✅ 좌석 그리드 클릭 시 토글 형태로 좌석 선택/해제 기능 (예매 완료 좌석은 선택 불가)
- ✅ 좌석 수에 비례한 총 결제 금액 동적 계산 (15,000원/석)

## 의도된 GUI 오류 3개

### site008-bug01 — state-mismatch
- **위치**: 우측 결제 요약 패널의 "인원 (성인)" 표기
- **증상**: 내가 클릭해서 선택한 좌석의 개수와 표시되는 인원 수가 다름 (선택된 수 + 1 명으로 표시됨).
- **selector**: `[data-bug-id="site008-bug01"]`

### site008-bug02 — button-no-response
- **위치**: 우측 결제 요약 패널 하단의 "결제하기" 버튼
- **증상**: 좌석을 선택하여 버튼이 활성화된 상태에서 클릭해도, 다음 결제 프로세스로 넘어가지 않고 무반응임.
- **selector**: `[data-bug-id="site008-bug02"]`

### site008-bug03 — css-layout
- **위치**: 중앙 좌석 선택 컨테이너 내의 좌석 그리드
- **증상**: 좁은 화면(창 크기 축소 시)에서 그리드가 유연하게 줄어들지 않고 카드 바깥으로 잘리거나 튀어나감.
- **selector**: `[data-bug-id="site008-bug03"]`
