🗄️ Port 9034: 데이터베이스 및 트랜잭션 결함 (DB & Transaction)데이터 정합성과 동시성 제어 실패를 탐색하는 핀테크 관리자 환경입니다.Index 52 (Dirty Read): 데이터베이스의 트랜잭션 격리 수준(Isolation Level)을 낮게 설정하여, 특정 작업이 커밋되기 전의 데이터가 다른 세션에 노출되는 데이터 불일치 상황을 만듭니다.Index 55 (Database Deadlock): 두 개 이상의 트랜잭션이 서로의 자원 점유가 끝나기를 기다리는 교착 상태를 의도적으로 발생시켜 시스템 업데이트가 멈추는 프리징(Freezing) 현상을 유도합니다.Index 50 (N+1 Query Problem): 연관 데이터를 로딩할 때 불필요하게 많은 쿼리가 폭증하도록 설계하여, 대시보드의 전체적인 응답 속도($P99$ 지연 시간)를 급격히 떨어뜨립니다.Index 58 (Sensitive SQL Leak): 시스템 디버그 로그 영역에 실제 실행된 SQL 원본 쿼리와 파라미터가 노출되도록 하여, 쿼리 내에 포함된 계좌 번호나 비밀번호 등의 민감 정보 유출을 재현합니다.
