# Leaf & Lesson 원예 클래스 예약

- 사이트 이름: Leaf & Lesson
- 사이트 ID: site076
- 포트 번호: 9295
- 기술 스택: Vanilla HTML, CSS, JavaScript, Express

## 실행 방법

```bash
cd site076
npm install
npm start
```

브라우저에서 `http://localhost:9295`로 접속합니다.

개발 실행도 동일하게 Express 서버를 사용합니다.

```bash
npm run dev
```

빌드 확인:

```bash
npm run build
```

## API 엔드포인트

- `GET /api/health`: 서버 상태, 사이트 ID, 타임스탬프 반환
- `GET /api/classes`: 원예 클래스 ID, 이름, 난이도, 식물 종류, 소요 시간, 가격, 키트 포함 여부, 일정, 이미지 반환
- `GET /api/instructors`: 강사 ID, 이름, 전문 분야, 경력, 프로필 이미지 반환

## 정상 작동 기능

- 난이도 필터
- 식물 종류 필터
- 검색 필터
- 추천순, 낮은 가격순, 짧은 수업순 정렬
- 필터 초기화
- 클래스 상세 모달 열기와 닫기
- 관심 클래스 저장 토글
- 일정표 날짜 선택
- 일정표 카드 선택
- 준비물 안내 accordion
- 예약 요약 패널 접기와 펼치기
- 예약 인원 증감
- API 로딩 상태와 에러 상태 UI
- 미구현 버튼의 `준비중입니다.` alert 처리

2. `site076-bug02`: 일정표 카드 겹침
   - 긴 클래스명이 있는 일정 카드가 고정 높이 row 안에서 아래 시간대와 겹칩니다.

3. `site076-bug03`: 예약 버튼 무반응
   - 특정 추천 클래스의 예약 버튼은 활성 버튼처럼 보이지만 클릭해도 예약 요약이 바뀌지 않습니다.
