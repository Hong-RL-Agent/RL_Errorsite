# site002 - Hospital Patient Portal

This is a patient-facing portal allowing clients to securely check health statuses, appointments, medical images metadata, prescriptions, lab results, visit history, insurance claims, payments, and general health checkup summaries.

## Getting Started

1. Install dependencies:
   ```bash
   cd site002
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   [http://localhost:9901](http://localhost:9901)

## Features

- Patient profile dashboard.
- Safe/vulnerable medical resource endpoint simulations.
- Direct medical identifier lookup interface.
- 100% Mock data architecture without actual EMR dependencies.
