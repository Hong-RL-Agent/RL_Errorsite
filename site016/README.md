# HomeSpace - 프리미엄 스마트 매물 플랫폼 (site016)

HomeSpace는 화이트, 에메랄드 그린, 다크 그레이 톤의 세련된 디자인을 바탕으로 한 프리미엄 부동산 매물 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 서비스를 구동할 수 있습니다.

```bash
cd site016
npm install
npm start
```

이후 브라우저에서 아래의 주소로 접속 가능합니다.
* **서비스 주소**: [http://localhost:9915](http://localhost:9915)

---

## 🎨 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **매물 종합 검색 및 필터링**: 지역, 매물명, 유형별 맞춤 필터 제공
- **중개사 프로필 소개 관리**: 파트너 공인중개사의 한줄 소개 실시간 변경 및 출력
- **1:1 상담 문의 포털**: 매물에 대한 비공개 상담 문의 등록 및 조회
- **매물 등록 포털**: 신규 매물 등록 및 상세 보기 기능
- **계약 증빙 파일 관리**: 단체 예약 등의 정산 명세 파일 설명 추가 및 보관함
- **한줄평 댓글 피드**: 각 매물 상세 피드에 솔직한 한줄평 댓글 등록 및 피드 제공
- **방문 예약 캘린더**: 특정 날짜를 지정하여 방문 상담 일정 예약 및 조율
- **관심 매물 관리**: 관심 있는 매물을 북마크 및 관리용 개별 메모 보관
- **가계약금 예치 및 결제**: 가계약금 예치 거래 신청 및 내역 보관함

---

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습 환경을 지원하기 위한 모의 부동산 매물 서비스입니다.
- 실제 지도 연동, 실제 문자 인증, 실제 결제 승인 API 등 외부 통신 모듈은 동작하지 않으며, 메모리 상의 Mock 데이터 및 가상 인터페이스로 구성되어 있습니다.
