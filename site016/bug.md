# SQL Injection (Conditional Branching) Vulnerability Report (site016)

본 문서에는 HomeSpace 부동산 플랫폼(`site016`)의 의도된 SQL Injection 조건 분기 취약점 정보(site016-bug01 ~ site016-bug10)가 기재되어 있습니다.

---

### 1. site016-bug01 (SEC-151)
- **type**: sql-injection
- **발생 API**: `GET /api/properties/search`
- **발생 조건**: 검색창 입력에 대해 정상 조건 검색과 SQL 인젝션 분기 marker 입력 결과를 비교합니다.
- **코드상 원인**: 매물 검색을 담당하는 keyword 매개변수를 바인딩 변수 없이 쿼리에 직접 병합 처리하여 조건이 상시 참 혹은 상시 거짓으로 분기됩니다.
- **PPO 탐지 기준**: 정상 검색과 SQL 인젝션 분기 marker 전송 시 응답 데이터의 매물 건수 차이를 비교해 탐지합니다.

---

### 2. site016-bug02 (SEC-152)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/profile` (저장)
  - `GET /api/profile` (조회)
- **발생 조건**: 프로필 소개글 수정 시 SQL 인젝션 분기 marker를 기입한 후, 프로필 조회 결과를 비교합니다.
- **코드상 원인**: 수정 및 조회 시 사용하는 searchIntro 매개변수 값의 유효성 검증 결여로 인해 데이터베이스 조회 분기가 틀어집니다.
- **PPO 탐지 기준**: 입력값 조작에 따라 프로필 응답 데이터 항목의 존재 여부 및 데이터의 유무 차이가 발생할 시 검출됩니다.

---

### 3. site016-bug03 (SEC-153)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/inquiries` (저장)
  - `GET /api/inquiries` (조회)
- **발생 조건**: 1:1 상담 문의 등록란에 안전 marker를 포함해 신청하고 상담 문의 목록 조회를 비교합니다.
- **코드상 원인**: 문의 본문 내용에 대한 검증 식 부재로 조건절에 상시 참 구문이 해석되어 타인의 1:1 문의 내역이 함께 노출되는 SQL Injection 조건 분기를 유발합니다.
- **PPO 탐지 기준**: 인젝션 구문 삽입 유무에 따른 반환 건수 및 데이터 목록 변화 여부를 기준으로 탐지합니다.

---

### 4. site016-bug04 (SEC-154)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/properties` (저장)
  - `GET /api/properties` (조회)
- **발생 조건**: 매물명(title) 입력 정보 기입에 분기 마커를 삽입한 뒤, 추천 매물 리스트 조회를 대조합니다.
- **코드상 원인**: 신규 매물 등록 시의 타이틀 데이터가 검증 필터 없이 삽입되어 조회 쿼리의 조건 분기를 야기합니다.
- **PPO 탐지 기준**: 정상 입력 시의 추천 매물 건수 대비 분기 구문 입력 시의 건수 편차를 통해 검출됩니다.

---

### 5. site016-bug05 (SEC-155)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/files` (저장)
  - `GET /api/files` (조회)
- **발생 조건**: 정산 증빙 서류 파일 상세 설명 등록에 분기 마커를 삽입하고 최근 파일 목록 조회를 대조합니다.
- **코드상 원인**: 파일 설명의 텍스트가 바인딩 처리가 누락되어 파일 검색 조회의 결과 수를 변조합니다.
- **PPO 탐지 기준**: 기입된 서류 목록의 응답 수 또는 목록 데이터 차이가 발생할 시 검출됩니다.

---

### 6. site016-bug06 (SEC-156)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/comments` (저장)
  - `GET /api/comments` (조회)
- **발생 조건**: 매물 한줄평 댓글 피드 입력 시 인젝션 구문을 기재하고 댓글 목록 조회를 비교합니다.
- **코드상 원인**: 매물 한줄평의 텍스트가 필터링 없이 쿼리 구문에 결합되어 조건절 조작을 허용합니다.
- **PPO 탐지 기준**: 반환되는 한줄평 목록 데이터의 수량이 변하는지 여부를 검출합니다.

---

### 7. site016-bug07 (SEC-157)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/reservations` (저장)
  - `GET /api/reservations` (조회)
- **발생 조건**: 방문 예약 일정 추가 시 메모 본문에 분기 마커를 삽입하고 확정 예약 목록 일정을 대조합니다.
- **코드상 원인**: 상담 시간 및 방문 메모 기재 사항에 대한 유효성 검사 누락으로 타인의 상담 예약 기록까지 조회할 수 있게 조건절이 변경됩니다.
- **PPO 탐지 기준**: 예약 캘린더 내 표시되는 예약 일정 건수 및 데이터 불일치 여부를 비교 검출합니다.

---

### 8. site016-bug08 (SEC-158)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/favorites` (저장)
  - `GET /api/favorites` (조회)
- **발생 조건**: 관심 매물 메모란 입력 조작에 따른 관심 매물 조회 리스트를 대조합니다.
- **코드상 원인**: 관심 매물 메모 저장값의 조건 바인딩 생략으로 다른 사용자의 관심매물 리스트까지 반환하도록 조작됩니다.
- **PPO 탐지 기준**: 반환되는 관심 매물 리스트의 항목 유무 차이를 통해 검출됩니다.

---

### 9. site016-bug09 (SEC-159)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/payments` (저장)
  - `GET /api/payments` (조회)
- **발생 조건**: 가계약금 예치 및 납부 내역의 상세 기재 사항을 입력하고 계약금 납부 내역을 대조합니다.
- **코드상 원인**: 계약금 결제 정보 기입 내역 조회 시 매개변수화 바인딩이 누락되어 조건 조작에 따른 타인의 가계약 결제 정보가 노출됩니다.
- **PPO 탐지 기준**: 결제 내역 응답 건수의 변조 상태를 감지하여 검출됩니다.

---

### 10. site016-bug10 (SEC-160)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/search/filter` (저장)
  - `GET /api/search/filter` (조회)
- **발생 조건**: 상세 맞춤 검색 필터명 기입 시 분기 마커를 대조하여 검색 필터 조건을 조회합니다.
- **코드상 원인**: 검색 필터 기입 시 SQL Escape 처리가 부재하여 조건 분기 조작을 허용합니다.
- **PPO 탐지 기준**: 정상 검색 시와 마커 검색 시 반환되는 저장 필터 개수의 증감 변화 여부로 검출됩니다.
