# QuickDelivery (site012)

쉽고 빠른 실시간 맛집 배달 플랫폼 모의 서비스입니다. 본 웹사이트는 고객 주문, 맛집 카테고리 필터링, 실시간 배달 진행 현황 모니터링, 점주용 비즈니스 대시보드 및 분석 툴 기능들을 제공하는 교육 및 취약점 동적 분석 테스트 환경입니다.

## 기술 스택
- **Frontend**: React, Vite, Vanilla CSS
- **Backend**: Express, Node.js
- **Mocking**: In-Memory Mock Database

## 실행 방법
현재 디렉터리를 `site012`로 이동한 뒤 의존성을 설치하고 서비스를 시작합니다.
```bash
cd site012
npm install
npm start
```
서버가 정상 구동되면 브라우저에서 `http://localhost:9911`로 접속하여 서비스를 확인할 수 있습니다.
- `npm run dev` : Vite 개발용 HMR 서버 실행 (포트: 5173, backend proxy 포트: 9911)
- `npm run build` : 배포용 프론트엔드 프로덕션 빌드
- `npm start` : Express 서버 구동 (포트: 9911, static dist 정적 배포 파일 제공)

## 주요 기능
- **사용자 권한(역할) 변경**: 고객(Customer), 점주(Owner), 관리자(Admin) 권한 전환을 통해 플랫폼 내 각 퍼소나별 특화 대시보드 탐색 가능.
- **음식 검색 및 추천**: 검색 키워드 입력 시 실시간으로 메뉴 자동완성 및 인기 검색어 제안 제공.
- **배달 주문 및 실시간 추적**: 장바구니에 음식을 담고 배송지 정보와 배송 메모를 기입하여 주문 시, 실시간으로 배달 단계(접수중 -> 조리중 -> 배달중 -> 완료)가 변동되는 현황판 제공.
- **친구 초대장 전송**: 개인화된 초대 링크와 메시지를 꾸며 친구에게 실시간 전송 시뮬레이션.
- **캘린더 예약 주문**: 원하는 배달 일시와 주문 일정을 캘린더 요약 뷰어로 등록.
- **점주 비즈니스 콘솔**: 맛집 메뉴 리스트를 CSV 업로드로 등록하고 매출 리포트 필터링 및 개발자 API 테스트 쿼리 실행 가능.
- **환불 센터**: 기 주문 완료 건에 대한 환불 신청 및 처리 프로세스 시뮬레이션.

## 서비스 안내 사항
- 본 웹사이트에 수록된 모든 상점 정보, 배달 주소, 결제 정보 및 배달 추적 데이터는 인메모리 Mock 데이터입니다.
- 실제 PG사 결제, 배달 대행 라이더 연동, 지도 API 위치 기반 추적, 그리고 실제 SMS/메신저 초대 발송 기능은 일절 포함되어 있지 않습니다.
