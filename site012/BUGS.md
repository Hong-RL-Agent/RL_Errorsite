# BUGS - site012

이 문서는 PPO 에이전트 훈련을 위해 의도적으로 삽입된 GUI 오류를 설명합니다.

## 1. site012-bug01
- **Bug ID**: site012-bug01
- **Type**: button-no-response
- **화면 위치**: 대시보드 상단 "거래 추가" (Add Transaction) 버튼
- **관련 파일**: `src/components/SummaryHeader.jsx`
- **Data Bug ID Selector**: `[data-bug-id="site012-bug01"]`
- **사용자가 경험하는 증상**: "거래 추가" 버튼을 클릭해도 새로운 지출/수입 내역을 입력하기 위한 모달이나 폼이 열리지 않음.
- **코드상 의도된 원인**: 버튼에 클릭 이벤트 핸들러가 연결되지 않았거나 빈 함수가 할당됨.
- **PPO 에이전트가 탐지해야 할 기대 행동**: 버튼 클릭 액션 이후 화면의 상태(DOM 변화 또는 시각적 변화)가 전혀 없는 것을 감지해야 함.

## 2. site012-bug02
- **Bug ID**: site012-bug02
- **Type**: state-mismatch
- **화면 위치**: 상단 요약 카드의 "총 지출" (Total Expense) 금액 표시 영역
- **관련 파일**: `src/App.jsx`
- **Data Bug ID Selector**: `[data-bug-id="site012-bug02"]`
- **사용자가 경험하는 증상**: 하단 테이블에 나열된 모든 거래 내역의 합계와 상단 카드에 표시된 "총 지출" 금액이 서로 일치하지 않음.
- **코드상 의도된 원인**: 요약 카드 렌더링 시 실제 거래 데이터 배열의 합계를 구하지 않고, 의도적으로 조작된 정적 수치나 잘못된 변수를 참조하도록 함.
- **PPO 에이전트가 탐지해야 할 기대 행동**: 테이블의 숫자 데이터들과 상단 요약 수치 간의 불일치를 논리적으로 감지해야 함.

## 3. site012-bug03
- **Bug ID**: site012-bug03
- **Type**: css-layout
- **화면 위치**: 거래 내역 테이블 (Transaction Table)의 첫 번째 열(날짜)
- **관련 파일**: `src/styles.css`
- **Data Bug ID Selector**: `[data-bug-id="site012-bug03"]`
- **사용자가 경험하는 증상**: 모바일 또는 작은 화면에서 거래 테이블을 볼 때, 첫 번째 열인 "날짜" 텍스트가 화면 왼쪽 끝으로 밀려 일부가 잘리거나 가려짐.
- **코드상 의도된 원인**: 테이블 컨테이너에 잘못된 `padding-left` 또는 음수 `margin`을 적용하고, `overflow` 속성을 부적절하게 설정함.
- **PPO 에이전트가 탐지해야 할 기대 행동**: 텍스트 요소가 부모 컨테이너의 경계를 벗어나 시각적으로 유실되는 레이아웃 오류를 감지해야 함.
