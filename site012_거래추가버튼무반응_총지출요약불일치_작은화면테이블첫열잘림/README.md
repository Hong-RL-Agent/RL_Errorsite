# Financial Dashboard (site012)

## 개요
이 프로젝트는 PPO 강화학습 모델이 프론트엔드 GUI 오류를 탐지할 수 있도록 훈련하기 위한 금융 가계부 대시보드 웹사이트입니다. 그린/아이보리 톤의 차분한 디자인을 지향합니다.

- **사이트 ID**: site012
- **포트 번호**: 9231
- **기술 스택**: React, Vite, Express, CSS

## 실행 방법
```bash
cd site012
npm install
npm run build
npm start
```
이후 브라우저에서 `http://localhost:9231` 에 접속합니다.

## API 엔드포인트 목록
- `GET /api/health` : 서버 상태 확인
- `GET /api/transactions` : 거래 내역 목록 조회
- `POST /api/transactions` : 새 거래 추가 (백엔드 로직은 정상)

## 정상 작동 기능 목록
- **카테고리 필터**: 지출 카테고리별로 거래 내역을 필터링하여 볼 수 있습니다.
- **월 선택**: 다른 월의 요약 데이터를 선택하여 조회할 수 있습니다 (Mock 데이터).
- **상세 Drawer**: 거래 내역 클릭 시 측면에서 상세 정보가 나타납니다.

## 의도된 GUI 오류 3개
1. **site012-bug01** (`button-no-response`): "거래 추가" 버튼 클릭 시 폼이 열리지 않음.
2. **site012-bug02** (`state-mismatch`): 상단 요약 금액이 실제 목록 합계와 다름.
3. **site012-bug03** (`css-layout`): 작은 화면에서 테이블 첫 번째 열이 잘림.

## PPO 에이전트 기대 행동
- 에이전트는 거래 내역의 숫자 합계와 요약 카드의 숫자를 비교하여 불일치를 찾아내야 합니다.
- 버튼 클릭 후의 시각적 피드백 부재를 감지해야 합니다.
- 반응형 뷰포트에서 텍스트가 잘리는 레이아웃 이슈를 감지해야 합니다.
