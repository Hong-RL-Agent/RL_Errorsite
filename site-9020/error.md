🔍 Site #9020 포함 오류 정리
공유 리소스 유기 (Abandoned Shared Resource):

사용자가 '사용 종료'를 눌러 리소스를 반납했음에도, 서버 내부의 실제 접근 제어 변수(internalLock)는 해제되지 않습니다.

리소스 데드락 유발:

UI 상으로는 '이용 가능'이라고 뜨지만, 다시 예약하려고 하면 백엔드에서 409 Conflict 에러를 뱉으며 예약을 거부합니다. 즉, 한 번 사용된 자원은 영원히 사용할 수 없는 상태가 됩니다.

에이전트 훈련 포인트:

에이전트는 **"표시된 상태(isAvailable)"**와 "내부 락 상태(internalLock)" 사이의 모순을 감지하고, 비즈니스 로직에서 자원 반납 처리가 불완전함을 진단해야 합니다.
