## 📋 정상 기능 요약

- **환자 진료 예약 대장**: 25개 이상의 소화기내과, 정형외과, 순환기내과, 신경과, 피부과 진료 예약 조회 및 일시 조정.
- **임상 검사 결과 리포트**: 20개 이상의 혈액 검사, 초음파, 심전도, MRI, 내시경 검사 소견 확인.
- **전문의 배정 및 대시보드**: 15명의 의료진 프로필, 진료실 배정 현황 및 일일 수용률 모니터링.
- **환자 세션 및 처방 관리**: 15명 이상의 환자 데이터 및 PAT-01/PAT-02 계정 스위칭.

## ⚠️ 의도적으로 삽입된 복합 오류 목록

1. **Frontend + Backend 요청 순서 충돌**
   - **설명**: 진료 예약 시간을 변경(3초 지연 완료)한 직후 담당 의사를 변경(0.1초 완료)하면, 의사 변경 API는 먼저 성공하지만 3초 뒤 완료되는 시간 변경 API 내부에 이전 의사 정보(`doctorId`, `doctorName`)가 동봉 저장되어 새로고침 시 새 시간과 이전 의사 조합이 저장됩니다.

2. **Backend + JSON DB 상태 충돌**
   - **설명**: 예약 취소(0.5초 완료) 직후 환자가 증상 설명을 수정(4초 지연 완료)하면, 취소 요청은 먼저 0.5초 만에 성공하지만 늦게 도착한 증상 수정 요청이 취소된 예약을 다시 'CONFIRMED'(예약 확정) 상태로 재활성화시킵니다. 목록에서는 취소, 상세에서는 확정 상태로 불일치하게 됩니다.

3. **Frontend 정렬 인덱스 오류**
   - **설명**: 예약 목록을 날짜순으로 정렬한 뒤 예약 변경 버튼을 누르면 화면의 정렬 인덱스를 원본 예약 배열(`appointments`)에 대입하여 클릭한 예약이 아닌 엉뚱한 예약 항목이 수정 선택됩니다.

4. **통계 데이터 불일치**
   - **설명**: 예약을 삭제(`DELETE /api/appointments/:id`) 처리하여 대장에서 소거하더라도, 병원 대시보드의 총 예약 수(`hospitalStats.totalAppointmentsCount`)와 진료과별 수용률 통계 그래프에는 차감되지 않고 계속 유지됩니다.

5. **Network stale response 오류**
   - **설명**: 진료과 필터('INTERNAL' 3초 지연 ➔ 'ORTHO' 0.2초 완료)와 예약 상태 필터를 빠르게 변경 시 오래된 응답이 최신 목록을 덮어써 중앙 진료 예약 목록은 오래된 필터 결과, 오른쪽 환자 요약은 최신 필터 기준 데이터로 서로 불일치합니다.

6. **Session + Cache 잔존 오류**
   - **설명**: 환자 A의 진료/검사 내역을 본 뒤 환자 B로 로그인하면 예약 목록은 B 기준으로 바뀌지만, 최근 검사 결과 수치, 미확인 알림, 처방전 요약 캐시(`cachedLatestTestResult`, `cachedUnreadNoticeCount`)는 A 데이터가 남아 노출됩니다.

7. **Server 파일 경로 오류**
   - **설명**: 검사 결과 리포트 파일 이름에 한글과 공백이 포함된 경우(`혈액 검사 결과 (최종).pdf`), 목록에서는 정상 표시되나 상세 검사 결과 탭 API 응답 시 이중 URL 인코딩을 적용해 상세 탭에서만 파일 링크가 404로 깨집니다.

## 🧪 테스트 시나리오

1. **Error 1 테스트**: 우측 패널에서 예약 일자 선택 후 `시간 변경` 클릭 직후 담당 의사 변경 ➔ 3초 후 새로고침 시 시간은 바뀌었으나 담당 의사는 이전 의사로 롤백됨을 확인.
2. **Error 2 테스트**: 우측 패널에서 `⚡ 예약 취소 후 증상 수정` 클릭 ➔ 0.5초 후 취소 응답 ➔ 4초 후 증상 수정 응답이 완료되며 목록(취소)과 상세 인스펙터(예약 확정) 간 상태 불일치 확인.
3. **Error 3 테스트**: 좌측 사이드바에서 `빠른 날짜순` 정렬 선택 ➔ 상단 항목의 예약 변경 클릭 ➔ 실제 원본 배열의 엉뚱한 index 예약이 수정 선택됨을 확인.
4. **Error 4 테스트**: 중앙 예약 내역 대장에서 `🗑️ 취소/삭제` 클릭 ➔ 대장에서는 삭제되나 병원 대시보드의 총 예약 수 및 진료과별 수용률 수치가 유지됨을 확인.
5. **Error 5 테스트**: 좌측 진료과 필터를 `소화기내과` 선택 직후 `정형외과` 선택 ➔ 3초 후 늦은 이전 결과가 최신 목록을 덮어씀을 확인.
6. **Error 6 테스트**: 상단 로그인 환자를 `환자 A`에서 `환자 B`로 전환 ➔ 예약 목록은 B로 바뀌나 상단 KPI 최근 검사 결과는 A 데이터로 잔존함을 확인.
7. **Error 7 테스트**: 검사 결과 목록에서 `상복부 초음파 정밀 영상` 선택 ➔ 우측 상세 리포트 미리보기 패널에서 파일 링크가 404로 깨짐을 확인.
