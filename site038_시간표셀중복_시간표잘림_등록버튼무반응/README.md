# Elite Academy - site038

엘리트 학원 수강관리 및 시간표 플랫폼입니다. PPO 강화학습 에이전트의 프론트엔드 GUI 오류 탐지 학습을 위해 제작되었습니다.

## 프로젝트 정보
- **사이트 ID**: site038
- **포트 번호**: 9257
- **기술 스택**: React, Vite, Express, Lucide-React
- **주제**: 학원 수강신청 및 시간표 관리

## 실행 방법
1. 폴더 이동: `cd site038`
2. 패키지 설치: `npm install`
3. 프론트엔드 빌드: `npm run build`
4. 서버 실행: `npm start`
5. 접속: `http://localhost:9257`

## API 엔드포인트
- `GET /api/health`: 서버 상태 확인
- `GET /api/classes`: 강좌 목록 데이터
- `GET /api/teachers`: 강사진 프로필 데이터

## 정상 작동 기능 (10+ Interactions)
1. 과목 카테고리 필터링 (Math, English 등)
2. 강사 프로필 이미지 클릭 시 상세 모달 오픈
3. 모달 내 상담 신청 버튼 인터랙션
4. 시간표 요일 탭 전환
5. 수강 등록 버튼 클릭 시 사이드바 장바구니 추가 (정상 과목)
6. 장바구니 항목 삭제 (휴지통 아이콘)
7. 수강료 안내 아코디언 토글
8. 후기 섹션 별점 및 내용 렌더링
9. 헤더 내 상담 신청/로그인 버튼 알림창
10. 푸터 내 각종 안내 링크 호버 효과

## 의도된 프론트엔드 오류 (3개)
1. **site038-bug01**: 시간표 셀 중복 (월요일 수업이 화요일에도 표시됨)
2. **site038-bug02**: 시간표 잘림 (CSS overflow 설정으로 금요일 열 노출 안됨)
3. **site038-bug03**: 등록 버튼 무반응 (특정 과목의 등록 버튼이 동작하지 않음)
