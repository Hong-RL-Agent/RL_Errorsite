# The Heritage - 아파트 주민 관리 포털 (site053)

주민들이 공지사항을 확인하고, 민원을 접수하며, 시설을 예약할 수 있는 아파트 관리 포털 사이트입니다. 강화학습(PPO) 에이전트의 GUI 오류 탐지 성능 측정을 위한 학습용 데이터셋으로 개발되었습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site053
- **포트 번호**: 9272
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **주요 테마**: 네이비 / 화이트 / 민트 계열의 전문적인 공공 포털 UI

## 2. 실행 방법
```bash
cd site053
npm install
npm start
```
- 접속 주소: [http://localhost:9272](http://localhost:9272)

## 3. 주요 기능
- **공지사항 조회**: 중요 공지 강조 표시 및 카테고리/검색 필터 기능
- **관리비 내역**: 월별 관리비 요약 및 항목별 금액 조회
- **민원 접수**: 유형별 민원 입력 및 접수 프로세스
- **시설 예약**: 커뮤니티 시설(휘트니스 등) 예약 캘린더
- **주민 지원**: 택배 알림, 차량 예약, 주민 투표 등 부가 서비스 (준비 중 포함)

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **공지사항 중복 렌더링 (site053-bug01)**: 특정 카테고리 필터링 시 기존 목록이 지워지지 않아 결과가 중복 표시됨.
2. **탭 콘텐츠 겹침 (site053-bug02)**: 시설 예약 탭으로 이동해도 민원 접수 폼이 사라지지 않아 화면이 겹침.
3. **민원 등록 버튼 무반응 (site053-bug03)**: 버튼의 ID가 코드 내 셀렉터와 일치하지 않아 클릭 시 동작하지 않음.

## 5. 프로젝트 구조
- `server.js`: 관리비 및 공지사항 API 서버
- `public/index.html`: 메인 대시보드 레이아웃
- `public/styles.css`: 디자인 시스템 및 탭 레이아웃 스타일
- `public/app.js`: 데이터 처리 및 의도된 오류 로직
- `BUGS.md`: 의도된 오류의 상세 명세 및 재현 경로
