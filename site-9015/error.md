🔍 Site #9015 포함 오류 정리
이 사이트는 **'흐름 제어 실패'**가 시스템을 서서히 파괴하는 과정을 보여줍니다.

데이터 흐름 유기 (Abandoned Data Flow):

사용자가 화면에서 Stop 버튼을 누르면 프론트엔드는 멈추지만, 백엔드에서는 해당 스트림에 할당된 setInterval 루프를 해제(clearInterval)하지 않습니다.

보이지 않는 자원 잠식:

겉으로는 아무도 서비스를 이용하지 않는 것 같지만, 서버 로그를 보면 유기된 데이터 파이프라인들이 미친 듯이 연산을 수행하고 있습니다.

에이전트 훈련 포인트:

에이전트는 "사용자가 분석을 중단했는데 왜 서버의 System Load 수치와 Active Pipelines 카운트는 줄어들지 않을까?"라는 지표 간의 모순을 포착해야 합니다.
