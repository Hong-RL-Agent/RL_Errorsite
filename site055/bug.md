# CulturePick (site055) 결함 명세서 (bug.md)

이 문서는 CulturePick(site055)에 구현된 정확히 5개의 의도적 오류(SEC-451 ~ SEC-455)에 대한 명세서입니다.

---

### 1. SEC-451 — 공연장 좌석 행(row) 구분자가 숫자와 문자열에서 다르게 처리되는 문제

* **SEC ID**: SEC-451
* **오류 유형**: Data Normalization / identifier-coercion
* **재현 조건**: 공연 회차 선택 후 좌석 선택 시 좌석 번호 포맷팅(A1 vs A01) 간 정규화 불일치가 발생하는 상황
* **재현 절차**:
  1. `공연 목록` (`/events`)에서 임의의 공연 선택하여 상세 페이지 진입
  2. `회차 보기` (`/events/:id/schedule`) 클릭하여 회차 선택
  3. `좌석 선택` (`/events/:id/seats`) 화면에서 `A1` 좌석 클릭
  4. 좌석 선택 요청 및 선택 상태 확인
* **관찰되는 증상**: 화면에는 A1으로 표시되나 내부적으로 A01 등으로 비정규화 처리되어 좌석 선택 조회가 어긋나거나 선택이 해제되는 현상 발생
* **정상 동작**: 좌석 식별자는 선행 0 여부와 관계없이 일관된 canonical 포맷으로 정규화되어 처리되어야 함
* **오류 발생 원인**: 서버 및 클라이언트의 좌석 매핑 로직에서 row와 number의 문자열 결합 시 정규화(padZero) 누락
* **PPO가 탐색해야 하는 행동**: 좌석 선택 화면에서 1열 좌석들을 클릭하고 내부 선택 식별자 및 상태를 확인

---

### 2. SEC-452 — 공연 상세에서 펼쳐보기/접기 후 스크롤 위치가 잘못 복원되는 문제

* **SEC ID**: SEC-452
* **오류 유형**: Interaction / scroll-position
* **재현 조건**: 공연 상세 페이지의 긴 공연 상세 정보에서 펼쳐보기(더보기) 클릭 후 아래로 스크롤한 뒤 접기를 누를 때 발생
* **재현 절차**:
  1. 공연 상세 페이지 (`/events/:id`) 진입
  2. 공연 소개 하단의 `상세 정보 더보기` 버튼 클릭
  3. 펼쳐진 상세 내용 아래쪽으로 스크롤 다운
  4. `상세 정보 접기` 버튼 클릭
* **관찰되는 증상**: 접기 버튼을 누르는 순간 보고 있던 위치가 유지되지 않고 화면 최상단(y=0)으로 갑자기 튕김
* **정상 동작**: 접기 실행 시 사용자가 보고 있던 섹션의 시작 위치로 부드럽게 복원되거나 현재 뷰포트를 유지해야 함
* **오류 발생 원인**: 접기 이벤트 핸들러에서 상대 위치 계산 없이 `window.scrollTo(0, 0)`를 호출함
* **PPO가 탐색해야 하는 행동**: 상세 정보 펼치기 & 스크롤 다운 후 접기 버튼을 눌러 뷰포트 스크롤 점프 현상을 관찰

---

### 3. SEC-453 — 공연 후기 작성 시 공백만 입력한 내용이 정상 후기처럼 저장되는 문제

* **SEC ID**: SEC-453
* **오류 유형**: Input Validation / whitespace-validation
* **재현 조건**: 후기 작성 화면에서 내용에 공백 문자(`"   "`)만 입력하고 등록할 때 발생
* **재현 절차**:
  1. 공연 상세 또는 후기 페이지에서 `관람 후기 작성` 선택
  2. 별점 선택 후 내용 입력창에 스페이스바(공백 문자 `"   "`)만 입력
  3. `후기 등록` 버튼 클릭
  4. 등록된 후기 목록 확인
* **관찰되는 증상**: 공백 입력에 대한 유효성 검사 에러가 발생하지 않고, 본문이 비어있는 빈 후기가 정상 생성되어 목록에 등록됨
* **정상 동작**: `content.trim().length === 0`인 경우 "후기 내용을 입력해주세요"라는 400 유효성 검증 에러를 반환해야 함
* **오류 발생 원인**: 서버에서 `if (content !== undefined)`로만 존재 여부를 검사하고 trim 공백 검사를 누락함
* **PPO가 탐색해야 하는 행동**: 후기 작성 폼에 공백 문자열만 입력하여 등록하고 빈 후기가 생성되는지 검증

### 4. SEC-454 — 브라우저 창 크기에 따라 좌석 배치의 선택 좌표가 어긋나는 문제

* **SEC ID**: SEC-454
* **오류 유형**: Responsive UI / coordinate-mismatch
* **재현 조건**: 반응형 화면(작은 뷰포트 또는 창 크기 조절 상태)에서 좌석을 클릭할 때 발생
* **재현 절차**:
  1. 좌석 선택 화면 (`/events/:id/seats`) 진입
  2. 모바일/반응형 뷰포트(또는 브라우저 창 폭 축소)로 화면 전환
  3. 특정 좌석(예: A3)을 직접 클릭
  4. 실제 선택된 좌석 번호 확인
* **관찰되는 증상**: 클릭한 좌석(A3) 대신 인접한 옆 좌석(A2 또는 A1)이 선택되는 좌표 계산 불일치 발생
* **정상 동작**: 화면 크기에 비례하여 좌석 터치/클릭 영역이 정확히 스케일링되어 클릭한 좌석이 정확히 선택되어야 함
* **오류 발생 원인**: 좌석 클릭 핸들러가 뷰포트 반응형 스케일 팩터를 반영하지 않고 고정된 데스크톱 픽셀 좌표 오프셋으로 인덱스를 계산함
* **PPO가 탐색해야 하는 행동**: 반응형 상태에서 좌석 그리드를 클릭하여 의도한 좌석과 실제 선택 좌석 간 불일치를 확인

---

### 5. SEC-455 — 공연 공유 버튼을 빠르게 연속 클릭하면 임시 공유 메뉴가 중첩되는 문제

* **SEC ID**: SEC-455
* **오류 유형**: UI Lifecycle / duplicate-overlay
* **재현 조건**: 공연 상세 페이지에서 공유(Share) 버튼을 빠르게 2회 이상 연속 클릭할 때 발생
* **재현 절차**:
  1. 공연 상세 페이지 (`/events/:id`) 진입
  2. `공유하기` 버튼을 빠르게 연속으로 3회 클릭
  3. 화면에 나타난 공유 모달 오버레이 상태 확인
  4. 닫기 버튼을 클릭하며 중첩 레이어 확인
* **관찰되는 증상**: 기존 모달이 닫히거나 단일 인스턴스로 유지되지 않고 여러 개의 공유 메뉴 오버레이가 화면에 겹쳐서 생성됨
* **정상 동작**: 공유 버튼 클릭 시 항상 단일 모달 오버레이만 열려야 함
* **오류 발생 원인**: 공유 버튼 클릭 시 boolean 토글 대신 배열 상태에 새로운 오버레이 ID를 계속 push하여 다중 렌더링됨
* **PPO가 탐색해야 하는 행동**: 공유 버튼을 더블/트리플 클릭하여 오버레이가 다중 중첩 생성되는지 관찰
