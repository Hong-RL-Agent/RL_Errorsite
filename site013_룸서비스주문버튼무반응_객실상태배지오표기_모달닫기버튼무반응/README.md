# Hotel Concierge Service (site013)

## 개요
이 프로젝트는 PPO 강화학습 모델의 GUI 오류 탐지 훈련을 위한 호텔 컨시어지 서비스 웹사이트입니다. 골드와 딥그린 테마의 고급스러운 디자인을 제공합니다.

- **사이트 ID**: site013
- **포트 번호**: 9232
- **기술 스택**: React, Vite, Express, CSS

## 실행 방법
```bash
cd site013
npm install
npm run build
npm start
```

## API 엔드포인트 목록
- `GET /api/health` : 서버 상태 확인
- `GET /api/room-info` : 객실 정보 조회
- `GET /api/menu` : 룸서비스 메뉴 조회
- `POST /api/request` : 컨시어지 요청 전송 (정상 동작)

## 정상 작동 기능 목록
- **카테고리 전환**: 메뉴 탭(식사, 음료, 서비스 등) 전환 시 목록이 변경됩니다.
- **입력 폼**: 컨시어지 요청 내용을 입력하고 전송할 수 있습니다.
- **객실 정보**: 현재 투숙 중인 객실의 기본 정보를 확인할 수 있습니다.
- **미구현 피드백**: 구현되지 않은 메뉴 클릭 시 "준비 중" 토스트가 나타납니다.

## 의도된 GUI 오류 3개
1. **site013-bug01** (`button-no-response`): 룸서비스 주문 버튼 무반응.
2. **site013-bug02** (`component-rendering`): 객실 상태 배지 오표기 (잘못된 색상/텍스트).
3. **site013-bug03** (`modal-ui`): 모달 닫기 버튼 무반응.

## PPO 에이전트 기대 행동
- 주문 버튼 클릭 후 장바구니 변화가 없는 것을 감지.
- 객실 상태 배지의 비정상적인 색상 배합 또는 텍스트 오류 감지.
- 모달 닫기 시도 후 화면에 모달이 유지되는 상태 감지.
