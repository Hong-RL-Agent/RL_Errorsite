# BUGS - site013

이 문서는 PPO 에이전트 훈련을 위해 의도적으로 삽입된 GUI 오류를 설명합니다.

## 1. site013-bug01
- **Bug ID**: site013-bug01
- **Type**: button-no-response
- **화면 위치**: 룸서비스 메뉴 카드 내부 "주문하기" (Order) 버튼
- **관련 파일**: `src/components/RoomService.jsx`
- **Data Bug ID Selector**: `[data-bug-id="site013-bug01"]`
- **사용자가 경험하는 증상**: 메뉴 항목의 "주문하기" 버튼을 눌러도 우측 주문 요약 패널에 해당 항목이 추가되지 않으며 아무런 반응이 없음.
- **코드상 의도된 원인**: 버튼 엘리먼트에 핸들러 함수를 연결하지 않음.
- **PPO 에이전트가 탐지해야 할 기대 행동**: 버튼 클릭 이후 주문 목록(DOM)의 변화가 없는 것을 감지해야 함.

## 2. site013-bug02
- **Bug ID**: site013-bug02
- **Type**: component-rendering
- **화면 위치**: 메인 대시보드의 "객실 상태" (Room Status) 배지
- **관련 파일**: `src/App.jsx`
- **Data Bug ID Selector**: `[data-bug-id="site013-bug02"]`
- **사용자가 경험하는 증상**: 객실 상태가 "체크인 완료" 상태임에도 불구하고 배지 색상이 경고색(빨간색)으로 표시되거나, 텍스트가 "알 수 없음" 또는 잘못된 상태값으로 렌더링됨.
- **코드상 의도된 원인**: 상태값에 따른 조건부 렌더링 로직에서 의도적으로 잘못된 스타일 클래스와 텍스트를 할당함.
- **PPO 에이전트가 탐지해야 할 기대 행동**: 텍스트 내용과 색상의 부조화, 혹은 데이터 문맥에 맞지 않는 배지 렌더링을 감지해야 함.

## 3. site013-bug03
- **Bug ID**: site013-bug03
- **Type**: modal-ui
- **화면 위치**: 객실 상세 정보 모달 (Room Detail Modal) 우측 상단 닫기(X) 버튼
- **관련 파일**: `src/components/RoomModal.jsx`
- **Data Bug ID Selector**: `[data-bug-id="site013-bug03"]`
- **사용자가 경험하는 증상**: 모달 창이 열린 상태에서 닫기 버튼(X)을 클릭해도 모달이 사라지지 않고 화면에 유지됨.
- **코드상 의도된 원인**: 닫기 버튼의 `onClick` 핸들러에서 상태 변경 함수를 호출하지 않거나 주석 처리함.
- **PPO 에이전트가 탐지해야 할 기대 행동**: 닫기 액션 이후에도 모달 요소가 DOM과 화면에 계속 남아있는 것을 감지해야 함.
