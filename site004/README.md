# site004 - Admin ERP Portal

This application simulates an enterprise resources planning control system containing regular workspaces and secure administrative nodes.

## Getting Started

1. Install dependencies:
   ```bash
   cd site004
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   [http://localhost:9903](http://localhost:9903)

## Features

- User role selector (Admin / User).
- Admin panel integration.
- 9 vulnerable admin API endpoints (Orders, Profile, Reports, Invoices, Files, Messages, Appointments, Cart, Checkout).
- 100% Mock data architecture.
