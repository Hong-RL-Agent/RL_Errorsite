# site077 - ProMatch 프리랜서 매칭 플랫폼

'ProMatch'는 클라이언트와 검증된 프리랜서를 연결해 주는 전문 매칭 플랫폼 데스크톱 웹사이트입니다. 이 프로젝트는 PPO(강화학습) 모델의 GUI 오류 탐지 학습을 위해 제작되었습니다.

## 기술 스택
- **Frontend**: Vanilla HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Port**: 9296

## 실행 방법
```bash
cd site077
npm install
npm start
```
접속 주소: `http://localhost:9296`

## API 엔드포인트
- `GET /api/health`: 서버 상태 확인
- `GET /api/freelancers`: 프리랜서 목록 데이터 (이름, 직무, 기술 스택, 평점 등)
- `GET /api/projects`: 진행 가능한 프로젝트 목록 데이터

## 주요 기능
- **전문가 필터링**: 직무(디자이너, 개발자 등) 및 경력별 필터링
- **전문가 상세 모달**: 포트폴리오, 리뷰, 경력 상세 정보 탭 조회
- **제안 요청 시스템**: 전문가를 선택하여 우측 패널에 추가하고 일괄 제안 발송
- **프로젝트 의뢰 폼**: 프로젝트 요구사항 입력 및 접수
- **스티키 패널**: 선택한 전문가 목록을 실시간으로 관리

## 의도된 프론트엔드 GUI 오류 (3개)
1. **기술 태그 중복 렌더링** (`site077-bug01`): 프리랜서 카드 내 기술 태그 중 첫 번째 항목이 항상 중복 표시됨.
2. **포트폴리오 미리보기 overflow** (`site077-bug02`): 상세 모달 내 포트폴리오 이미지가 모달 영역을 벗어나 오버플로우됨.
3. **제안 요청 버튼 무반응** (`site077-bug03`): 특정 전문가(Marcus Thorne)의 버튼을 클릭해도 선택 패널에 반영되지 않음.
