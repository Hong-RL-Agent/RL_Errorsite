# site005 - Marketplace Seller Center

This application simulates an e-commerce marketplace seller admin console containing regular store statistics and secure administrative backend modules.

## Getting Started

1. Install dependencies:
   ```bash
   cd site005
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   [http://localhost:9904](http://localhost:9904)

## Features

- Active account switcher (Admin / Seller).
- Multi-channel statistics dashboard.
- 10 vulnerable admin API endpoints (Search, Notifications, Payments, Shipping, Returns, Reviews, Coupons, Wishlist, Support, Analytics).
- 100% Mock data architecture without active DB connections or external network dependencies.
