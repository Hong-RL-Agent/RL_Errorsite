# Site026: 독서 토론 모임 모집 플랫폼 (Book Club Hub)

독서 토론 모임을 모집하고 참여할 수 있는 커뮤니티 플랫폼입니다. PPO 강화학습 에이전트의 백엔드 로직 오류 탐지 성능을 평가하기 위한 테스트 환경으로 설계되었습니다.

## 핵심 기능
- **모임 목록 조회**: 필터링(참여 인원, 상태) 및 검색 기능을 통한 모임 조회.
- **새 모임 생성**: 새로운 독서 토론 모임 개설.
- **인기 모임 큐레이션**: 참여자 수가 많은 인기 모임 실시간 순위 제공.
- **대시보드 통계**: 플랫폼 내 전체 모임 현황 요약 제공.

## 기술 스택
- **Frontend**: React + Vite (Lucide Icons, Tailwind-like Vanilla CSS)
- **Backend**: Express (Node.js)
- **Port**: 9135

## 실행 방법
```bash
cd site026
npm install
npm start
```
서버 실행 후 [http://localhost:9135](http://localhost:9135)에서 접속 가능합니다.

## 의도된 백엔드 오류
본 프로젝트에는 PPO 에이전트 탐지용으로 의도된 4가지 백엔드 로직 오류가 포함되어 있습니다.

1.  **site026-bug01**: 참여 인원 필터 논리 오류 (결과가 반대로 출력됨)
2.  **site026-bug02**: 응답 데이터 필드 누락 (특정 조건에서 `bookTitle` 누락)
3.  **site026-bug03**: 모임 생성 시 기본값 오류 (`open` 대신 `closed`로 저장)
4.  **site026-bug04**: 인기 모임 조회 API 응답 지연 (2초 타임아웃 지연)

상세 내용은 `BUGS.md`를 참고하세요.
