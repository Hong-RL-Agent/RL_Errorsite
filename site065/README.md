# CleanDrop - 세탁 수거 예약 서비스 (site065)

집 앞에서 편리하게 맡기는 스마트 세탁 서비스 CleanDrop입니다. 고품질의 데스크톱 예약 시스템과 함께, 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위한 3가지 의도적 결함이 포함되어 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site065
- **포트 번호**: 9284
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 화이트, 클린 블루, 라이트 민트 기반의 깨끗한 생활 서비스 디자인

## 2. 실행 방법
```bash
cd site065
npm install
npm start
```
- 접속 주소: [http://localhost:9284](http://localhost:9284)

## 3. 주요 기능
- **세탁 품목 선택**: 품목별 단가 확인 및 예약 리스트 추가
- **수거 일정 예약**: 실시간 예약 가능 날짜 및 시간 슬롯 선택
- **실시간 가격 산정**: 선택 품목에 따른 예상 결제 금액 즉시 표시
- **서비스 안내**: 가격표 아코디언 및 수거 불가 품목 가이드 제공
- **주소 입력 시스템**: 직관적인 수거 주소 및 출입 정보 입력 폼

## 4. 의도된 프론트엔드 GUI 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **예상 금액 불일치 (site065-bug01)**: 선택된 모든 품목의 합계가 아닌, 마지막 항목을 제외한 금액이 표시됨.
2. **예약 폼 레이아웃 깨짐 (site065-bug02)**: 특정 화면 너비(1024px~1200px)에서 주소 입력창과 시간 선택창이 겹침.
3. **예약 버튼 무반응 (site065-bug03)**: '수거 예약하기' 버튼 클릭 시 이벤트 리스너 미연결로 인해 아무런 동작을 하지 않음.

## 5. 프로젝트 구조
- `server.js`: 세탁 품목 및 수거 슬롯 데이터를 제공하는 Express 서버
- `public/index.html`: 메인 예약 대시보드 레이아웃
- `public/styles.css`: 생활 서비스 테마 스타일 및 레이아웃 결함 구현
- `public/app.js`: 예약 로직, 가격 계산 및 이벤트/상태 결함 구현
