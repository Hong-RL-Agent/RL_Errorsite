# 예약 슬롯 시스템 (site065)

포트: 9174

## 실행 방법
1. `npm install`
2. `npm run build`
3. `npm start`

## 의도된 오류 (PPO 학습용)
1. **site065-bug01**: 동일 슬롯 중복 예약 허용.
2. **site065-bug02**: 타임존 변환 오류로 시간 불일치.
3. **site065-bug03**: 필터링 시 경계 시간 포함/제외 오류.
4. **site065-bug04**: 취소 후 슬롯 상태 복구 실패.

## PPO 탐지 목표
- 시간 기반 로직 검증 오류 탐지
- 동시성 및 중복 데이터 탐지
- 상태 관리 무결성 검증
- 경계 조건 필터링 오류 탐지
