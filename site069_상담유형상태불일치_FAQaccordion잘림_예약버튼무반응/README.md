# LawConnect - 법률 상담 예약 서비스 (site069)

신뢰할 수 있는 전문 변호사와 고객을 연결하는 법률 상담 예약 플랫폼입니다. 네이비와 골드 테마의 무게감 있는 디자인과 함께, 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위한 3가지 의도적 결함이 포함되어 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site069
- **포트 번호**: 9288
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 화이트, 네이비, 골드 기반의 신뢰감 있는 법률 서비스 스타일

## 2. 실행 방법
```bash
cd site069
npm install
npm start
```
- 접속 주소: [http://localhost:9288](http://localhost:9288)

## 3. 주요 기능
- **분야별 변호사 필터링**: 민사, 형사, 가사, 기업 등 분야별 전문 변호사 검색
- **상담 유형 선택**: 방문, 전화, 서면 등 다양한 상담 방식 선택
- **실시간 예약 요약**: 선택한 변호사와 상담 유형에 따른 합계 비용 실시간 계산
- **변호사 상세 프로필**: 경력, 평점 및 상담 가능 시간을 모달로 확인
- **FAQ 아코디언**: 상담 전 궁금한 사항을 미리 확인 가능

## 4. 의도된 프론트엔드 GUI 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **상담 유형 상태 불일치 (site069-bug01)**: '서면 검토' 등 특정 상담 유형을 선택해도 우측 예약 요약에는 이전 값(예: 민사 상담)이 그대로 표시됨.
2. **FAQ 아코디언 잘림 (site069-bug02)**: FAQ 답변을 펼쳤을 때 답변 내용이 길면 아래쪽이 잘려 보임 (고정 높이 및 overflow 오류).
3. **예약 버튼 무반응 (site069-bug03)**: '강소라 변호사' 카드의 예약 버튼 클릭 시 아무런 반응이 없음.

## 5. 프로젝트 구조
- `server.js`: 변호사 및 상담 유형 데이터를 제공하는 Express 서버
- `public/index.html`: 법률 상담 예약 레이아웃
- `public/styles.css`: 네이비 & 골드 테마 스타일 및 레이아웃 결함 구현
- `public/app.js`: 필터링, 예약 로직 및 상태/이벤트 결함 구현
