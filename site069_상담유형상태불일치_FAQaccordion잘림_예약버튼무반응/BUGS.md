# Intentional Frontend GUI Bugs - site069

PPO 에이전트 탐지용 의도적 GUI 오류 명세입니다.

---

### 1. 상담 유형 상태 불일치
- **Bug ID**: `site069-bug01`
- **CSV 오류명**: 상담 유형 상태 불일치
- **Type**: `consultation-type-summary-mismatch`
- **화면 위치**: 우측 '상담 예약 요약' 패널의 상담 유형 영역
- **관련 파일**: `public/app.js` (renderTypes 함수)
- **Selector**: `[data-bug-id="site069-bug01"]`
- **사용자 경험 증상**: 사용자가 '서면 검토' 상담 유형을 클릭하여 선택했음에도 불구하고, 우측 요약 패널에는 여전히 기본값인 '민사 상담'이 표시됩니다. 이로 인해 최종 예약 정보가 일치하지 않는 데이터 불일치 문제가 발생합니다.
- **의도된 원인**: `renderTypes` 내에서 '방문 상담'이 아닌 유형을 선택할 경우, 내부 상태는 변경되지만 화면을 갱신하는 `renderSummary` 함수 호출을 의도적으로 생략했습니다.
- **기대 탐지 행동**: 선택된 UI 요소의 텍스트와 요약 패널의 텍스트가 서로 일치하는지 비교하여 데이터 불일치 상태를 탐지해야 합니다.

---

### 2. FAQ 아코디언 잘림
- **Bug ID**: `site069-bug02`
- **CSV 오류명**: FAQ accordion 잘림
- **Type**: `faq-accordion-clipped`
- **화면 위치**: 본문 하단 '자주 묻는 질문' 섹션
- **관련 파일**: `public/styles.css`
- **Selector**: `[data-bug-id="site069-bug02"]`
- **사용자 경험 증상**: FAQ 항목 중 첫 번째 질문(상담 시간)을 클릭하여 펼쳤을 때, 답변 내용이 카드 높이에 갇혀 아래쪽 문장이 잘린 채로 보입니다. 사용자는 전체 답변을 읽을 수 없는 불편함을 겪습니다.
- **의도된 원인**: `.accordion-content` 요소에 `max-height: 40px`와 `overflow: hidden`을 고정적으로 부여하여, 텍스트가 길어져도 높이가 확장되지 않도록 설계했습니다.
- **기대 탐지 행동**: 요소 내의 실제 콘텐츠 높이(ScrollHeight)와 화면에 보이는 높이(ClientHeight)를 비교하여 콘텐츠가 잘렸음을 탐지해야 합니다.

---

### 3. 예약 버튼 무반응
- **Bug ID**: `site069-bug03`
- **CSV 오류명**: 예약 버튼 무반응
- **Type**: `legal-booking-button-no-response`
- **화면 위치**: '강소라 변호사' 카드 내의 '상담 예약하기' 버튼
- **관련 파일**: `public/app.js` (renderLawyers 함수)
- **Selector**: `button[data-bug-id="site069-bug03"]`
- **사용자 경험 증상**: 강소라 변호사 카드의 예약 버튼을 클릭해도 우측 요약 패널에 해당 변호사 정보가 반영되지 않습니다. 다른 변호사들의 버튼은 정상적으로 작동합니다.
- **의도된 원인**: 특정 변호사 ID(`2`)인 경우에만 클릭 이벤트 리스너를 등록하는 로직을 건너뛰도록 구현했습니다.
- **기대 탐지 행동**: 버튼 클릭 인터랙션 후 요약 패널의 상태 변화가 없는 결함 상태를 탐지해야 합니다.
