# CleanSpark - 프리미엄 청소 예약 서비스 (site048)

전문적인 청소 서비스를 손쉽게 견적 내고 예약할 수 있는 고해상도 데스크톱 웹사이트입니다. 강화학습(PPO) 에이전트의 프론트엔드 GUI 오류 탐지 학습을 위해 제작되었습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site048
- **포트 번호**: 9267
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **주요 테마**: 화이트 / 민트 / 네이비 컬러를 사용한 신뢰감 있는 서비스 UI

## 2. 실행 방법
```bash
cd site048
npm install
npm start
```
- 접속 주소: [http://localhost:9267](http://localhost:9267)

## 3. 주요 기능
- **서비스 선택**: 스튜디오, 가정집, 사무실 등 다양한 청소 서비스 선택
- **실시간 견적**: 청소 면적 및 추가 옵션(냉장고, 창문 등)에 따른 예상 금액 계산
- **예약 시간표**: API로부터 받은 날짜별 예약 가능 시간 동적 선택
- **반응형 요소**: Sticky 예약 요약 패널, FAQ 아코디언, 서비스 상세 모달 등
- **API 연동**: Express 서버를 통한 서비스 목록 및 시간표 데이터 페칭

## 4. 의도된 프론트엔드 오류 (3개)
학습 데이터용으로 의도적으로 삽입된 GUI 오류입니다. 상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **선택 옵션 표시 오류 (site048-bug01)**: 체크한 옵션과 요약에 표시되는 이름이 매핑 오류로 인해 다르게 나타남.
2. **폼 컬럼 깨짐 (site048-bug02)**: 특정 데스크톱 폭(1024px-1200px)에서 견적 폼의 입력 필드들이 겹치는 레이아웃 오류.
3. **견적 계산 버튼 무반응 (site048-bug03)**: 버튼의 ID와 이벤트 리스너의 셀렉터가 일치하지 않아 클릭 시 가격 계산이 동작하지 않음.

## 5. 프로젝트 구조
- `server.js`: Express 서버 및 API 엔드포인트
- `public/index.html`: 메인 웹사이트 구조
- `public/styles.css`: 전체 스타일 및 의도된 레이아웃 오류
- `public/app.js`: 서비스 로직 및 의도된 상태/이벤트 오류
- `BUGS.md`: 의도된 오류의 상세 명세
