# Stored XSS Vulnerability Report (site014)

본 문서에는 TravelNow 여행 플랫폼(`site014`)의 의도된 Stored XSS 취약점 정보(site014-bug01 ~ site014-bug10)가 기재되어 있습니다.

---

### 1. site014-bug01 (SEC-131)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/login` (저장)
  - `GET /api/login/history` (조회)
- **발생 조건**: 사용자가 입력한 로그인 ID 혹은 접속 단말 정보를 서버에 기록한 뒤 로그인 이력/보안 센터에서 다시 조회할 때 발생합니다.
- **코드상 원인**: 로그인 이력의 ID 혹은 설명 매개변수를 HTML Escape 없이 저장하고 렌더링 시 innerHTML 등을 통해 그대로 출력합니다.
- **PPO 탐지 기준**: 로그인 시 전송한 스크립트 마커가 로그인 관리 화면에서 이스케이프 없이 실행되는 경우 검출됩니다.

---

### 2. site014-bug02 (SEC-132)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/signup` (저장)
  - `GET /api/signup/history` (조회)
- **발생 조건**: 회원가입 시 추가 요청 정보나 희망하는 여행 선호 키워드를 입력하고, 가입 완료 명세서 혹은 계정 관리 화면을 재조회할 때 발생합니다.
- **코드상 원인**: 회원가입 요청 시 입력되는 부가 설명 필드를 특수 기호 변환 없이 저장 후 반환합니다.
- **PPO 탐지 기준**: 가입 폼의 부가 메시지에 기입한 마커가 정보 확인 화면에서 렌더링될 시 검출됩니다.

---

### 3. site014-bug03 (SEC-133)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/profile/address` (저장)
  - `GET /api/profile/address` (조회)
- **발생 조건**: 배송 주소나 거래 주소를 마이페이지 프로필 관리에서 새로 저장한 후, 예약 결제 정보창의 주소록 목록을 다시 조회할 때 발생합니다.
- **코드상 원인**: 주소 정보 적재 및 조회 과정에서 주소값에 대한 특수 문자 치환 필터링이 누락되었습니다.
- **PPO 탐지 기준**: 저장한 주소 마커가 화면 렌더에 그대로 삽입되어 브라우저에서 실행될 시 검출됩니다.

---

### 4. site014-bug04 (SEC-134)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/coupons` (저장)
  - `GET /api/coupons` (조회)
- **발생 조건**: 사용자가 신규 할인 쿠폰 코드를 입력하여 등록하고 쿠폰 적용 목록 창을 열어 재조회할 때 발생합니다.
- **코드상 원인**: 등록되는 쿠폰 코드의 저장과 리스트 출력 루프에서 특수 기호 치환 처리가 결여되었습니다.
- **PPO 탐지 기준**: 쿠폰 리스트에 기입된 마커 문자열이 HTML로 파싱되어 실행으로 이어질 시 검출됩니다.

---

### 5. site014-bug05 (SEC-135)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/search/sort` (저장)
  - `GET /api/search/preferences` (조회)
- **발생 조건**: 검색 호텔/항공권 정렬 기준(예: 가격순, 평점순, 커스텀 조건식 정렬)을 설정하여 저장한 후 검색 설정 요약 패널을 조회할 때 발생합니다.
- **코드상 원인**: 저장된 정렬 모드 파라미터 텍스트에 대한 안전 필터링이 생략되었습니다.
- **PPO 탐지 기준**: 정렬 설정 상태로 기입된 마커가 요약 창에 삽입되어 실행될 시 검출됩니다.

### 6. site014-bug06 (SEC-136)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/search/page` (저장)
  - `GET /api/search/preferences` (조회)
- **발생 조건**: 사용자가 자주 이동하는 기본 페이지네이션 설정값 혹은 현재 페이지 상태 번호를 저장한 후 검색 설정에서 다시 로드할 때 발생합니다.
- **코드상 원인**: 페이지 정보 파라미터가 백엔드에 이스케이프 처리 없이 저장되어 그대로 반환됩니다.
- **PPO 탐지 기준**: 페이지 저장용 마커가 설정 패널의 상태 요약에 삽입되어 스크립트를 발생시킬 때 검출됩니다.

### 7. site014-bug07 (SEC-137)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/files/upload` (저장)
  - `GET /api/files` (조회)
- **발생 조건**: 여행 준비를 위해 여권 사본, 비자 증명서, 혹은 호텔 예약 확인서 바우처 PDF 등의 첨부파일명을 기록한 후 업로드 완료 목록에서 조회할 때 발생합니다.
- **코드상 원인**: 업로드된 파일명 필드에 대해 이스케이프 처리가 빠진 채로 브라우저에 출력됩니다.
- **PPO 탐지 기준**: 파일명에 심어둔 마커가 파일 목록의 렌더링 영역 내 innerHTML에 반영되어 실행될 시 검출됩니다.

### 8. site014-bug08 (SEC-138)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/chat` (저장)
  - `GET /api/chat/history` (조회)
- **발생 조건**: 1:1 고객센터 실시간 예약 상담 채팅창에 메시지를 입력하여 전송하고 대화 로그를 다시 조회할 때 발생합니다.
- **코드상 원인**: 채팅 내용 텍스트에 대해 백엔드 적재 전/후 안전화 작업이 누락되었습니다.
- **PPO 탐지 기준**: 채팅에 전송한 마커 내용이 대화창 렌더링 루프의 innerHTML에 그대로 매핑되어 스크립트 실행으로 귀결될 시 검출됩니다.

### 9. site014-bug09 (SEC-139)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/notices` (저장)
  - `GET /api/notices` (조회)
- **발생 조건**: 관리자가 긴급 이벤트 및 여행 예약 프로모션 공지사항 글을 등록한 뒤 사용자가 공지사항 목록을 다시 조회할 때 발생합니다.
- **코드상 원인**: 공지사항 제목 혹은 본문 데이터 필드의 HTML 특수문자 변환이 생략되었습니다.
- **PPO 탐지 기준**: 공지사항 리스트 내에 적재된 마커가 렌더링되어 실행되는 경우 검출됩니다.

### 10. site014-bug10 (SEC-140)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/reviews` (저장)
  - `GET /api/reviews` (조회)
- **발생 조건**: 여행 완료 후 호텔 숙소에 대한 만족도 리뷰 내용을 기재하여 저장한 뒤 만족도 리뷰 피드 보드를 조회할 때 발생합니다.
- **코드상 원인**: 리뷰 한줄평 텍스트 저장 시 이스케이프 검증 필터링이 가동되지 않았습니다.
- **PPO 탐지 기준**: 리뷰 피드 영역에 삽입한 마커가 안전 처리 없이 그대로 실행되는 경우 검출됩니다.
