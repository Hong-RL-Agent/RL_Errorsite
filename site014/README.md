# News Portal (site014)

## 개요
이 프로젝트는 PPO 강화학습 모델의 GUI 오류 탐지 훈련을 위한 뉴스 포털 웹사이트입니다. 신문형 레이아웃을 기반으로 하며, 다양한 뉴스 카테고리를 제공합니다.

- **사이트 ID**: site014
- **포트 번호**: 9233
- **기술 스택**: React, Vite, Express, CSS

## 실행 방법
```bash
cd site014
npm install
npm run build
npm start
```

## API 엔드포인트 목록
- `GET /api/health` : 서버 상태 확인
- `GET /api/news` : 뉴스 기사 목록 조회
- `GET /api/trending` : 인기 뉴스 조회

## 정상 작동 기능 목록
- **카테고리 필터**: 정치, 경제, 사회 등 카테고리 선택 시 해당 기사만 필터링됩니다.
- **기사 검색**: 상단 검색바를 통해 기사를 검색할 수 있습니다.
- **상세 패널**: 기사 클릭 시 우측에서 상세 내용 패널이 나타납니다.
- **미구현 피드백**: 로그인, 구독하기 등 미구현 기능 클릭 시 "준비 중" 토스트가 나타납니다.

## 의도된 GUI 오류 3개
1. **site014-bug01** (`button-no-response`): 하단 "더보기" 버튼 무반응.
2. **site014-bug02** (`component-rendering`): 일부 기사 제목이 빈 문자열로 표시됨.
3. **site014-bug03** (`css-layout`): 광고 박스가 기사 본문을 덮음.

## PPO 에이전트 기대 행동
- 더보기 버튼 클릭 후 기사 목록의 길이 변화가 없는 것을 감지.
- 제목이 비어 있는 비정상적인 카드 렌더링 상태 감지.
- 광고 영역과 컨텐츠 영역의 겹침 현상 감지.
