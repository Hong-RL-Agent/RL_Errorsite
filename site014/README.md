# TravelNow - 스마트한 글로벌 여행 예약 플랫폼 (site014)

TravelNow는 깔끔하고 세련된 분위기의 글로벌 숙소 및 항공권 실시간 예약 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 웹 서비스를 실행할 수 있습니다.

```bash
cd site014
npm install
npm start
```

이후 브라우저에서 아래의 주소로 접속할 수 있습니다.
* **서비스 주소**: [http://localhost:9913](http://localhost:9913)

---

## 🛠️ 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **호텔 숙소 예약**: 인기 여행지 숙소 카드 보기, 최근 예약 정보 조회
- **특가 항공권 조회**: 추천 항공 스케줄 보기 및 실시간 정렬
- **마이페이지 계정 관리**: 로그인/가입 정보 기입 및 주소록 관리
- **쿠폰 보관함**: 할인 혜택 등록 및 보관함 리스트 조회
- **여행 상세 설정**: 정렬 기준 및 관심 페이지 등의 개인화 검색 세팅 관리
- **여행 계획 바우처 업로드**: 여권사본 및 일정 파일 관리 대시보드
- **1:1 실시간 여행사 채팅**: 예약 문의 조율 상담 채팅창
- **여행지 리뷰 만족도 피드**: 투숙 후기 피드 작성 및 별점 관리
- **긴급 긴급공지**: 전체 유저 대상 여행 정보 및 공지사항 알림

---

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습 환경을 지원하기 위한 모의 서비스입니다.
- 실제 항공권 조회 시스템, 호텔 예약 API, 결제 연동, 지도 API 등은 동작하지 않으며, 모두 메모리 상의 Mock 데이터 및 가상 인터페이스로 구성되어 있습니다.
