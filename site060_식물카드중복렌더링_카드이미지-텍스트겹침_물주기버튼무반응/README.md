# PlantCare - 식물 관리 매니저 (site060)

내 손안의 작은 숲, 반려 식물을 위한 통합 관리 솔루션입니다. 식물 정보 조회, 물주기 일정 체크, 관리 팁 제공 기능을 포함하고 있으며, 강화학습(PPO) 에이전트의 GUI 오류 탐지를 위한 의도적인 결함이 포함되어 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site060
- **포트 번호**: 9279
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 화이트, 포레스트그린, 라이트민트 기반의 자연 친화적 디자인

## 2. 실행 방법
```bash
cd site060
npm install
npm start
```
- 접속 주소: [http://localhost:9279](http://localhost:9279)

## 3. 주요 기능
- **식물 관리 대시보드**: 내 식물의 상태와 종류를 한눈에 확인
- **스마트 필터 및 검색**: 종류별 필터링과 이름 검색 기능
- **관리 태스크 리스트**: 오늘 해야 할 물주기, 영양제 등 체크리스트
- **식물 상세 정보**: 모달을 통한 식물별 상세 케어 가이드 확인
- **물주기 기록**: 버튼 클릭으로 마지막 물주기 날짜 즉시 갱신
- **지식 아코디언**: 초보자를 위한 단계별 관리 팁 제공

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **식물 카드 중복 렌더링 (site060-bug01)**: 필터 변경 시 특정 식물 카드가 리스트에 중복되어 나타남.
2. **카드 이미지-텍스트 겹침 (site060-bug02)**: 특정 화면 너비에서 이미지가 아래 카드의 텍스트 영역을 침범함.
3. **물주기 버튼 무반응 (site060-bug03)**: 특정 식물(Snake Plant)의 '물주기 기록' 버튼을 눌러도 반응이 없음.

## 5. 프로젝트 구조
- `server.js`: 식물 및 태스크 데이터를 제공하는 Express API 서버
- `public/index.html`: 메인 대시보드 및 레이아웃
- `public/styles.css`: 자연 친화적 테마 스타일 및 레이아웃 버그 구현
- `public/app.js`: 데이터 페칭, 렌더링, 이벤트 처리 및 기능 버그 구현
- `BUGS.md`: 의도된 오류의 상세 명세
