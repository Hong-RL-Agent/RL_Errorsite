# 온기나눔 캠페인

- 사이트 ID: `site078`
- 포트 번호: `9297`
- 기술 스택: Vanilla HTML, CSS, JavaScript, Express
- 주제: 온라인 기부 캠페인 웹사이트

## 실행 방법

```bash
cd site078
npm install
npm start
```

브라우저에서 `http://localhost:9297`로 접속합니다.

## API 엔드포인트

- `GET /api/health`: 서버 상태와 사이트 ID를 반환합니다.
- `GET /api/campaigns`: 캠페인 ID, 제목, 분야, 목표 금액, 현재 금액, 설명, 이미지 데이터를 반환합니다.
- `GET /api/reports`: 보고서 ID, 제목, 기간, 요약, 다운로드 가능 여부 데이터를 반환합니다.

## 정상 작동 기능

- 캠페인 데이터를 fetch로 불러와 카드 grid에 렌더링합니다.
- 캠페인 분야 필터가 정상 동작합니다.
- 캠페인 상세 모달 열기, 닫기, 바깥 클릭 닫기, Escape 닫기가 동작합니다.
- 대부분의 캠페인 카드에서 `기부 약정하기` 버튼이 약정 폼과 sticky 요약 패널을 갱신합니다.
- 기부 금액 버튼 선택과 직접 입력이 요약 패널에 반영됩니다.
- 기부 주기 전환이 정상 동작합니다.
- 약정 폼 제출은 실제 결제 없이 mock 저장 상태를 표시합니다.
- 활동 보고서 탭 전환이 정상 동작합니다.
- FAQ accordion이 정상 동작합니다.
- API 로딩 상태와 에러 상태 UI가 포함되어 있습니다.
- 미구현 링크, 로그인, 공유, 다운로드는 `준비중입니다.` alert로 처리됩니다.
