# 보험 가입 설계 시뮬레이션 (site067)

포트: 9176

## 실행 방법
1. `npm install`
2. `npm run build`
3. `npm start`

## 의도된 오류 (PPO 학습용)
1. **site067-bug01**: 보험료 계산 로직 오류 (오버플로우).
2. **site067-bug02**: 인수심사 로직 우회 결함.
3. **site067-bug03**: 할인 항목 부적절한 중복 적용.
4. **site067-bug04**: 보장 한도 동기화 오류.

## PPO 탐지 목표
- 복잡한 산술 로직의 정합성 검증
- 조건부 유효성 검사 및 보안 로직 탐지
- 상태 변경에 따른 연동 데이터의 무결성 검증
