## 📋 정상 기능 요약

- **디지털 광고 캠페인 통합 대장**: 35개 캠페인의 일일 예산, 소진율, CTR, 상태(초안/심사중/승인/반려/집행중/일시중지/종료) 관제.
- **광고 소재 심사 보드**: 50개 소재(배너/비디오/네이티브/피드)의 심사 상태와 심사관 메모 관리.
- **예산 변경 감사 로그**: 80건의 예산 변경 이력 및 60건의 소재 심사 가이드 대장 관리.
- **광고주 계정 관리**: 20개 광고주사의 집행 예산 및 담당 마케터 관제.

## ⚠️ 의도적으로 삽입된 8가지 복합 오류

1. **Frontend + Backend 요청 순서 충돌**
   - 광고 소재를 승인(3초 지연 완료)한 직후 캠페인 예산을 변경(0.1초 완료)하면, 예산 변경 API는 먼저 완료되나 3초 뒤 완료되는 소재 승인 API가 요청 시작 시점의 구 DB 스냅샷(이전 예산)을 덮어써 저장하여 새로고침 시 캠페인 상세 예산과 대시보드 예산 요약이 서로 달라집니다.

2. **Backend + JSON DB 상태 충돌**
   - 캠페인 일시중지 API(0.5초 완료) 호출 직후 소재 심사완료 API(4초 지연 완료) 호출 시, 일시중지는 성공하지만 늦게 완료된 심사완료 요청이 일시중지된 캠페인을 다시 `RUNNING`(집행중) 상태로 복원시킵니다. 캠페인 목록에서는 일시중지, 소재 심사 화면에서는 집행중으로 표시됩니다.

3. **Frontend 정렬 인덱스 오류**
   - 캠페인 목록을 소진율순/CTR순으로 정렬한 뒤 상세 버튼 클릭 시 `sortedCampaigns` 배열 대신 원본 정렬 전 `campaigns` 배열의 동일 인덱스 캠페인 데이터가 열리는 결함입니다.

4. **통계 집계 불일치**
   - 예산 변경 로그를 삭제(`DELETE /api/budget-logs/:id`)하면 로그 대장에서는 소거되지만, 캠페인별 소진 금액(`adStats.totalSpentAmount`) 및 광고주별 집행액 수치에는 삭제 전 수치가 계속 남습니다.

5. **Network stale response 오류**
   - 광고주 필터 고속 변경 시(삼성전자: 3초 지연, 현대자동차: 0.2초 완료), 늦게 응답된 삼성전자 결과가 최신 현대자동차 캠페인 목록을 덮어써 캠페인 목록과 성과 요약이 불일치합니다.

6. **Session + Cache 잔존 오류**
   - 관리자 A에서 관리자 B로 로그인 전환 시 캠페인 목록은 B 권한 기준으로 변경되나, 상단 심사 대기 소재 수 및 최근 캠페인 알림 캐시에는 관리자 A의 데이터가 잔존합니다.

7. **Backend 권한 로그 오류**
   - 권한 없는 일반 직원이 광고 소재 강제 승인 API 호출 시 HTTP 403 Forbidden을 응답하지만, 서버 내부 활동 감사 로그에는 `CREATIVE APPROVED SUCCESSFULLY (200 OK)`로 기록됩니다.

8. **부분 저장 오류**
   - 캠페인 정보 수정 모달에서 캠페인명, 일일예산, 타겟 지역을 동시에 수정하면 백엔드는 일일예산 필드를 제외하고 부분 저장하지만 프론트엔드 UI에는 3가지 항목 모두 정상 저장된 것으로 표시됩니다.

## 🧪 테스트 시나리오

1. **Error 1 테스트**: 우측 관제 패널에서 `소재 승인 후 즉시 캠페인 예산 변경 (Error 1)` 클릭 ➔ 0.1초 후 예산 변경 응답 ➔ 3초 후 소재 승인 완료 ➔ 새로고침 시 이전 예산으로 롤백 저장됨을 확인.
2. **Error 2 테스트**: `⚡ 캠페인 일시중지 후 소재 심사완료 연쇄 실행 (Error 2)` 클릭 ➔ 0.5초 후 일시중지 응답 ➔ 4초 후 심사완료 완료 ➔ 일시중지된 캠페인이 RUNNING 집행중 상태로 복원됨을 확인.
3. **Error 3 테스트**: 좌측 사이드바에서 `예산 소진율 높은순` 정렬 선택 ➔ 최상단 캠페인의 `상세` 클릭 ➔ UI 상단 캠페인명과 우측 관제 패널의 소재/예산 정보가 상이함을 확인.
4. **Error 4 테스트**: 중앙 예산 감사 로그 대장에서 `🗑️ 로그 삭제` 클릭 ➔ 대장에서는 삭제되나 대시보드 소진 금액 수치가 유지됨을 확인.
5. **Error 5 테스트**: 좌측 광고주 필터를 `삼성전자` 선택 직후 `현대자동차` 선택 ➔ 3초 후 늦은 삼성전자 결과가 최신 현대자동차 캠페인 목록을 덮어씀을 확인.
6. **Error 6 테스트**: 상단 로그인 마케터를 `김광고 총괄`에서 `이심사 관`으로 전환 ➔ 캠페인 목록은 B로 바뀌나 상단 KPI 심사 대기 건수는 A 데이터로 잔존함을 확인.
7. **Error 7 테스트**: `🔒 권한 없는 일반 직원의 광고 소재 강제 승인 시도` 클릭 ➔ UI/API는 HTTP 403 오류 반환 ➔ 백엔드 콘솔 로그에는 SUCCESS (200 OK)로 잘못 작성됨을 확인.
8. **Error 8 테스트**: 우측 하단 캠페인 정보 수정 패널에서 일일예산 포함 입력 후 `캠페인 정보 저장` 클릭 ➔ 토스트는 성공으로 표시되나 새로고침 시 일일예산만 수정되지 않았음을 확인.
