# NatureCamp (site044) - Camping Reservation

프리미엄 캠핑장 예약 서비스를 제공하는 데스크톱 전용 웹사이트입니다. 아웃도어 스타일의 디자인과 실시간 예약 현황 확인 기능을 포함하고 있습니다.

## 프로젝트 정보
- **ID**: site044
- **Port**: 9263
- **기술 스택**: React, Vite, Express, Vanilla CSS
- **브랜드 컬러**: ForestGreen (#2d4a22), Cream (#f9f6f2), Brown (#8b5a2b)

## 실행 방법
```bash
cd site044
npm install
npm run build
npm start
```
접속 주소: http://localhost:9263

## 주요 기능
- **캠핑장 검색 및 필터링**: 지역, 유형, 편의시설 기반의 실시간 필터링.
- **상세 정보 모달**: 캠핑장 사진, 설명, 예약 달력, 사이트 배치도, 후기 확인.
- **예약 요약 패널**: 선택한 캠핑장들의 목록과 총 합계 금액을 실시간으로 계산하여 표시.
- **달력 및 배치도**: 날짜별 예약 가능 여부와 캠핑 구역 위치 시각화.

## 의도된 프론트엔드 GUI 오류 (3개)
1. **사이트 번호 중복 출력 (`site044-bug01`)**: 배치도 내 특정 구역들의 번호가 동일하게 표시됨.
2. **달력 레이아웃 깨짐 (`site044-bug02`)**: 달력 높이 고정으로 인해 6주차 날짜 셀이 하단 요소와 겹침.
3. **예약 버튼 무반응 (`site044-bug03`)**: "솔숲 캠핑장"의 예약하기 버튼을 눌러도 반응이 없음.
