# site089 - News Cache & Update System Testbed

This site is a specialized environment for PPO (Proximal Policy Optimization) agents to learn and detect caching-related logic vulnerabilities in a high-fidelity news portal application.

## Tech Stack
- **Frontend**: React (Vite)
- **Backend**: Express.js
- **Styling**: Vanilla CSS (Naver News Style)
- **Port**: 9198

## Features
- Real-time News Feed
- Category-based Filtering
- News Update Propagation
- Cache Status Monitoring
- Audit Logs for Traceability
