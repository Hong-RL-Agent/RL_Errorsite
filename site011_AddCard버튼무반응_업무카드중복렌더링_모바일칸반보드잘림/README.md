# Productivity SaaS Kanban Board (site011)

## 개요
이 프로젝트는 PPO 강화학습 모델이 프론트엔드 GUI 오류를 탐지할 수 있도록 훈련하기 위한 목적으로 만들어진 독립적인 웹사이트(테스트 환경)입니다. 생산성 SaaS 스타일의 업무 칸반보드로 설계되었습니다.

- **사이트 ID**: site011
- **포트 번호**: 9230
- **기술 스택**: React, Vite, Express, CSS

## 실행 방법
```bash
cd site011
npm install
npm run build
npm start
```
이후 브라우저에서 `http://localhost:9230` 에 접속합니다.
(개발 시에는 `npm run dev`를 사용할 수 있습니다.)

## API 엔드포인트 목록
- `GET /api/health` : 서버 상태 확인용 엔드포인트
- `GET /api/tasks` : 칸반 보드 카드 데이터 (Mock 데이터) 조회

## 정상 작동 기능 목록
- **컬럼 필터**: "To Do", "In Progress", "Done" 상태별로 업무 카드가 올바르게 필터링되어 컬럼에 나타납니다.
- **카드 상세 보기**: 카드의 제목, 설명, 담당자 아바타 및 우선순위 배지가 정상적으로 표시됩니다.
- **완료 체크 토글**: 카드 내부의 체크박스를 통해 완료 여부를 토글할 수 있습니다 (프론트엔드 상태 반영).

## 의도된 GUI 오류 3개
본 프로젝트에는 다음과 같은 3개의 의도적인 GUI 버그가 포함되어 있습니다. (상세 내용은 `BUGS.md` 참조)

1. **site011-bug01** (`button-no-response`): "Add Card" 버튼을 클릭해도 입력 모달이 열리지 않음. `[data-bug-id="site011-bug01"]`
2. **site011-bug02** (`component-rendering`): 특정 업무 카드가 두 컬럼에 중복 렌더링됨. `[data-bug-id="site011-bug02"]`
3. **site011-bug03** (`css-layout`): 모바일에서 칸반 보드가 가로로 밀려 화면 일부가 잘림. `[data-bug-id="site011-bug03"]`

## PPO 에이전트 기대 행동
- 에이전트는 사용자와 같이 웹 페이지를 탐색하며 클릭 등의 액션을 수행합니다.
- `site011-bug01`의 경우, 버튼을 클릭하고 난 뒤 화면의 변화가 없는 것을 감지하고 이를 비정상적인 상태(오류)로 리포트해야 합니다.
- `site011-bug02`의 경우, 동일한 카드가 논리적으로 양립할 수 없는 두 컬럼에 동시에 렌더링되어 있는 정적 스크린샷 상태를 감지해야 합니다.
- `site011-bug03`의 경우, 모바일 뷰포트에서 DOM 요소의 너비가 화면 너비를 초과하여 레이아웃이 잘리는 현상을 감지해야 합니다.

## 배포 시 주의사항
- 본 프로젝트는 단일 폴더 `site011`만으로 동작해야 합니다.
- `package.json`의 `start` 스크립트 실행 시 Express 서버가 실행되며, 빌드된 React 정적 파일(dist/)을 서빙해야 합니다. 반드시 배포 전에 `npm run build`를 실행해야 합니다.
