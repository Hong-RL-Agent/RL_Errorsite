# Royal Museum of History - 오디오 가이드 (site056)

고급스러운 박물관/미술관 분위기의 오디오 가이드 웹사이트입니다. 주민들이 전시 작품의 해설을 듣고 전시관 정보를 확인할 수 있는 인터페이스를 제공하며, 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위해 제작되었습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site056
- **포트 번호**: 9275
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 아이보리 / 딥브라운 / 골드 기반의 클래식 박물관 UI

## 2. 실행 방법
```bash
cd site056
npm install
npm start
```
- 접속 주소: [http://localhost:9275](http://localhost:9275)

## 3. 주요 기능
- **전시관별 가이드**: 탭 기능을 통한 갤러리별 작품 오디오 트랙 조회
- **실시간 검색**: 작품명 및 작가 키워드를 통한 빠른 트랙 필터링
- **오디오 플레이어**: 하단 고정 플레이어를 통한 해설 재생 및 진행 상태 확인 (Mock)
- **작품 상세 정보**: 모달 창을 통한 작품의 역사적 배경 및 작가 설명 제공
- **맞춤형 코스**: 관람객 특성에 맞는 추천 관람 경로 안내

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **트랙 리스트 중복 (site056-bug01)**: 렌더링 로직 오류로 인해 첫 번째 트랙이 리스트에 두 번 표시됨.
2. **하단 플레이어 덮임 (site056-bug02)**: 본문 하단 여백 부족으로 고정 플레이어가 리스트 마지막 항목을 가림.
3. **재생 버튼 무반응 (site056-bug03)**: 특정 작품('함무라비 법전')의 재생 버튼이 클릭 이벤트 리스너 누락으로 동작하지 않음.

## 5. 프로젝트 구조
- `server.js`: 작품 및 오디오 트랙 데이터를 제공하는 Express API 서버
- `public/index.html`: 메인 대시보드 및 오디오 플레이어 레이아웃
- `public/styles.css`: 박물관 테마 디자인 및 고정 요소 레이아웃
- `public/app.js`: 데이터 처리, 필터링 및 의도된 오류 로직 구현
- `BUGS.md`: 의도된 오류의 상세 명세 및 재현 경로
