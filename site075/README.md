# site075 - PlayGround 보드게임 카페 예약 시스템

보드게임 카페 'PlayGround'의 좌석 예약 및 게임 목록 조회를 제공하는 데스크톱 전용 웹사이트입니다. 이 프로젝트는 PPO(강화학습) 모델의 GUI 오류 탐지 학습을 위해 제작되었습니다.

## 기술 스택
- **Frontend**: Vanilla HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Port**: 9294

## 실행 방법
```bash
cd site075
npm install
npm start
```
접속 주소: `http://localhost:9294`

## API 엔드포인트
- `GET /api/health`: 서버 상태 확인
- `GET /api/games`: 보드게임 목록 데이터 (장르, 난이도 등 포함)
- `GET /api/tables`: 예약 가능한 좌석 및 시간표 데이터

## 주요 기능
- **게임 목록 필터링**: 장르 및 난이도별 게임 조회
- **좌석 예약 시간표**: 테이블별 예약 가능한 시간 슬롯 확인
- **예약 요약 패널**: 선택한 테이블과 시간을 실시간으로 확인
- **게임 상세 모달**: 게임의 상세 정보(인원, 시간, 난이도 등) 팝업
- **찜하기 기능**: 게임 카드 및 상세 페이지에서 찜하기 토글

## 의도된 프론트엔드 오류 (3개)
학습 데이터용으로 고의 삽입된 GUI 오류입니다. 상세 내용은 `BUGS.md`를 참조하세요.
1. **난이도 필터 결과 불일치** (`site075-bug01`): 초급 필터 적용 시 일부 고급 게임이 섞여 나옴.

3. **좌석 예약 버튼 무반응** (`site075-bug03`): 특정 시간 슬롯의 버튼이 클릭에 반응하지 않음.
