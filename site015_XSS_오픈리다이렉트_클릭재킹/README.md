# Community Forum (site015)

## 개요
이 프로젝트는 PPO 강화학습 모델의 GUI 오류 탐지 훈련을 위한 커뮤니티 포럼 웹사이트입니다. 실제 보안 취약점인 XSS, 오픈 리다이렉트, 클릭재킹의 증상을 UI상에서 재현합니다.

- **사이트 ID**: site015
- **포트 번호**: 9234
- **기술 스택**: React, Vite, Express, CSS

## 실행 방법
```bash
cd site015
npm install
npm run build
npm start
```

## API 엔드포인트 목록
- `GET /api/health` : 서버 상태 확인
- `GET /api/posts` : 게시글 목록 조회
- `GET /api/tags` : 인기 태그 조회

## 정상 작동 기능 목록
- **태그 필터**: 사이드바 태그 클릭 시 해당 태그 게시글만 필터링.
- **좋아요**: 하트 아이콘 클릭 시 좋아요 수 카운트 증가.
- **상세 패널**: 게시글 클릭 시 우측에서 상세 내용이 슬라이드 인.
- **로딩/에러**: 데이터 fetch 중 스켈레톤 또는 에러 메시지 표시.

## 의도된 GUI 오류 (보안 시뮬레이션)
1. **site015-bug01** (XSS): 게시글 본문에 삽입된 스크립트가 실행되어 비정상적인 경고 UI 출력.
2. **site015-bug02** (오픈 리다이렉트): 파트너사 링크 클릭 시 잘못된 리다이렉션 발생.
3. **site015-bug03** (클릭재킹): 투명 레이어로 인해 의도치 않은 버튼 클릭 유도.

## PPO 에이전트 기대 행동
- UI 조작 시 예상되는 결과와 실제 시각적 피드백의 차이 감지.
- 보안 취약점의 전형적인 증상(비정상 팝업, 경로 이탈, 레이어 겹침) 식별.
