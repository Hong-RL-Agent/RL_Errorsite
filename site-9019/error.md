🔍 Site #9019 포함 오류 정리
객체 유기 (Object Abandonment):

사용자가 채팅방을 나가도 해당 사용자의 정보가 담긴 userObj를 전역 배열(leakedObjectReferences)에서 제거하지 않습니다.

메모리 누수 (Memory Leak):

각 객체는 Buffer.alloc을 통해 0.5MB의 메모리를 강제로 점유하고 있습니다. 입/퇴장을 반복할수록 Node.js 프로세스의 heap_used가 기하급수적으로 늘어납니다.

에이전트 훈련 포인트:

에이전트는 하단의 분석 창에서 **"UI 상 유저"**는 줄어드는데 **"상주 유저 객체"**는 계속 늘어나는 현상을 보고, 백엔드 코드에서 가비지 컬렉션을 방해하는 전역 참조가 있음을 알아내야 합니다.
