# MapOps | 지도 기반 장소 플랫폼 (site063)

이 웹사이트는 **강화학습 모델(PPO)**이 백엔드 로직 오류를 탐지하도록 설계된 특수 테스트 베드입니다. 고충실도 UI와 4개의 의도된 백엔드 로직 결함을 포함하고 있습니다.

## 📡 시스템 정보
- **사이트 ID**: site063
- **포트**: 9172 (Vite) / 9173 (Express)
- **기술 스택**: React, Vite, Express.js

## 🚀 실행 방법
```bash
cd site063
npm install
npm start
```
접속: http://localhost:9172

## 🐞 의도된 오류 (PPO 탐지 목표)

| Bug ID | 유형 | 설명 | 트리거 방법 |
|---|---|---|---|
| **site063-bug01** | coordinate-precision-loss | 좌표 소수점 2자리 제한 (정밀도 손실) | '장소 탐색' > [정밀 위치 조회] 버튼 |
| **site063-bug02** | distance-calculation-distortion | 거리 계산 공식 왜곡 (정렬 부정확) | '장소 탐색' > [거리순 정렬] 버튼 |
| **site063-bug03** | favorite-key-collision | 즐겨찾기 키 충돌 (사용자 식별 누락) | 장소 카드 > [⭐] 버튼 클릭 |
| **site063-bug04** | pagination-gap-loss | 페이지네이션 데이터 누락 (Offset 오류) | '리뷰 관리' > [2] 페이지 버튼 |

## ✅ 주요 기능
- **장소 탐색**: 위치 기반 장소 리스트 조회 및 거리순 정렬.
- **즐겨찾기**: 나만의 장소를 별표로 등록하고 관리.
- **리뷰 모니터링**: 사용자 리뷰 페이지네이션 조회.
- **대시보드**: 전체 데이터 현황 및 시스템 트랜잭션 로그 실시간 확인.
- **PPO 모니터**: 화면 우측 하단의 패널을 통해 탐지된 BugId를 실시간 확인 가능.

## 🎨 디자인 컨셉
- **Aesthetic**: `site043` 스타일 (화이트 배경, 레드 포인트, 블랙 텍스트)
- **Map Focus**: 지도 기반 서비스 고유의 그린/블루 포인트 적용
- **Interactive**: 모든 버튼은 시각적 피드백과 함께 동작하며, 오류 발생 시 명확한 배너가 노출됩니다.

---
**PPO 학습 포인트**: 
1. 정밀도 손실로 인한 데이터 중복 인지.
2. 수학적 로직(거리)과 정렬 순서의 불일치 탐지.
3. 데이터 덮어쓰기(Collision)로 인한 정합성 위반 탐지.
4. 페이지 이동 간 데이터 누락(Gap) 패턴 분석.
