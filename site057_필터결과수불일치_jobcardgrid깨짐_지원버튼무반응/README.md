# RemoteBase - 리모트 워크 채용 플랫폼 (site057)

전 세계 어디서든 일할 수 있는 원격 근무 기회를 연결하는 현대적인 채용 플랫폼입니다. 세련된 SaaS UI를 통해 직무 탐색과 지원 프로세스를 제공하며, 강화학습(PPO) 에이전트의 오류 탐지 학습 데이터셋으로 활용됩니다.

## 1. 프로젝트 정보
- **사이트 ID**: site057
- **포트 번호**: 9276
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 화이트 / 인디고 / 민트 기반의 깔끔한 SaaS 스타일

## 2. 실행 방법
```bash
cd site057
npm install
npm start
```
- 접속 주소: [http://localhost:9276](http://localhost:9276)

## 3. 주요 기능
- **통합 검색 및 필터링**: 직무 카테고리 및 원격근무 유형별 맞춤형 공고 탐색
- **채용 공고 관리**: 기술 스택, 연봉 범위 등 상세 정보 확인 및 모달 조회
- **관심 기업 관리**: 회사 저장(즐겨찾기) 기능 및 기업별 채용 현황 확인
- **지원 프로세스**: 즉시 지원하기 기능을 통한 채용 프로세스 진입 (Mock)
- **사용자 편의**: 실시간 지원 현황 요약 및 커리어 콘텐츠 제공

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **필터 결과 수 불일치 (site057-bug01)**: 필터 적용 시 화면의 카드 수와 상단 결과 수 배지의 숫자가 다르게 표시됨.
2. **job card grid 깨짐 (site057-bug02)**: 브라우저 너비 축소 시 카드가 겹치거나 레이아웃이 밀리는 결함.
3. **지원 버튼 무반응 (site057-bug03)**: 특정 공고('NovaSoft')의 지원 버튼이 클릭 이벤트 미연결로 작동하지 않음.

## 5. 프로젝트 구조
- `server.js`: 채용 공고 및 기업 정보를 제공하는 API 서버
- `public/index.html`: 메인 채용 보드 및 대시보드 레이아웃
- `public/styles.css`: 현대적인 디자인 시스템 및 그리드 레이아웃 스타일
- `public/app.js`: 데이터 필터링, 검색 및 의도된 오류 로직 구현
- `BUGS.md`: 의도된 오류의 상세 명세 및 재현 경로
