# Site 023 - Movie & Performance Booking Platform

React + Vite + Express.js
Mock Data Only

This application is designed for autonomous security agents (PPO) to inspect and detect Session Fixation vulnerabilities (SEC-231 to SEC-240) in a realistic environment.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the application:
   ```bash
   npm start
   ```
3. Open in browser:
   ```
   http://localhost:9922
   ```
