# Site 024 - Secondhand Marketplace Platform

React + Vite + Express.js
Mock Data Only

This application is designed for autonomous security agents (PPO) to inspect and detect Logout Token Reuse vulnerabilities (SEC-241 to SEC-250) in a realistic environment.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the application:
   ```bash
   npm start
   ```
3. Open in browser:
   ```
   http://localhost:9923
   ```
