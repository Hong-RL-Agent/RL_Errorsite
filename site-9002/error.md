1. 리눅스 파일 시스템 권한 오류 (핵심 함정)
파일 위치: 백엔드 컨테이너 내의 /app/uploads 폴더.

내용: docker exec 명령어를 통해 해당 폴더의 권한을 555 (읽기 및 실행 가능, 쓰기 불가)로 제한했습니다.

오류: 백엔드 서버가 사용자의 파일을 저장하려고 시도할 때, 운영체제(OS) 수준에서 "너는 이 폴더에 글을 쓸 권한이 없어!"라고 거부합니다.

2. 백엔드(Node.js)의 EACCES 예외 발생
파일: backend/server.js (Multer 미들웨어)

내용: 파일 업로드 라이브러리인 Multer가 uploads/ 폴더에 임시 파일을 생성하려고 하지만, 권한 부족으로 인해 시스템 에러(Error: EACCES: permission denied)가 발생합니다.

오류: 백엔드 코드는 이 에러를 캐치하여 사용자에게 HTTP 403 Forbidden 상태 코드를 반환합니다.

3. 볼륨 마운트 동기화 문제 (Docker 인프라 함정)
파일: docker-compose.yml

내용: 로컬 호스트의 ./uploads 폴더와 컨테이너 내부의 /app/uploads 폴더가 연결(Volume Mount)되어 있습니다.

오류: 때때로 호스트 컴퓨터(Windows)의 폴더 보안 설정이 도커 내부 권한과 충돌을 일으키기도 합니다. 에이전트는 단순한 코드 버그가 아니라, 컨테이너 외부와 내부의 연결 관계까지 의심해야 하는 상황에 놓입니다.
