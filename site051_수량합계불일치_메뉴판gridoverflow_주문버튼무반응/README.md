# BerryBliss - 프리미엄 디저트 카페 주문 (site051)

달콤하고 세련된 브랜드 이미지를 강조한 디저트 카페 온라인 주문 웹사이트입니다. 강화학습(PPO) 에이전트의 GUI 오류 탐지 및 학습을 위한 데이터셋으로 활용됩니다.

## 1. 프로젝트 정보
- **사이트 ID**: site051
- **포트 번호**: 9270
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 딸기 핑크 / 크림 / 초콜릿 브라운 기반의 스위트 감성 UI

## 2. 실행 방법
```bash
cd site051
npm install
npm start
```
- 접속 주소: [http://localhost:9270](http://localhost:9270)

## 3. 주요 기능
- **메뉴 브라우징**: 케이크, 쿠키, 마카롱 등 카테고리별 디저트 탐색
- **실시간 검색**: 메뉴 이름을 통한 실시간 필터링
- **장바구니 시스템**: 상품별 수량 조절 및 실시간 주문 요약 업데이트
- **픽업 예약**: API로 제공되는 실시간 시간대별 픽업 예약 선택
- **사용자 알림**: 미구현 기능 클릭 시 "준비 중입니다" alert 제공

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **수량 합계 불일치 (site051-bug01)**: 장바구니에 담긴 아이템의 총 수량이 실제 합계보다 적게 계산됨 (app.js 로직 오류).
2. **메뉴판 grid overflow (site051-bug02)**: 특정 화면 너비에서 메뉴 그리드가 우측 패널을 침범하거나 레이아웃을 벗어남 (CSS 고정 너비 오류).
3. **주문 버튼 무반응 (site051-bug03)**: '제주 말차 파운드' 메뉴의 주문 버튼이 클릭 이벤트 미연결로 인해 동작하지 않음 (app.js 이벤트 오류).

## 5. 프로젝트 구조
- `server.js`: Express 서버 및 메뉴/픽업 데이터 API
- `public/index.html`: 메인 주문 인터페이스
- `public/styles.css`: 디자인 시스템 및 레이아웃 오류 구현
- `public/app.js`: 주문 로직 및 상태 관리 오류 구현
- `BUGS.md`: 의도된 오류의 명세 및 재현 방법
