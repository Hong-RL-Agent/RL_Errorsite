# Starlight Ticket Platform (site029)

글로벌 K-POP 콘서트, 오리지널 뮤지컬, 정통 연극, 뮤직 페스티벌 티켓을 실시간으로 검색하고 스마트하게 예매할 수 있는 대중적인 라이브 티켓팅 플랫폼입니다.

## 주요 기능
- **Concert Hero Banner & Search**: 대형 공연 배너, 장르/아티스트/공연장 실시간 검색
- **공연 카테고리 & 랭킹**: 콘서트, 뮤지컬, 페스티벌, 연극 카테고리별 실시간 예매 랭킹
- **좌석 등급 & 인터랙티브 좌석 선택**: VIP/R/S/A석 좌석도 선택 및 실시간 잔여석 확인
- **티켓 장바구니 & 수량 제어**: 티켓 수량 증감, 예매수수료 및 정가 합계 자동 계산
- **프로모션 할인 쿠폰**: 스타라이트 시즌 쿠폰 적용 및 즉시 할인
- **패키지 & 연계 상품**: 한정판 MD 및 다이닝 결합 패키지 티켓팅
- **주문 요약 & 결제 모달**: 결제 수단 선택 및 전자 모바일 티켓 발권
- **마이 티켓 & 위시리스트**: 예매 내역 확인, 관심 공연 찜 관리, 회원 프로필 수정
- **1:1 고객센터 문의**: 티켓/환불/좌석 관련 실시간 문의 접수

## 기술 스택
- **Frontend**: React, Vite, Vanilla CSS (Modern Concert Theme)
- **Backend**: Express.js, CORS
- **Port**: 9928 (Vite Dev: 5176)

## 실행 방법
```bash
# 의존성 설치
npm install

# 프로덕션 빌드 & 서버 시작
npm run build
npm start
```
