# VIRTUAL-ESTATE Security Report

본 문서는 PPO 에이전트 학습 및 관제 훈련을 위한 가상 보안 사고 시뮬레이션 리포트입니다. 모든 시나리오는 폐쇄된 훈련 환경에서만 사용하는 방어 목적의 탐지 패턴입니다.

## 환경 격리

- 서비스 진입점: `http://localhost:9082`
- 프론트엔드 API 호출: `/api/...` 상대 경로
- Docker 외부 공개 포트: `9082`
- 이전 프로젝트 포트 범위의 값은 코드와 설정에 포함하지 않음

## 하이브리드 취약점 시뮬레이션 11종

1. Kerberos 토큰 탈취를 통한 Pass-the-Ticket 공격 가능 로그
   - 탐지 포인트: 티켓 재사용, 비정상 서비스 프린시펄 접근, VIP 자산 API 권한 상승
   - 권장 대응: 티켓 수명 단축, 민감 계정 재인증, SIEM 상관 분석

2. NTLM 요청을 가로채 전달하는 릴레이 공격 시나리오
   - 탐지 포인트: 동일 해시 기반의 연속 인증, SMB/HTTP 간 인증 경로 불일치
   - 권장 대응: NTLM 제한, SMB signing 강제, EPA 적용

3. 관리자 기기의 블루투스 스택 취약점에 의한 연결 징후
   - 탐지 포인트: 관리 콘솔 근처의 비인가 BLE 페어링 요청, RSSI 급상승
   - 권장 대응: 관리자 단말 Bluetooth 비활성화 정책, 페어링 로그 중앙 수집

4. KRACK 공격을 통한 Wi-Fi 암호화 무력화 현상 시뮬레이션
   - 탐지 포인트: WPA2 4-way handshake 재전송, nonce 재사용 의심
   - 권장 대응: 클라이언트 패치 검증, WPA3 전환, 재전송 임계치 알림

5. 사내 망 내부에 출처 불명의 Rogue AP 발견 로그
   - 탐지 포인트: 승인되지 않은 BSSID, 사내 SSID 유사 명칭, 비정상 채널 점유
   - 권장 대응: WIDS 차단 정책, AP 위치 추적, 스위치 포트 격리

6. 서버실 센서에 기록된 비정상적인 문 열림
   - 탐지 포인트: 유지보수 창 외 문 열림, 출입 카드 이벤트 부재
   - 권장 대응: CCTV 이벤트 매칭, 현장 확인, 출입 권한 재검토

7. 인가되지 않은 인원이 출입구를 통과하는 Tailgating 탐지
   - 탐지 포인트: 단일 카드 인증 후 2명 이상 통과, 열화상 카운터 불일치
   - 권장 대응: 게이트 재인증, 보안요원 알림, 방문자 동선 확인

8. 폐기 기기에서 추출된 데이터 복구 흔적
   - 탐지 포인트: 폐기 디스크 시리얼 재등장, 스냅샷/매물 계약서 복구 흔적
   - 권장 대응: 폐기 전 암호화 삭제, 파쇄 증적 보관, 자산 반납 감사

9. 비밀번호 입력 시 외부 시선 노출 위험 경고
   - 탐지 포인트: 로비 키오스크 입력 중 근접 카메라 시야 겹침
   - 권장 대응: 프라이버시 필터, 가림막, OTP/패스키 전환

10. 회의실 음성 데이터 변조 및 도청 장치 신호 포착
   - 탐지 포인트: 회의실 RF 스펙트럼 이상, 음성 파일 해시 불일치
   - 권장 대응: RF sweep, 회의실 장비 무결성 검사, 민감 회의 녹취 통제

11. 유리창 진동 감지를 통한 레이저 마이크 도청 시뮬레이션
   - 탐지 포인트: 창면 진동 패턴과 외부 레이저 반사 이벤트 상관성
   - 권장 대응: 방진 필름, 회의실 white noise, 외부 시야 차폐

## 대시보드 반영 항목

- 네트워크 인증 공격: Pass-the-Ticket, NTLM Relay
- 무선 공격: Bluetooth stack anomaly, KRACK, Rogue AP
- 물리 보안: 서버실 문 열림, Tailgating, Shoulder Surfing
- 정보 유출: Dumpster Diving, Bugging, Laser Microphone

## 운영 메모

대시보드는 실제 공격 실행 기능을 포함하지 않습니다. 모든 항목은 훈련용 로그, 점수화, 탐지 힌트, 대응 가이드로 구성되어 있습니다.
