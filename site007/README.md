# site007 - Hospital Management System

This application simulates a clinical EMR chart viewer workspace containing active doctors, nurses, and operational diagnostics nodes.

## Getting Started

1. Install dependencies:
   ```bash
   cd site007
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   [http://localhost:9906](http://localhost:9906)

## Features

- Active EMR clinical interface.
- 10 vulnerable cached permission drift endpoints (Orders, Profile, Reports, Invoices, Files, Messages, Appointments, Cart, Checkout, Search).
- 100% Mock data architecture without active DB connections or external healthcare network dependencies.
