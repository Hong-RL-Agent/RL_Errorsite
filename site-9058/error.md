# [PROJECT J.A.W.S] 포트 9058: AI-RECRUITER 시스템 및 비즈니스 결함 리포트

본 문서는 PPO 에이전트 학습을 위한 AI 면접 시스템(AI-RECRUITER)의 의도적 시스템/UX 결함 11종을 정의합니다.

## 1. GPU P2P 통신 데드락 (GPU P2P Deadlock)
- **현상**: 면접자의 표정 분석을 위해 두 개 이상의 GPU가 직접 통신(P2P)할 때, 자원 점유 순서가 꼬여 시스템이 무한 대기에 빠짐.
- **영향**: 영상 분석 기능 중단.

## 2. 메모리 내부 파편화와 유령 누수 (Ghost Leak)
- **현상**: 분석 객체 할당 시 실제 데이터보다 훨씬 큰 메모리 블록을 할당하여, 겉으로는 가용 메모리가 많아 보이지만 실제로는 할당이 실패함.
- **영향**: 원인 불명의 메모리 부족 오류 발생.

## 3. 스펙큘러 실행 패치 IPC 하락 (Speculative Execution Patch)
- **현상**: 사이드 채널 공격 방어 패치(Spectre 등)로 인해 CPU의 명령어 처리 속도(IPC)가 인위적으로 하락함.
- **영향**: AI 추론 연산의 전반적인 속도 저하.

## 4. 메모리 TRR에 의한 대역폭 잠식 (TRR Bandwidth Poaching)
- **현상**: Rowhammer 공격 방어를 위한 TRR(Target Row Refresh) 로직이 빈번하게 실행되어 메모리 버스 대역폭을 점유함.
- **영향**: 대량의 데이터 로딩 시 병목 발생.

## 5. GPU 레지스터 파일 부족 및 점유율 하락 (Occupancy Drop)
- **현상**: 복잡한 AI 모델이 GPU의 레지스터를 과도하게 점유하여, 동시에 실행될 수 있는 스레드 수가 줄어듦.
- **영향**: GPU 하드웨어 자원의 효율성 급락.

## 6. 비결정적 테일 레이턴시 (Tail Latency)
- **현상**: 평균 응답 속도는 빠르지만, 1%의 요청이 네트워크 스택 병목으로 인해 비정상적으로 늦게 처리됨.
- **영향**: 간헐적인 면접 끊김 현상 발생.

## 7. 고성능 기기 및 최신 OS 강요 (OS Lock-in)
- **현상**: 하위 호환성을 무시하고 특정 최신 OS 버전과 고성능 기기에서만 사이트가 열리도록 체크 로직 구현.
- **영향**: 범용성 상실 및 특정 환경 외 접근 차단.

## 8. 오프라인 모드 미지원 (No Offline Support)
- **현상**: 일시적인 네트워크 불안정 시 로컬에 임시 저장하는 기능이 없어 면접 데이터가 즉시 소실됨.
- **영향**: 사용자 데이터 손실 위험.

## 9. 특정 결제 수단 강요 (Forced Payment Method)
- **현상**: 일반적인 신용카드나 간편결제를 막고, 특정 암호화폐나 제휴 포인트로만 결제 가능하도록 로직 고정.
- **영향**: 결제 접근성 저해.

## 10. 고가 기기 전용 기능 (High-end Only Features)
- **현상**: 기술적으로 충분히 가능한 기능임에도 하드웨어 식별 번호를 확인하여 저가형 기기에서는 비활성화 처리함.
- **영향**: 기기 사양에 따른 차별적 서비스 제공.

## 11. 환경 변수 주입 실패 (Env Var Injection Failure)
- **현상**: 도커 컨테이너 실행 시 필요한 핵심 설정값(API Key 등)이 환경 변수 주입 과정에서 누락됨.
- **영향**: 시스템 초기화 실패 및 런타임 에러.
