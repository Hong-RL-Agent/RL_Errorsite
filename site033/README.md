# OTT 영화 스트리밍 메인 - 로직 엣지 케이스 탐지 환경 (Site033)

이 사이트는 영화 스트리밍 플랫폼으로 위장한 **백엔드 로직의 언어적/타입적/런타임 결함 탐지 학습 환경**입니다. 
PPO 강화학습 에이전트는 유니코드 처리, 타입 불일치로 인한 정렬 오류, 런타임 예외 발생 시의 Fallback 동작, 그리고 테스트 코드의 부작용을 식별해야 합니다.

## 🛠 기술 스택
- **Frontend**: React + Vite + Lucide React + Framer Motion
- **Backend**: Express (Node.js)
- **Port**: 9142 (Frontend) / 9146 (Backend)

## 🚀 실행 방법
```bash
cd site033
npm install
npm start
```

## 📡 API 엔드포인트
- `GET /api/health`: 서비스 상태 확인
- `GET /api/movies`: 영화 목록 조회 (Bug 01 트리거 가능)
- `GET /api/movies/popular`: 인기 영화 조회 (Bug 02 트리거)
- `GET /api/movies/:id`: 영화 상세 조회 (Bug 03 트리거 가능)
- `POST /api/watch`: 영화 시청 기록 저장
- `GET /api/test/mutate`: 테스트용 데이터 변조 API (Bug 04 트리거)

## ❗ 의도된 백엔드 오류

### 1. [site033-bug01] language-edge-case (언어 문법 엣지 케이스)
- **설명**: 유니코드(é 등)나 대소문자 처리가 불완전하여 특정 검색어 입력 시 결과가 누락됩니다.
- **트리거**: 검색창에 `é` 입력 또는 대소문자가 섞인 검색 수행

### 2. [site033-bug02] type-system-error (타입 시스템 오류)
- **설명**: 평점(rating) 데이터가 숫자와 문자열이 섞여 있어, 인기순 정렬 시 기대와 다른 결과가 나타납니다.
- **트리거**: "대세 콘텐츠" 탭 진입 또는 "정렬 기준 확인" 클릭

### 3. [site033-bug03] runtime-behavior-error (런타임 특성 오류)
- **설명**: 존재하지 않는 ID 요청 시 내부에서 정의되지 않은 프로퍼티에 접근하려다 에러가 발생하며, 서버는 죽지 않고 Fallback 데이터를 반환합니다.
- **트리거**: "테스트 랩" 탭에서 "런타임 예외 처리 테스트" 클릭

### 4. [site033-bug04] test-side-effect (관련 없는 테스트 영향)
- **설명**: 테스트용으로 만들어진 API가 실제 운영용 영화 평점 데이터를 무작위로 변경하는 부작용을 일으킵니다.
- **트리거**: "테스트 랩" 탭에서 "테스트 실행" 클릭

## 🤖 PPO 학습 목표
- 유니코드 및 대소문자 감수성 부족으로 인한 데이터 누락 식별
- 동적 타이핑 언어의 타입 혼용으로 인한 정렬 로직 결함 발견
- 런타임 에러 발생 시의 비정상적인 Fallback 응답 패턴 인식
- 격리되지 않은 테스트 환경이 운영 데이터에 미치는 영향 분석
