# FreshBox - 신선한 도시락 주문 서비스 (site066)

전문 영양사가 설계한 건강한 도시락을 편리하게 주문할 수 있는 푸드 커머스 플랫폼입니다. 직관적인 필터 시스템과 실시간 주문 요약 기능을 제공하며, 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위한 3가지 의도적 결함이 포함되어 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site066
- **포트 번호**: 9285
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 화이트, 라임 그린, 오렌지 기반의 신선하고 활기찬 푸드 서비스 디자인

## 2. 실행 방법
```bash
cd site066
npm install
npm start
```
- 접속 주소: [http://localhost:9285](http://localhost:9285)

## 3. 주요 기능
- **메뉴 필터링**: 식단 유형(비건, 고단백 등), 칼로리별 맞춤 메뉴 검색
- **수량 조절 및 담기**: 개별 상품 수량 선택 및 실시간 장바구니 반영
- **추가 옵션 선택**: '밥 적게', '덜 맵게' 등 커스텀 옵션 제공
- **영양 정보 조회**: 모달을 통한 상세 영양 성분(탄단지, 나트륨) 확인
- **정기 배송 가이드**: 아코디언 형태의 배송 서비스 FAQ 제공

## 4. 의도된 프론트엔드 GUI 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **옵션 요약 중복 (site066-bug01)**: '밥 적게' 옵션을 선택하면 주문 요약 영역에 해당 옵션이 두 번 표시됨.
2. **Sticky Cart 레이아웃 침범 (site066-bug02)**: 우측 주문 요약 패널이 중앙 상품 리스트 영역을 덮어 클릭을 방해함.
3. **주문 확인 버튼 무반응 (site066-bug03)**: '주문 확인' 버튼 클릭 시 이벤트 리스너 미연결로 인해 아무런 동작을 하지 않음.

## 5. 프로젝트 구조
- `server.js`: 도시락 메뉴 및 영양 정보를 제공하는 Express 서버
- `public/index.html`: 메인 푸드 커머스 레이아웃
- `public/styles.css`: 신선한 테마 스타일 및 레이아웃 결함 구현
- `public/app.js`: 필터링, 장바구니 로직 및 데이터/이벤트 결함 구현
