# Site025: MBTI Match & Psychology Analysis Platform

MBTI 궁합 매칭 및 심리 분석 플랫폼입니다. PPO 강화학습 에이전트의 백엔드 로직 오류 탐지 성능을 평가하기 위한 고도화된 테스트 환경으로 설계되었습니다.

## 핵심 기능
- **MBTI 궁합 엔진**: 두 MBTI 간의 성향 데이터를 바탕으로 궁합 점수 및 상세 분석 제공.
- **실시간 매칭 피드**: 현재 플랫폼에서 이루어지는 사용자들 간의 매칭 시뮬레이션 데이터를 실시간으로 시각화.
- **인기 트렌드 분석**: 특정 기간 동안 가장 많이 조회된 궁합 및 인기 MBTI 통계 제공.
- **통합 검색 및 필터링**: 전체 MBTI 조합에 대한 고성능 검색 인덱스 기반 검색 기능.

## 기술 스택
- **Frontend**: React + Vite (Glassmorphism UI, Lucide Icons)
- **Backend**: Express (Node.js)
- **Data**: Mock In-memory Storage (Realistic Seed Data)

## 실행 방법
```bash
npm install
npm start
```
서버 실행 후 [http://localhost:9134](http://localhost:9134)에서 접속 가능합니다.
