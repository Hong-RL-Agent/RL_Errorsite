# CinePulse - 영화 리뷰 & 평점 커뮤니티 (site054)

전문적인 시네마 매거진 스타일의 영화 리뷰 및 평점 공유 웹사이트입니다. 강화학습(PPO) 에이전트의 GUI 오류 탐지 역량 강화를 위한 고품질 학습 데이터셋으로 제작되었습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site054
- **포트 번호**: 9273
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 다크 네이비 / 골드 / 블랙 기반의 프리미엄 시네마 UI

## 2. 실행 방법
```bash
cd site054
npm install
npm start
```
- 접속 주소: [http://localhost:9273](http://localhost:9273)

## 3. 주요 기능
- **영화 브라우징**: 장르별 필터링 및 제목 검색이 가능한 영화 라이브러리
- **상세 정보**: 영화 줄거리 및 메타데이터를 확인할 수 있는 상세 모달
- **리뷰 커뮤니티**: 실시간 평점 부여 및 사용자 리뷰 리스트 조회 (정렬 기능 지원)
- **정보성 섹션**: 실시간 박스오피스 순위 및 인기 평론가 소개
- **피드백 시스템**: 미구현 기능 클릭 시 "준비 중입니다" alert 제공

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **별점 표시 오류 (site054-bug01)**: 실제 평점 데이터보다 별 1개가 더 많이 채워져 렌더링됨 (로직 오류).
2. **리뷰 카드 overflow (site054-bug02)**: 긴 단어가 포함된 리뷰가 카드 영역을 벗어나 우측 패널 아래로 겹침 (레이아웃 오류).
3. **리뷰 등록 버튼 무반응 (site054-bug03)**: 버튼의 ID와 코드 내 셀렉터가 불일치하여 등록 동작이 수행되지 않음 (이벤트 오류).

## 5. 프로젝트 구조
- `server.js`: 영화 및 리뷰 데이터를 제공하는 Express API 서버
- `public/index.html`: 메인 대시보드 및 리뷰 시스템 레이아웃
- `public/styles.css`: 시네마 테마 스타일 및 텍스트 오버플로우 오류 구현
- `public/app.js`: 데이터 처리 및 별점 렌더링/버튼 리스너 오류 구현
- `BUGS.md`: 의도된 오류의 상세 명세 및 재현 경로
