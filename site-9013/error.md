🔍 Site #9013 장애 포인트 정리
비즈니스 리소스 임대 유기 (Lease Abandonment):

사용자가 Leave를 눌러 회의실에서 나갔음에도, 백엔드의 meetingSessions 배열에서 해당 객체가 삭제되지 않습니다.

점진적 메모리 고갈 (Memory Leak):

방 하나가 만들어질 때마다 createHeavyResource()를 통해 큰 메모리 덩어리가 할당됩니다. Leave를 반복할수록 서버의 memory_usage 수치가 계속 올라가며, 결국 서버가 죽게 됩니다.

에이전트 훈련 목표:

에이전트는 "현재 접속자 수는 0인데, 서버 메모리 사용량은 왜 계속 증가하고 세션 카운트는 왜 안 줄어들까?"라는 모순을 발견해야 합니다.
