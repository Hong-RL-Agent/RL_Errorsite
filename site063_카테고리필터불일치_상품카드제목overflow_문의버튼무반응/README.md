# 당근마켓 - 지역 기반 중고거래 플랫폼 (site063)

이웃과 함께하는 따뜻한 중고거래 마켓 웹사이트입니다. 친근한 오렌지 테마의 UI와 함께, 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위한 3가지 의도적 결함이 포함되어 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site063
- **포트 번호**: 9282
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 화이트, 오렌지, 크림 기반의 친근한 커뮤니티 디자인

## 2. 실행 방법
```bash
cd site063
npm install
npm start
```
- 접속 주소: [http://localhost:9282](http://localhost:9282)

## 3. 주요 기능
- **중고 매물 리스트**: 지역별, 카테고리별 매물 조회 및 검색
- **지역 필터링**: 내가 설정한 동네의 매물만 필터링하여 확인
- **매물 상세 정보**: 모달을 통한 상품 상세 이미지 및 설명 확인
- **문의하기**: 채팅을 통해 이웃과 실시간으로 거래 상담 가능
- **인기 키워드 및 가이드**: 동네 인기 검색어와 안전 거래 가이드 제공

## 4. 의도된 프론트엔드 GUI 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **카테고리 필터 불일치 (site063-bug01)**: '가전/디지털' 카테고리 선택 시 '가구' 매물이 섞여서 출력됨.
2. **상품 카드 제목 오버플로우 (site063-bug02)**: 매우 긴 상품명이 카드 영역을 벗어나 우측 패널 침범.
3. **특정 매물 문의 버튼 무반응 (site063-bug03)**: '에어팟 프로' 매물의 문의하기 버튼을 클릭해도 아무런 반응이 없음.

## 5. 프로젝트 구조
- `server.js`: 매물 및 지역 데이터를 제공하는 Express 서버
- `public/index.html`: 메인 마켓 플레이스 레이아웃
- `public/styles.css`: 오렌지 테마 스타일 및 레이아웃 오버플로우 오류 구현
- `public/app.js`: 데이터 페칭, 검색/필터 로직 및 기능 결함 구현
