# site003 - Enterprise Collaboration Workspace Admin Portal

This is a SaaS control dashboard designed for workspace administrators to supervise project assets, data synchronization, user groups, system diagnostics, and background worker queues.

## Getting Started

1. Install dependencies:
   ```bash
   cd site003
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   [http://localhost:9902](http://localhost:9902)

## Features

- Control panel summary statistics.
- 11 access control verification endpoints (Exports, Imports, Documents, Teams, Roles, Audit Logs, Subscriptions, Devices, API Keys, Webhooks, Jobs).
- Manual code diagnostic panel mapping logic.
- 100% Mock telemetry without actual cloud services or databases.
