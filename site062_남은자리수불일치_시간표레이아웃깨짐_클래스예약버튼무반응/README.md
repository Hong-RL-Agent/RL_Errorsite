# ZenSpace Yoga - 요가 클래스 예약 플랫폼 (site062)

몸과 마음의 균형을 찾는 요가 클래스 예약 웹사이트입니다. 고품질의 웰니스 브랜드 디자인과 함께, 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위한 3가지 의도적 결함이 포함되어 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site062
- **포트 번호**: 9281
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 세이지 그린, 화이트, 라이트 베이지 기반의 차분한 웰니스 테마

## 2. 실행 방법
```bash
cd site062
npm install
npm start
```
- 접속 주소: [http://localhost:9281](http://localhost:9281)

## 3. 주요 기능
- **클래스 예약 시스템**: 실시간 잔여 좌석 확인 및 클래스 선택
- **정교한 필터링**: 난이도 및 강사별 클래스 맞춤 검색
- **주간 시간표**: 요일별 수업 일정을 확인하는 탭 기반 인터페이스
- **예약 요약 패널**: 선택한 클래스의 정보와 잔여 인원 실시간 요약
- **멤버십 FAQ**: 아코디언 기반의 자주 묻는 질문 답변

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **남은 자리 수 불일치 (site062-bug01)**: 클래스 카드의 잔여석 수치와 예약 요약 패널의 수치가 서로 다르게 표시됨.
2. **시간표 레이아웃 깨짐 (site062-bug02)**: 주간 시간표의 마지막 열이 우측 영역에 가려지거나 잘리는 현상.
3. **특정 클래스 예약 버튼 무반응 (site062-bug03)**: 'Morning Vinyasa' 클래스의 예약 버튼을 클릭해도 아무런 반응이 없음.

## 5. 프로젝트 구조
- `server.js`: 클래스 및 강사 데이터를 제공하는 Express 서버
- `public/index.html`: 메인 대시보드 레이아웃
- `public/styles.css`: 웰니스 테마 스타일 및 레이아웃 오류 구현
- `public/app.js`: 예약 로직, 필터링 및 상태 오류 구현
