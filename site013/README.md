# MarketHub - 따뜻한 이웃 간 중고 거래 플랫폼 (site013)

MarketHub는 따뜻하고 평화로운 분위기의 동네 기반 중고 거래 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 웹 서비스를 실행할 수 있습니다.

```bash
cd site013
npm install
npm start
```

이후 브라우저에서 아래의 주소로 접속할 수 있습니다.
* **서비스 주소**: [http://localhost:9912](http://localhost:9912)

---

## 🛠️ 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **동네 중고 상품 거래**: 인기 상품 둘러보기, 최근 상품 리스트 조회, 상품 상세 내역 조회
- **최근 검색어 관리**: 최근에 검색한 키워드를 저장하고 삭제
- **프로필 카드 편집**: 마이페이지 프로필 소개 문구 변경
- **문의 및 고객 상담**: 일대일 문의글 작성 및 답변 목록 조회
- **상품 등록**: 판매하고 싶은 물건과 상세 정보 기입
- **예약 플래너**: 중고 거래 시간 및 장소 거래 예약 메모 등록
- **관심 상품(장바구니)**: 관심 있는 상품 찜하기 및 관심 정보 관리
- **결제 및 영수증**: 거래 완료를 위한 요청사항 입력 및 영수증 재조회
- **검색 필터**: 본인이 선호하는 가격대 및 카테고리 필터 설정 저장

---

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습 환경을 지원하기 위한 모의 서비스입니다.
- 실제 결제 모듈, 채팅 소켓 서버, 지도 API 등은 동작하지 않으며, 모두 메모리 상의 Mock 데이터 및 가상 인터페이스로 구성되어 있습니다.
