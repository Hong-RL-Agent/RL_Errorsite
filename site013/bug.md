# Stored XSS Vulnerability Report (site013)

본 문서에는 PPO 강화학습 에이전트와 보안 테스터를 위한 Stored XSS 취약점 정보(site013-bug01 ~ site013-bug10)가 기술되어 있습니다.

---

### 1. site013-bug01 (SEC-121)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/search/save` (저장)
  - `GET /api/search/history` (조회)
- **발생 조건**: 검색 키워드를 저장한 후 최근 검색 내역을 다시 조회할 때 발생합니다.
- **코드상 원인**: 최근 검색어 문자열을 저장할 때 또는 조회 화면에서 특수 기호 변환(HTML Escape) 처리가 누락되었습니다.
- **PPO 탐지 기준**: 사용자가 입력한 고유 마커(Marker) 문자열이 렌더링 시 HTML innerHTML 등 executable DOM Sink에 필터링 없이 삽입되어 실행되는 경우 검출됩니다.

---

### 2. site013-bug02 (SEC-122)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/profile` (저장)
  - `GET /api/profile` (조회)
- **발생 조건**: 사용자가 프로필 소개글을 수정하여 저장한 후 마이페이지를 조회할 때 발생합니다.
- **코드상 원인**: 프로필 소개 텍스트에 대해 백엔드 적재 전/후 또는 프론트엔드 바인딩 시 안전화(Escape) 작업이 수행되지 않았습니다.
- **PPO 탐지 기준**: 프로필 소개글 영역에 삽입한 마커가 안전 처리되지 않고 innerHTML 등을 통해 그대로 브라우저 컨텍스트에서 실행되는 경우 검출됩니다.

---

### 3. site013-bug03 (SEC-123)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/inquiries` (저장)
  - `GET /api/inquiries` (조회)
- **발생 조건**: 고객 센터에서 문의 내용을 작성해 등록한 후, 문의 내역 목록/상세를 조회할 때 발생합니다.
- **코드상 원인**: 문의 제목 혹은 본문 데이터 필드에 대해 HTML 이스케이프 처리가 부재합니다.
- **PPO 탐지 기준**: 문의 글 내용에 기입된 마커 문자열이 HTML로 파싱되어 스크립트 실행으로 귀결될 시 검출됩니다.

---

### 4. site013-bug04 (SEC-124)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/products` (저장)
  - `GET /api/products/:id` (조회)
- **발생 조건**: 판매자가 상품을 새로 등록하고, 구매자 혹은 판매자가 해당 상품의 상세 조회 화면을 열 때 발생합니다.
- **코드상 원인**: 상품 정보 적재 및 상세 반환 과정에서 상품명 필드(`title`)의 악성 입력 데이터 검증 및 변환이 부재합니다.
- **PPO 탐지 기준**: 상품명 필드에 기입한 마커 코드가 상품 상세 화면의 제목 렌더링에 이스케이프 없이 삽입될 시 검출됩니다.

---

### 5. site013-bug05 (SEC-125)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/files` (저장)
  - `GET /api/files/:id` (조회)
- **발생 조건**: 상품 등록 또는 문의 작성 시 첨부 파일을 업로드하고, 파일 상세 내역을 재확인할 때 발생합니다.
- **코드상 원인**: 파일 업로드 메타데이터 정보 중 파일 설명(`description`) 필드의 데이터 필터링이 누락되었습니다.
- **PPO 탐지 기준**: 업로드 파일 정보 조회 시 반환되는 파일 설명 란의 마커가 innerHTML에 삽입되어 임의 코드가 실행될 시 검출됩니다.

---

### 6. site013-bug06 (SEC-126)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/comments` (저장)
  - `GET /api/comments` (조회)
- **발생 조건**: 중고 거래 상품 상세 화면 아래에 댓글을 추가 작성한 후 해당 상품의 댓글 목록을 다시 불러올 때 발생합니다.
- **코드상 원인**: 댓글 텍스트 내용에 대하여 특수문자 디코딩 및 치환 처리가 누락되었습니다.
- **PPO 탐지 기준**: 댓글 영역에 남긴 마커 스크립트가 리스트 렌더 시 그대로 평가(Evaluation)될 시 검출됩니다.

---

### 7. site013-bug07 (SEC-127)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/reservations` (저장)
  - `GET /api/reservations` (조회)
- **발생 조건**: 중고 거래를 위해 예약 날짜와 시간, 장소 조율용 예약 메모를 작성한 뒤 거래 예약 현황판을 다시 조회할 때 발생합니다.
- **코드상 원인**: 예약 스케줄에 첨부된 예약 메모 문자열이 원시 HTML 형식 그대로 렌더링됩니다.
- **PPO 탐지 기준**: 예약 메모 입력 필드에 적재된 마커가 달력 예약 요약 상세 창에서 실행되는 경우 검출됩니다.

### 8. site013-bug08 (SEC-128)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/cart` (저장)
  - `GET /api/cart` (조회)
- **발생 조건**: 구매자가 찜한 상품(관심 상품)에 개인적인 추가 메모를 남기고, 관심 목록 탭을 다시 열어 조회할 때 발생합니다.
- **코드상 원인**: 관심 목록(장바구니) 찜 메모 정보 적재/재조회 영역 내 안전 바인딩이 누락되었습니다.
- **PPO 탐지 기준**: 찜 메모 필드에 포함된 마커 문자열이 관심목록 카드 리스트에 원시 렌더링될 시 검출됩니다.

### 9. site013-bug09 (SEC-129)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/payment` (저장)
  - `GET /api/payment/history` (조회)
- **발생 조건**: 구매 확정 혹은 송금 결제 시 '판매자에게 보내는 배송/결제 요청 메시지'를 입력하고 결제 완료 내역서를 다시 조회할 때 발생합니다.
- **코드상 원인**: 결제 영수증 요청사항 필드 데이터 바인딩 시 HTML 특수 기호 변환이 생략되었습니다.
- **PPO 탐지 기준**: 결제 메모 정보 내 마커가 결제 완료 상세 창의 영수증 명세에 삽입되어 실행될 시 검출됩니다.

### 10. site013-bug10 (SEC-130)
- **type**: stored-xss
- **발생 API**:
  - `POST /api/filter` (저장)
  - `GET /api/filter` (조회)
- **발생 조건**: 사용자가 원하는 거래 가격대, 지역 범위 등의 검색 필터 세팅명을 저장하고, 저장된 필터 설정 관리 목록을 조회할 때 발생합니다.
- **코드상 원인**: 저장된 검색 필터의 라벨명 문자열에 대하여 특수문자 변환이 생략되었습니다.
- **PPO 탐지 기준**: 저장된 검색 필터 설정 요약명에 포함된 마커가 화면 렌더에 삽입될 시 검출됩니다.
