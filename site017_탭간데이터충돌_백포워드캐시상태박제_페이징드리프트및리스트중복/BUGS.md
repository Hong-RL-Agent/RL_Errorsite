# 의도된 프론트엔드 오류 목록 (site017)

이 문서에는 PPO 에이전트가 탐지해야 할 3가지 의도된 GUI 오류가 기록되어 있습니다.

---

### 1. 탭 간 데이터 충돌 (Bug ID: site017-bug01)
- **CSV 오류명**: 탭 간 데이터 충돌
- **유형**: `frontend-state-rendering`
- **화면 위치**: 의사 상세 페이지 > 예약 전 전달사항 (초안) 입력란
- **관련 파일**: `src/App.jsx`
- **Selector**: `[data-bug-id="site017-bug01"] textarea`
- **증상**: 탭 A에서 초안을 작성 중인데, 다른 탭 B에서 초안을 저장하거나 수정하면 탭 A의 입력 내용이 탭 B의 내용으로 강제 교체됨.
- **원인**: `localStorage`의 `storage` 이벤트 리스너가 현재 탭의 입력 포커스나 변경 여부를 고려하지 않고 전역 상태를 무조건 덮어씌움.
- **기대 행동**: 현재 활성화된 탭의 입력을 우선하거나, 충돌 발생 시 사용자에게 알림을 주어야 함.

### 2. 백포워드 캐시 상태 박제 (Bug ID: site017-bug02)
- **CSV 오류명**: 백포워드 캐시 상태 박제
- **유형**: `frontend-state-rendering`
- **화면 위치**: 의사 상세 페이지 전체
- **관련 파일**: `src/App.jsx`
- **Selector**: `[data-bug-id="site017-bug02"]`
- **증상**: 의사 A를 클릭해 상세 페이지를 본 후, 목록으로 돌아갔다가 다시 의사 B를 클릭했을 때, 잠깐 동안 의사 A의 정보가 남아있거나 뒤로가기 시 엉뚱한 의사의 상세 정보가 표시됨.
- **원인**: `sessionStorage`에 저장된 `last_viewed_doctor`를 URL 매칭 없이 컴포넌트 마운트 시점에 강제로 상태에 주입함.
- **기대 행동**: 진입한 경로(ID)에 맞는 데이터를 새롭게 Fetch하거나 상태를 초기화해야 함.

### 3. 페이징 드리프트 및 리스트 중복 (Bug ID: site017-bug03)
- **CSV 오류명**: 페이징 드리프트 및 리스트 중복
- **유형**: `frontend-state-rendering`
- **화면 위치**: 의사 찾기 페이지 > 전문의 리스트 하단
- **관련 파일**: `src/App.jsx`
- **Selector**: `[data-bug-id="site017-bug03"]`
- **증상**: '더 많은 의사 보기' 버튼을 클릭하면 리스트 하단에 이전에 이미 보였던 의사 카드가 다시 나타남 (중복 노출).
- **원인**: `fetchDoctors` 함수에서 새 데이터를 기존 데이터와 병합할 때, 오프셋 계산 실수(의도적 `slice(-2)`)로 인해 이전 페이지의 마지막 항목이 포함됨.
- **기대 행동**: 리스트에 중복된 고유 ID를 가진 카드가 존재하지 않아야 함.
