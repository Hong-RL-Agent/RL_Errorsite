# FoodSpot - Restaurant Review & Reservation Platform (site010)

FoodSpot은 사용자가 맛집을 탐색하고 예약, 리뷰 작성, 장바구니 주문 및 결제 프로세스를 경험할 수 있는 고성능 맛집 예약 및 리뷰 플랫폼 시뮬레이터입니다.

---

## 🛠️ 기술 스택 (Technology Stack)

* **프론트엔드 (Frontend)**: React + Vite + Vanilla CSS
* **백엔드 (Backend)**: Express (Node.js)
* **포트 번호 (Port)**: `9909`

---

## 🚀 실행 방법 (Execution Instructions)

아래 명령어를 사용하여 의존성을 설치하고 서비스를 실행할 수 있습니다.

```bash
# 1. 프로젝트 폴더로 이동
cd site010

# 2. 패키지 의존성 설치
npm install

# 3. 전체 프로젝트 빌드 및 실행 (Express에서 React 빌드 결과 자동 제공)
npm start
```

실행이 완료되면 브라우저에서 아래 주소로 접속 가능합니다.
* **로컬 접속 주소**: [http://localhost:9909](http://localhost:9909)

---

## ✨ 주요 기능 (Key Features)

1. **맛집 탐색 및 검색**: 카테고리별 맛집 필터링 및 이름 검색 기능 제공.
2. **상세 예약 관리**: 예약 인원, 날짜, 요청 사항(예약 메모)을 작성하고 요약본 미리보기 기능 제공.
3. **사용자 프로필 편집**: 사용자 자기소개 글 편집 및 미리보기 제공.
4. **리뷰 및 피드백 작성**: 댓글 작성, 맛집 리뷰 등록, 사진 및 캡션 업로드 미리보기 기능 제공.
5. **장바구니 및 모의 주문**: 맛집 메뉴를 장바구니에 담고, 맞춤 요청 메모를 입력한 후 시뮬레이션 결제 단계 실행.
6. **고객 센터 문의**: 관리자에게 다이렉트 문의 접수 및 문의 미리보기 제공.
7. **다양한 사용자 역할 시뮬레이션**: 관리자(Admin), 점주(Owner), 일반 고객(Customer) 간의 역할 스위칭 기능 제공.

---

## ⚠️ 안내 사항 (Notice)

* 본 서비스는 **Mock 데이터 및 모의 API**로만 작동합니다.
* 실제 데이터베이스(DB), 지도 API, 결제 대행사(PG) API, 예약 연동 시스템 등 외부 유료 API는 일절 사용하지 않으며 메모리 내 데이터로 시뮬레이션됩니다.
