# Nexus Events - 프리미엄 컨퍼런스 & 행사 관리 플랫폼 (site020)

Nexus Events는 세련된 Purple, Sky Blue, Dark Navy 톤의 프리미엄 컨퍼런스 및 행사 관리 대시보드 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 서비스를 구동할 수 있습니다.

```bash
cd site020
npm install
npm run build   # (선택) 프로덕션 빌드 빌드 시
npm start       # Express 서버 실행 (기본 포트: 9919)
```

이후 브라우저에서 아래의 주소로 접속 가능합니다.
* **서비스 주소**: [http://localhost:9919](http://localhost:9919)

---

## 🎨 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **통합 행사 대시보드**: 통계 카드, 참여 현황, 실시간 공지 패널 제공
- **행사 목록 & 검색 자동완성**: 카테고리별 필터 및 똑똑한 실시간 자동완성 검색 기능
- **일정 캘린더**: 월별 행사 스케줄 확인 및 일정 상세 등록 기능
- **태그 관리 포털**: 행사 분류 태그 동적 할당 및 삭제 관리
- **참가 초대 & 알림 센터**: 참석자 대상 초대장 발송 및 실시간 알림 기능
- **운영 리포트 & 통계 필터**: 날짜 및 카테고리별 가상 통계 리포트 다운로드 및 필터 조회
- **CSV 대량 참가자 등록**: 엑셀 및 CSV 형식을 이용한 대량 등록 히스토리 기능
- **API 쿼리 콘솔**: 시스템 연동 테스트를 위한 가상 쿼리 실행기

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습(PPO) 에이전트의 취약점 동적 분석 탐지 학습을 위해 구축된 환경입니다.
