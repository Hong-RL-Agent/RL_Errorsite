# NeonFit - 프리미엄 스마트 피트니스 플랫폼 (site019)

NeonFit은 블랙, 네온 그린, 다크 그레이 컬러를 조합하여 강렬하고 스포티한 분위기를 자아내는 프리미엄 운동 관리 및 PT 회원권 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 서비스를 구동할 수 있습니다.

```bash
cd site019
npm install
npm start
```

이후 브라우저에서 아래의 주소로 접속 가능합니다.
* **서비스 주소**: [http://localhost:9918](http://localhost:9918)

---

## 🎨 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **PT 프로그램 맞춤 필터링**: Diet, Strength, Body 등 체력 감량 카테고리 필터링 및 만족도 순 정렬
- **회원 통합 로그인 & 가입**: 예비 회원 계정 로그인 및 가입 시스템
- **주소지 및 프로모션 쿠폰**: 개인 라커 배송지 설정 및 신년 맞이 바디프로필 할인 쿠폰 등록
- **식단 및 칼로리 명세 보관함**: 식단 서류 설명 등록 및 관리 포털
- **1:1 수석 코치 대화**: 담당 트레이너 실시간 견적 상담 메시지 기입
- **공지사항 상세 검색**: 신년 챌린지 상금 이벤트 및 단축 운영 공지사항 검색
- **실시간 상담 스케줄 캘린더**: 실시간 상담 날짜 예약 및 일정 시뮬레이션
- **고객 생생 이용 리뷰**: 실제 피트니스 이용 만족도 후기 작성

---

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습 환경을 지원하기 위한 모의 피트니스 멤버십 서비스입니다.
- 실제 결제 승인, 캘린더 연동, 문자 인증 API 등은 동작하지 않으며, 메모리 상의 Mock 데이터 및 가상 인터페이스로 구성되어 있습니다.
