# PackMate - 여행 짐 체크리스트 (site059)

여행 준비의 시작부터 끝까지, 빠짐없이 짐을 챙길 수 있도록 돕는 여행 패킹 플래너 웹사이트입니다. 직관적인 3컬럼 레이아웃과 템플릿 기반의 체크리스트를 제공하며, 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위해 의도적인 결함이 포함되어 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site059
- **포트 번호**: 9278
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 스카이블루 / 샌드베이지 / 네이비 기반의 여행 도구 UI

## 2. 실행 방법
```bash
cd site059
npm install
npm start
```
- 접속 주소: [http://localhost:9278](http://localhost:9278)

## 3. 주요 기능
- **스마트 템플릿**: 여행 유형(여름 바다, 겨울 스키, 출장 등)에 맞는 준비물 자동 생성
- **진행률 대시보드**: 전체 항목 중 준비 완료된 항목을 실시간 퍼센트로 시각화
- **카테고리별 분류**: 필수 서류, 전자기기, 의류 등 체계적인 3컬럼 리스트 관리
- **추천 아이템**: 여행 전문가들이 추천하는 필수 아이템 태그를 클릭해 즉시 추가
- **공유 기능**: 완성된 체크리스트를 고유 링크로 공유 (Mock)

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **완료 개수 불일치 (site059-bug01)**: 체크된 항목 수보다 대시보드에 표시되는 완료 수가 1개 적게 나타남.
2. **체크리스트 컬럼 깨짐 (site059-bug02)**: 화면 너비 축소 시 컬럼 간 `min-width` 충돌로 레이아웃이 겹침.
3. **항목 추가 버튼 무반응 (site059-bug03)**: 코드 내 버튼 선택자(ID) 불일치로 인해 '추가' 버튼이 작동하지 않음.

## 5. 프로젝트 구조
- `server.js`: 체크리스트 데이터 및 템플릿 정보를 제공하는 Express API 서버
- `public/index.html`: 여행 플래닝 메인 대시보드 레이아웃
- `public/styles.css`: 3컬럼 레이아웃 및 여행 테마 스타일 가이드
- `public/app.js`: 체크리스트 상태 관리, 진행률 계산 및 의도된 오류 로직
- `BUGS.md`: 의도된 오류의 상세 명세 및 재현 경로
