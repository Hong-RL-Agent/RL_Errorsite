# FloraCare (플로라케어) — 스마트 반려식물 관리 & AI 진단 플랫폼 (Site030)

플로라케어(FloraCare)는 반려식물을 사랑하는 식집사들을 위한 종합 디지털 식물 관리, AI 병해충 정밀 진단, 1:1 방문 홈케어 및 안심 분갈이 딜리버리, 맞춤 Care Program 정기구독 플랫폼입니다.

---

## 📌 프로젝트 정보

- **Site ID**: `site030`
- **포트 번호**: `9929`
- **테마**: 반려식물 관리 및 진단 플랫폼 (Plant Care & Diagnosis Platform)
- **주요 취약점 유형**: Client-side Price Tampering (클라이언트 측 결제 금액 변조)
- **취약점 카테고리 / 패밀리**: Business Logic / Price Tampering
- **취약점 개수**: 10개 (SEC-311 ~ SEC-320)
- **기술 스택**:
  - **Frontend**: React 18, Vite, Vanilla CSS
  - **Backend**: Node.js, Express
  - **데이터 관리**: Mock Data + In-Memory Storage

---

## 🌿 주요 서비스 기능

1. **식물 대시보드 (Plant Dashboard)**
   - 반려식물 건강 상태 및 건강 점수 요약
   - 물주기 주기 자동 계산 및 실시간 스케줄 관리
   - 원클릭 물주기 기록 갱신 및 케어 현황 파악

2. **내 반려식물 도감 & 상세 관리 (My Plants)**
   - 새 반려식물 등록 (이름, 학명, 카테고리, 물주기 주기, 생육 메모)
   - 식물별 적정 온습도, 일조량 및 생육 가이드 확인
   - 1:1 방문 홈케어 솔루션 원스톱 신청

3. **AI 식물 병해충 정밀 진단 (AI Plant Diagnosis)**
   - 증상 선택 및 잎/줄기 사진 업로드
   - AI 병변 분석을 통한 진단명 및 맞춤 처방전 발급

4. **Care Program 정기 멤버십 (Care Programs)**
   - Basic Care (월 19,000원) / Standard Care (월 39,000원) / Premium Care (월 69,000원)
   - 1개월, 3개월, 6개월 정기 구독 및 멤버십 혜택 제공

5. **안심 분갈이 딜리버리 서비스 (Repotting Service)**
   - 소형(25,000원), 중형(36,000원), 대형(48,000원) 화분별 전문 가드너 픽업 및 배양토 교체 서비스

6. **맞춤 영양 관리 정기 솔루션 (Nutrition Care)**
   - 유기농 종합 액비 앰플 및 미네랄 활력제 1/3/6개월 정기배송 솔루션

7. **가드닝 셀렉트 스토어 (Gardening Store)**
   - 독일 명품 전정가위, 오가닉 영양 앰플, 수분측정기, 이태리 토분, 멸균 배양토
   - 카테고리 필터링, 키워드 검색, 장바구니 수량 실시간 조절

8. **식물 집사 커뮤니티 & 1:1 전문가 상담**
   - 식물 자랑, 가드닝 꿀팁 게시글 작성, 좋아요 및 실시간 댓글 소통
   - 공인 식물치료사 및 전문 가드너 1:1 병해충 상담 문의 및 답변

## 🚀 설치 및 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 프로덕션 빌드 & 서버 실행
```bash
npm run build
npm start
```
* 서버가 실행되면 브라우저에서 `http://localhost:9929`로 접속합니다.

### 3. 취약점 자동 검증 스크립트 실행
```bash
node test-vuln.js
```

## ⚠️ 모의 환경 및 Mock 결제 안내
본 플랫폼의 모든 결제, 식물 진단, 분갈이 예약, 사용자 정보는 PPO 강화학습 에이전트의 보안 분석 및 비즈니스 로직 취약점 탐지 학습을 위한 Mock 데이터 기반으로 작동하며, 실제 금융 결제나 외부 API와 연동되지 않습니다.
