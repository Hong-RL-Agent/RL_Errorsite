# Paper Pond

- 사이트 ID: `site046`
- 포트 번호: `9265`
- 기술 스택: Vanilla HTML, CSS, JavaScript, Express
- 주제: 데스크톱 문구 쇼핑몰 웹사이트

## 실행 방법

```bash
cd site046
npm install
npm start
```

브라우저에서 `http://localhost:9265`로 접속합니다.

## API 엔드포인트

- `GET /api/health`: 서버 상태와 사이트 ID를 반환합니다.
- `GET /api/products`: 문구 상품 ID, 이름, 카테고리, 브랜드, 가격, 색상 옵션, 이미지, 재고 상태를 반환합니다.
- `GET /api/reviews`: 상품 ID, 작성자, 평점, 후기 내용, 작성일을 반환합니다.

## 정상 작동 기능

- 상품 검색
- 좌측 카테고리 필터
- 재고 상품만 보기
- 추천순, 가격순, 평점순 정렬
- 상품 색상 옵션 선택 표시
- 상품 상세 모달 열기와 닫기
- 정상 상품 장바구니 담기
- 장바구니 상품 삭제
- 우측 장바구니 요약 패널 접기와 펼치기
- 베스트 상품 렌더링
- 고객 후기 평점 필터
- 뉴스레터 이메일 입력값 실시간 반영
- API 로딩 상태와 에러 상태 UI
- 구현하지 않은 보조 버튼의 `준비중입니다` alert 처리

## 의도된 프론트엔드 오류 3개

1. `site046-bug01` / `data-bug-id="site046-bug01"`
   - CSV 오류명: 상품 개수 UI 불일치
   - 헤더 장바구니 배지가 실제 장바구니 상품 수보다 하나 적게 표시됩니다.
2. `site046-bug02` / `data-bug-id="site046-bug02"`
   - CSV 오류명: 카드 flex 깨짐
   - 긴 상품명 카드에서 제목이 길게 내려가고 버튼 정렬이 다른 카드와 어긋납니다.
3. `site046-bug03` / `data-bug-id="site046-bug03"`
   - CSV 오류명: 담기 버튼 무반응
   - 특정 베스트 상품의 담기 버튼이 정상처럼 보이지만 클릭해도 장바구니가 변경되지 않습니다.

## PPO 에이전트 기대 탐지 행동

- 장바구니 목록과 헤더 배지 숫자를 비교해 카운트 불일치를 탐지합니다.
- 상품 그리드에서 특정 긴 상품 카드의 높이와 버튼 위치가 주변 카드와 불균형한지 확인합니다.
- 베스트 상품 영역에서 `데스크 위클리 플래너 A4` 담기 버튼 클릭 후 장바구니 변화가 없는지 확인합니다.
