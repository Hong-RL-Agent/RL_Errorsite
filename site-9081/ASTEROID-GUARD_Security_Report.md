# ASTEROID-GUARD Security Report

본 문서는 PPO 에이전트 학습을 위한 방어형 보안 시뮬레이션 명세입니다. 모든 항목은 실제 악용 절차가 아니라 관제, 탐지, 대응 로직을 검증하기 위한 안전한 모의 이벤트로 구현되었습니다.

## 포트 및 네트워크 격리

- 공식 접근 주소: `http://localhost:9081`
- 프론트엔드 API 호출: `/api/...` 상대 경로만 사용
- Vite 개발 프록시: `/api` -> `http://localhost:8080`
- Docker 외부 노출: UI `9081`, 백엔드 보조 진단 `9082`
- 프로젝트 네트워크: `asteroid-guard-9081`

## 11개 심화 취약점 시뮬레이션

1. 루트킷 감염 시나리오
   - 커널 프로세스 은닉 징후를 `kernel-cloak` 이벤트로 모델링합니다.
   - 탐지 포인트: 프로세스 카운터 불일치, 서명되지 않은 커널 모듈, EDR 블라인드 스팟.

2. 펌웨어 취약점 노출
   - 관측 위성 게이트웨이의 펌웨어 무결성 저하를 `firmware-drift` 이벤트로 표시합니다.
   - 탐지 포인트: 부트 체인 측정값 변동, 관리 콘솔 버전 편차.

3. 망 분리 우회 데이터 유출 경로
   - 물리적 망 분리 환경에서 텔레메트리 릴레이 이상 흐름을 `airgap-bridge`로 표현합니다.
   - 탐지 포인트: 비인가 단방향 큐, 외부 반출량 급증, 비정상 스테이징 파일.

4. USB 오토런 악성코드
   - 관리자 워크스테이션의 이동식 매체 이벤트를 `usb-autorun`으로 시뮬레이션합니다.
   - 탐지 포인트: 신규 드라이브 연결 직후 권한 상승 프로세스 생성.

5. 제로데이 침투 현상
   - 패치 부재 상태의 서비스 이상 호출을 `zero-day-vector`로 표현합니다.
   - 탐지 포인트: 정상 API 경로 밖의 충돌 패턴, WAF 미분류 페이로드.

6. 내부 APT 데이터 유출 징후
   - 내부 장기 체류 공격자의 은밀한 데이터 이동을 `apt-exfil`로 표시합니다.
   - 탐지 포인트: 저속 압축 전송, 업무 시간 외 접근, 분산 쿼리.

7. C2 채널 개방
   - 외부 명령 서버와의 비정상 비콘을 `c2-beacon`으로 모델링합니다.
   - 탐지 포인트: 주기적 DNS/HTTPS 비콘, JA3 지문 변동, 지연시간 고정 패턴.

8. 로밍 프로파일 오염
   - AD 로밍 프로파일을 통한 횡적 확산을 `roaming-profile-taint`로 표현합니다.
   - 탐지 포인트: 프로파일 스크립트 변경, 로그인 직후 다중 호스트 동시 경보.

9. AD 탈취 결함
   - 도메인 권한 계층 붕괴를 `ad-privilege-collapse`로 표시합니다.
   - 탐지 포인트: Tier-0 그룹 멤버십 변경, GPO 강제 배포, DC 동기화 이상.

10. Kerberoasting 가능성
   - 서비스 계정 티켓 요청 급증을 `kerberoast-risk`로 시뮬레이션합니다.
   - 탐지 포인트: SPN 계정 대상 TGS 요청 증가, 오래된 암호 정책.

11. Pass-the-Hash 환경
   - 해시 기반 인증 우회 징후를 `pass-the-hash`로 표현합니다.
   - 탐지 포인트: NTLM 원격 로그인, 원본 호스트 불일치, 짧은 간격의 다중 인증 성공.

## 방어 관제 구현

- Spring Boot API는 위 이벤트를 안전한 JSON 텔레메트리로 제공합니다.
- React 대시보드는 궤도 시뮬레이션, 지구 관측망, AD 권한 계층, C2 로그 터미널을 시각화합니다.
- 모든 화면과 API는 훈련용 탐지 데이터를 표시하며 실제 공격 코드를 포함하지 않습니다.
