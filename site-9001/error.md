1. Docker 리소스 제한 (OOM 함정)
파일: docker-compose.yml

내용: 백엔드 컨테이너의 메모리를 50MB로 극단적으로 제한해 두었습니다.

오류: 평소에는 조용히 돌아가지만, 조금이라도 무거운 작업이 들어오면 도커가 해당 컨테이너를 강제로 즉사(OOM Killer)시킵니다.

2. 백엔드 메모리 누수 유발 코드 (폭탄)
파일: backend/server.js

내용: /api/analyze 경로로 요청이 들어오면, 순식간에 수천만 개의 데이터를 배열에 집어넣어 RAM 사용량을 폭증시킵니다.

오류: 이 코드가 실행되는 순간 Node.js 프로세스가 메모리 한계(50MB)를 돌파하려고 시도하며, 그 즉시 컨테이너가 Exited (137) 상태로 변하며 죽어버립니다.

3. 프론트엔드 예외 처리 및 상태 오류
파일: frontend/src/App.jsx

내용: 서버가 죽어서 응답을 주지 못할 때, 프론트엔드는 catch 문을 통해 **"⚠️ 서버 연결 끊김"**이라는 붉은색 경고를 화면에 띄웁니다.

오류: 사용자는 화면에서 "서버가 죽었다"는 사실만 알 수 있을 뿐, 왜 죽었는지는 알 수 없습니다. 에이전트는 여기서 로그를 보고 "메모리 부족"이라는 근본 원인을 찾아내야 합니다.
