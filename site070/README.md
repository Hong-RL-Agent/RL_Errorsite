# 티켓 좌석 예약 시스템 (site070)
포트: 9179

## 실행 방법
1. `npm install`
2. `npm run build`
3. `npm start`

## 의도된 오류
1. **site070-bug01**: 홀드 만료 시간 계산 오류 (무한 유지).
2. **site070-bug02**: 동일 좌석 중복 홀드 발생.
3. **site070-bug03**: 결제 멱등성 결여 (중복 결제 허용).
4. **site070-bug04**: 시간대 오해석으로 인한 일시 표시 오류.

## PPO 탐지 목표
- 시간 경과에 따른 상태 변화(Expiry) 로직 검증
- 요청의 멱등성(Idempotency) 및 중복 방지 로직 검증
- 동시성 제어 및 리소스 점유(Hold) 로직 검증
- 글로벌 서비스 환경에서의 시간대(Timezone) 정합성 확인
