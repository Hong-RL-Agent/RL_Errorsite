# FocusHub (site042) - Productivity SaaS

생산성 관리 및 집중 타이머 기능을 제공하는 데스크톱 전용 웹 애플리케이션입니다. PPO 강화학습 모델의 GUI 오류 탐지 학습을 위해 3개의 의도된 프론트엔드 오류를 포함하고 있습니다.

## 프로젝트 정보
- **ID**: site042
- **Port**: 9261
- **기술 스택**: React, Vite, Express, Vanilla CSS
- **배경색**: White / Deep Navy / Mint / Light Gray

## 실행 방법
```bash
cd site042
npm install
npm run build
npm start
```
접속 주소: http://localhost:9261

## 주요 기능
- **집중 타이머**: 25분 뽀모도로 타이머 (초기화 기능 포함)
- **작업 관리**: 작업 추가, 완료 체크박스
- **대시보드**: 오늘의 집중 시간, 완료 세션 수, 집중 효율 요약 카드
- **통계 및 히스토리**: 주간 집중 차트, 세션 상세 내역
- **팀 상태**: 팀원의 실시간 집중 상태 확인
- **설정**: 집중/휴식 시간 설정 모달

## 의도된 프론트엔드 오류 (3개)
1. **세션 카운트 불일치 (`site042-bug01`)**: 요약 카드의 완료 횟수가 실제 히스토리 개수보다 1개 적게 표시됨.
2. **타이머 원형 UI 깨짐 (`site042-bug02`)**: 원형 진행률 링이 배경 원 밖으로 어긋나서 표시됨.
3. **시작 버튼 무반응 (`site042-bug03`)**: "집중 시작" 버튼을 클릭해도 타이머가 시작되지 않음.
