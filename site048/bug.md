# Bug Details Report (site048 - ClassMate)

본 문서는 site048 (ClassMate 커뮤니티 기반 클래스·워크숍 관리 플랫폼)의 PPO 탐색용 의도된 취약점 및 비즈니스 로직 결함(SEC-416 ~ SEC-420)의 세부 명세를 기술합니다.

---

### SEC-416
* **SEC ID**: SEC-416
* **오류 이름**: 권한 없는 클래스 공지사항 수정
* **오류 유형**: `resource-authorization` (자원 인가 검증 결함)
* **발생 조건**: 수강생 또는 일반 회원이 다른 강사가 개설한 클래스의 공지사항 수정 API를 호출할 때
* **정상 동작**: 해당 클래스의 `instructorId`와 요청자의 `userId`를 대조하여 일치하지 않을 경우 `403 Forbidden`을 반환해야 함.
* **현재 잘못된 동작**: 강사 소유권 확인 없이 `announcementId`만 조회하여 수정을 완료함.
* **관련 API**: `PATCH /api/classes/:classId/announcements/:announcementId`
* **관련 UI**: 클래스 상세 공지사항 탭 및 수정 모달
* **관찰 가능한 결과**: 수강생 계정에서도 공지사항 내용이 변경되고 200 OK 수신.
* **PPO 탐색 흐름**: 일반 사용자로 로그인 → 클래스 공지사항 진입 → 공지 수정 요청 전송 → 권한 인가 우회 관찰.

---

### SEC-417
* **SEC ID**: SEC-417
* **오류 이름**: 검색 필터와 실제 결과 상태 불일치
* **오류 유형**: `filter-state-sync` (상태 동기화 결함)
* **발생 조건**: 카테고리 필터를 연속으로 변경하며 검색할 때
* **정상 동작**: 선택된 카테고리(예: '사진')와 정확히 일치하는 클래스만 목록에 노출되어야 함.
* **현재 잘못된 동작**: 이전 검색 결과의 일부 데이터가 다음 검색 결과 목록에 비동기 잔존하여 표시됨.
* **관련 API**: `GET /api/classes`
* **관련 UI**: 클래스 탐색 페이지 검색 필터 탭 및 결과 카드 그리드
* **관찰 가능한 결과**: 카테고리 선택 칩과 화면에 렌더링된 카드 태그의 불일치.
* **PPO 탐색 흐름**: 카테고리 '도예' 선택 후 '사진'으로 변경 → 반환된 카드 중 '도예' 항목 잔존 여부 확인.

### SEC-418
* **SEC ID**: SEC-418
* **오류 이름**: 프로필 이미지 업로드 후 미리보기 불일치
* **오류 유형**: `upload-preview-sync` (업로드-뷰 상태 동기화 결함)
* **발생 조건**: 마이페이지 프로필에서 새로운 아바타 이미지를 선택하고 업로드할 때
* **정상 동작**: 업로드 완료 즉시 화면의 프로필 아바타 이미지가 새로운 이미지로 갱신되어야 함.
* **현재 잘못된 동작**: 백엔드 데이터는 수정되지만 응답 객체에 이전 캐시 이미지가 포함되어 화면에 즉시 반영되지 않음.
* **관련 API**: `POST /api/profile/avatar`
* **관련 UI**: 마이페이지 프로필 아바타 이미지 및 파일 업로더
* **관찰 가능한 결과**: 업로드 성공 토스트가 떴음에도 아바타 미리보기가 이전 이미지로 유지됨.
* **PPO 탐색 흐름**: 프로필 이미지 파일 선택 및 업로드 → 업로드 응답 페이로드 및 뷰 아바타 src 속성 대조.

### SEC-419
* **SEC ID**: SEC-419
* **오류 이름**: 클래스 신청 취소 후 상태 전이 오류
* **오류 유형**: `state-transition` (상태 머신 전이 검증 결함)
* **발생 조건**: 이미 '참여 완료(completed)' 또는 '취소됨(cancelled)' 상태인 신청에 대해 취소 요청을 보낼 때
* **정상 동작**: 현재 상태가 '신청 완료(enrolled)'일 때만 취소를 허용하고 완료/기취소 건은 `400 Bad Request` 처리해야 함.
* **현재 잘못된 동작**: 현재 상태 검증 없이 무조건 `status: "cancelled"`로 덮어쓰기 허용.
* **관련 API**: `PATCH /api/enrollments/:id/cancel`
* **관련 UI**: 내 클래스 목록의 상태 뱃지 및 취소 버튼
* **관찰 가능한 결과**: 이미 종료된 수강 이력도 취소 상태로 변경 처리됨.
* **PPO 탐색 흐름**: 완료된 클래스 항목 확인 → 취소 API 요청 트리거 → 상태 전이 불일치 관찰.

---

### SEC-420
* **SEC ID**: SEC-420
* **오류 이름**: 게시글 삭제 후 댓글 데이터 잔존
* **오류 유형**: `orphaned-child-data` (데이터 무결성 및 고아 데이터 결함)
* **발생 조건**: 댓글이 작성된 커뮤니티 게시글을 삭제할 때
* **정상 동작**: 게시글 삭제 시 연결된 모든 하위 댓글 데이터도 함께 연쇄 삭제(Cascade Delete)되어야 함.
* **현재 잘못된 동작**: 게시글만 삭제되고 연결된 댓글 레코드가 메모리 저장소에 그대로 잔존함.
* **관련 API**: `DELETE /api/posts/:id`, `GET /api/posts/:postId/comments`
* **관련 UI**: 커뮤니티 게시글 상세 및 삭제 버튼
* **관찰 가능한 결과**: 게시글 삭제 후에도 해당 postId를 가진 댓글 데이터가 고아 상태로 조회 가능.
* **PPO 탐색 흐름**: 댓글이 있는 게시글 삭제 실행 → 댓글 조회 엔드포인트 응답 데이터 무결성 검증.
