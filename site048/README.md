# ClassMate — Community Workshop & Class Management Platform

ClassMate는 누구나 쉽게 자신에게 맞는 취미와 원데이 클래스를 탐색하고 수강 신청하며, 강사와 수강생이 실시간으로 소통할 수 있는 커뮤니티 기반 워크숍 관리 플랫폼입니다.

---

## 🌟 주요 기능

1. **클래스 탐색 및 상세 검색**
   - 도예, 베이킹, 드로잉, 사진, 공예, 운동 등 카테고리 및 지역별 다차원 필터링
   - 커리큘럼, 준비물, 일정, 강사 프로필, 수강 정원 실시간 확인

2. **클래스 수강 신청 및 내 일정 관리**
   - 간편 수강 신청 및 신청 내역 확인
   - 일정 변경 및 참여 취소 관리

3. **강사 센터 (Instructor Dashboard)**
   - 신규 클래스 개설 및 운영
   - 수강생 출석 체크 (출석, 미출석, 지각)
   - 클래스 공지사항 작성 및 관리

4. **취미 커뮤니티**
   - 수강 후기, 취미 질문, 소모임 모집 게시판
   - 실시간 댓글 및 피드백

5. **마이페이지 & 프로필 관리**
   - 프로필 사진 변경 및 자기소개
   - 관심 카테고리 및 수강 이력 관리

---

## 🚀 실행 및 빌드 방법

### 1. 의존성 패키지 설치
```bash
npm install
```

### 2. 프로덕션 빌드 및 서버 시작
```bash
npm run build
npm start
```

### 3. 개발 서버 실행
```bash
npm run dev
```
