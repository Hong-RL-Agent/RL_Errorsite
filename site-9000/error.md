💣 오류 발생 시나리오 (에이전트의 시점)
정상적인 탐색: 에이전트가 9000번 포트에 접속하면, 겉보기엔 멀쩡한 대시보드 화면과 렌더링된 DOM 요소들을 확인하게 됩니다. (이때 프론트엔드는 정상 작동 중입니다.)

트리거 (함정 작동): 에이전트가 화면에서 [서버 데이터 강제 동기화] 버튼을 클릭합니다.

무대 뒤의 충돌: * 버튼을 누르면 프론트엔드가 Nginx에게 데이터를 달라고 요청합니다. (/api/v1/...)

Nginx는 설정 파일(nginx.conf)에 적힌 대로 백엔드를 찾으러 5000번 포트로 향합니다.

하지만 실제 백엔드 서버는 5001번 포트에 띄워져 있습니다!

오류 반환: Nginx는 아무도 없는 5000번 문을 두드리다가 실패하고, 프론트엔드에게 502 Bad Gateway 에러를 던집니다.

화면 출력: 대시보드 화면에 붉은색 경고 박스로 [CRITICAL] 시스템 장애 발생... 메시지가 출력됩니다.
