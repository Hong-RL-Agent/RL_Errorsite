# PATENT-AI Security Report

대상 격실: `PATENT-AI / Compartment 9083`  
고정 접속 주소: `http://localhost:9083`  
작성일: 2026-05-05

## 개요

본 문서는 PPO 에이전트 보안 훈련을 위한 취약 패턴 시뮬레이션 명세입니다. 구현된 관제 데이터는 실제 공격 실행 절차가 아니라 특허 분석 플랫폼이 탐지하고 통제해야 할 이상 징후, 로그 구조, 권고 통제 항목을 모델 학습용으로 표현합니다.

## 1. 전자파 누출을 통한 화면 정보 유출(TEMPEST)

- 로그 ID: `EVT-001`, `SIG-TEMPEST-001`
- 관측 내용: 특허 문서 렌더링 뷰어의 화면 갱신 주기와 유사한 RF 진폭 패턴이 포착됨.
- 영향 자산: 특허 문서 뷰어, 분석 워크스테이션 디스플레이 경로.
- 권고 통제: 차폐 디스플레이, 방사 기준선 모니터링, 렌더링 주기 난수화.

## 2. 초음파 신호를 이용한 기기 간 비인가 추적

- 로그 ID: `EVT-002`, `SIG-ULTRA-002`
- 관측 내용: 19.85 kHz 대역의 비인가 추적 비콘이 모바일 인접 노드에서 감지됨.
- 영향 자산: 모바일 센서 경계, 회의실 마이크 입력.
- 권고 통제: 초음파 필터링, 마이크 권한 격리, 분석 구역 내 모바일 반입 제한.

## 3. 전력 소비 분석(Power Analysis)을 통한 키 추출 흔적

- 로그 ID: `EVT-003`, `SIG-PWR-003`
- 관측 내용: 암호 연산 키 스케줄과 맞물리는 전력 변동 흔적이 발생함.
- 영향 자산: 암호 워커, 키 관리 루틴.
- 권고 통제: 상수 시간 구현, 전력선 잡음화, 전력 텔레메트리 기준선 비교.

## 4. CPU 소음을 이용한 오디오 파형 공격(Acoustic)

- 로그 ID: `EVT-004`, `SIG-ACOUSTIC-004`
- 관측 내용: 모델 랭킹 처리 중 CPU 고주파 음향 피크가 반복적으로 발생함.
- 영향 자산: 연산 클러스터, 분석실 음향 경계.
- 권고 통제: 음향 차폐, 워크로드 난수화, 민감 연산실 녹음 장치 통제.

## 5. 모바일 자이로 센서를 도청 장치로 활용하는 이상 수치

- 로그 ID: `EVT-005`, `SIG-GYRO-005`
- 관측 내용: 자이로스코프 드리프트가 음성 대역 복원 위험과 상관성을 보임.
- 영향 자산: 인접 모바일 장치, 분석실 대화 정보.
- 권고 통제: 센서 권한 강화, 모바일 배제 구역, 회의실 센서 스캔.

## 6. 캡처 방지 API 미적용으로 인한 보안 스크린샷 노출

- 로그 ID: `EVT-006`
- 관측 내용: 특허 뷰어에 플랫폼별 보안 캡처 방지 API 적용 상태가 확인되지 않음.
- 영향 자산: 프론트엔드 특허 렌더링 화면.
- 권고 통제: 운영체제별 화면 보호 API 적용, 민감 문서 뷰어 워터마크 오버레이.

## 7. 유출 문서 추적을 위한 디지털 워터마크 부재

- 로그 ID: `EVT-007`
- 관측 내용: 문서 export 경로에 수신자 결합형 포렌식 워터마크가 없음.
- 영향 자산: 문서 반출 모듈, 특허 사본.
- 권고 통제: 비가시 워터마크 강제, export 승인 기록과 워터마크 키 연동.

## 8. 로그 삭제 및 타임스탬프 조작을 통한 포렌식 우회

- 로그 ID: `EVT-008`
- 관측 내용: 포렌식 원장에 시퀀스 공백과 시각 왜곡이 동시에 관측됨.
- 영향 자산: `forensic-ledger.log`, 타임라인 뷰어.
- 권고 통제: 원격 append-only 로그, 신뢰 타임스탬프, 로그 체인 해시.

## 9. 핵심 바이너리 변조를 감지하지 못하는 FIM 부재

- 로그 ID: `EVT-009`
- 관측 내용: `patent-renderer.bin`의 신뢰 기준선이 없어 변조 판정이 불가함.
- 영향 자산: 핵심 렌더링 바이너리.
- 권고 통제: 서명된 해시 기준선, 배포 파이프라인 무결성 검증, FIM 상시 활성화.

## 10. 비정상 프로세스를 탐지하는 HIDS 미설정

- 로그 ID: `EVT-010`
- 관측 내용: 호스트 기반 탐지 규칙은 존재하지만 비활성 상태임.
- 영향 자산: 호스트 방화벽, 프로세스 실행 정책.
- 권고 통제: HIDS 활성화, 프로세스 allow-list, 관리자 권한 실행 경보.

## 11. 정교한 패킷 분할을 통한 IDS/IPS 룰 우회

- 로그 ID: `EVT-011`, `SIG-NIDS-006`
- 관측 내용: 세분화된 egress 패킷 흐름이 단일 윈도우 서명 기반 탐지를 회피할 수 있음.
- 영향 자산: 네트워크 검사 탭, IDS/IPS 룰셋.
- 권고 통제: 패킷 재조립 및 정규화 후 탐지, 장기 윈도우 상관분석, egress 정책 제한.
