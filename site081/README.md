# Chef's Pantry

- 사이트 이름: Chef's Pantry
- 사이트 ID: site081
- 포트 번호: 9300
- 기술 스택: Vanilla HTML, CSS, JavaScript, Express

## 실행 방법

```bash
cd site081
npm install
npm start
```

브라우저에서 `http://localhost:9300`으로 접속한다.

## API 엔드포인트

- `GET /api/health`: 서비스 상태와 사이트 ID를 반환한다.
- `GET /api/kitchenware`: 상품 ID, 상품명, 카테고리, 브랜드, 소재, 가격, 이미지, 평점, 재고 상태 데이터를 반환한다.
- `GET /api/brands`: 브랜드 ID, 이름, 설명, 추천 여부 데이터를 반환한다.

## 정상 작동 기능

- 카테고리 필터
- 소재 필터
- 브랜드 필터
- 가격대 필터
- 재고 상품만 보기
- 상품 검색
- 상품 정렬
- 상품 상세 모달 열기와 닫기
- 정상 상품 장바구니 담기
- 장바구니 수량 증가와 감소
- 장바구니 상품 삭제
- 장바구니 요약 패널 접기와 펼치기
- 뉴스레터 이메일 입력 반영
- API 로딩 상태와 에러 상태 UI
- 미구현 메뉴와 버튼의 `준비중입니다.` 알림
