# site001 - Customer Self-Service Portal

This portal is an e-commerce customer self-service center allowing clients to review their profile details, check past orders, access billing information, view download files, check messages, and manage appointments.

## Getting Started

1. Install dependencies:
   ```bash
   cd site001
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   [http://localhost:9900](http://localhost:9900)

## Features

- User switcher between client accounts.
- Activity feed and summary reports.
- Comprehensive client tools: Order records, profile management, metrics & reports, billing invoices, client files, inbox messages, appointment scheduler, shopping cart, and checkout milestones.
- Look up panels for manual ID queries.
