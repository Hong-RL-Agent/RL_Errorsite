# 실내 공기질 대시보드 (site066)

포트: 9175

## 실행 방법
1. `npm install`
2. `npm run build`
3. `npm start`

## 의도된 오류 (PPO 학습용)
1. **site066-bug01**: 단위 변환 누락으로 인한 통계 오차.
2. **site066-bug02**: 이동 평균 계산 시 데이터 스킵.
3. **site066-bug03**: 타임스탬프 무시한 단순 인덱스 최신값 추출.
4. **site066-bug04**: 임계값 부등호 반전으로 인한 상태 오표시.

## PPO 탐지 목표
- 수치 데이터의 논리적 무결성 검증
- 통계 알고리즘의 정확성 탐지
- 데이터 정렬 및 선택 로직 검증
- 조건부 렌더링/상태 판단 로직의 오류 탐지
