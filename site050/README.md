# EduStream - 온라인 코스 카탈로그 (site050)

현대적인 교육 플랫폼 스타일의 온라인 강좌 카탈로그 웹사이트입니다. 강화학습(PPO) 에이전트의 프론트엔드 GUI 오류 탐지 및 학습을 위해 다양한 오류 시나리오를 포함하고 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site050
- **포트 번호**: 9269
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **주요 테마**: 인디고 / 라이트 블루 / 소프트 그레이 교육 플랫폼 UI

## 2. 실행 방법
```bash
cd site050
npm install
npm start
```
- 접속 주소: [http://localhost:9269](http://localhost:9269)

## 3. 주요 기능
- **강좌 탐색**: 분야별, 난이도별 필터링을 지원하는 강좌 목록
- **실시간 검색**: 강좌 제목 및 강사명을 기반으로 한 실시간 검색
- **상세 정보**: 모달을 통한 강좌 상세 커리큘럼 및 정보 확인
- **강사 및 후기**: 플랫폼 내 강사진 소개 및 수강생들의 생생한 후기 섹션
- **상태 피드백**: 미구현 기능 클릭 시 "준비 중입니다" alert 제공

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **난이도 뱃지 undefined (site050-bug01)**: 특정 강좌의 난이도 데이터가 누락되어 화면에 `undefined`가 렌더링됨.
2. **카드 높이 깨짐 (site050-bug02)**: 제목이 매우 긴 강좌 카드에서 텍스트 줄임 처리가 되지 않아 그리드 레이아웃이 붕괴됨.
3. **강좌 담기 무반응 (site050-bug03)**: 특정 강좌의 "내 학습에 담기" 버튼에 이벤트 리스너가 누락되어 클릭 시 반응이 없음.

## 5. 프로젝트 구조
- `server.js`: Express 서버 및 강좌/강사 데이터 API
- `public/index.html`: 메인 대시보드 레이아웃
- `public/styles.css`: 인디고 스타일 가이드 및 레이아웃 오류 구현
- `public/app.js`: 데이터 처리 및 인터랙션 로직
- `BUGS.md`: 의도된 오류의 원인 및 해결 방안
