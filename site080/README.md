# site080 - The Living 프리미엄 인테리어 견적 시스템

'The Living'은 고객의 공간에 맞는 최적의 인테리어 시공 견적을 계산하고 전문가 상담을 예약할 수 있는 데스크톱 전용 웹사이트입니다. 이 프로젝트는 PPO(강화학습) 모델의 GUI 오류 탐지 학습을 위해 제작되었습니다.

## 기술 스택
- **Frontend**: Vanilla HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Port**: 9299

## 실행 방법
```bash
cd site080
npm install
npm start
```
접속 주소: `http://localhost:9299`

## API 엔드포인트
- `GET /api/health`: 서버 상태 확인
- `GET /api/options`: 시공 옵션 데이터 (이름, 단가 등)
- `GET /api/portfolio`: 시공 사례 데이터 (평수, 이미지, 스타일 등)

## 주요 기능
- **스마트 견적 계산기**: 평수와 시공 옵션을 선택하여 실시간 예상 견적 확인
- **포트폴리오 조회**: 공간 유형 및 스타일별 시공 사례 확인 (상세 모달 지원)
- **상담 예약 시스템**: 이름, 연락처, 희망일을 입력하여 1:1 상담 신청
- **스티키 견적 패널**: 선택한 옵션을 실시간으로 요약하여 보여줌

## 의도된 프론트엔드 GUI 오류 (3개)
1. **예상 견적 계산 불일치** (`site080-bug01`): 옵션을 선택하면 요약 목록에는 나오지만, 총액 계산 시 마지막으로 선택한 옵션의 금액이 누락됨.
2. **포트폴리오 grid 겹침** (`site080-bug02`): 세로형 이미지를 포함한 카드가 grid 행 높이를 초과하여 아래 행의 카드와 시각적으로 겹침.
3. **상담 신청 버튼 무반응** (`site080-bug03`): 버튼의 ID와 자바스크립트 내 셀렉터가 일치하지 않아 클릭 시 아무런 동작(alert 등)이 발생하지 않음.
