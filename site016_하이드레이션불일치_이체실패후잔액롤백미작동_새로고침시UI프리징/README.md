# Online Banking Dashboard (site016)

## 개요
이 프로젝트는 PPO 강화학습 모델의 GUI 오류 탐지 훈련을 위한 온라인 뱅킹 대시보드 웹사이트입니다. 하이드레이션 불일치, 상태 동기화 실패, 런타임 에러로 인한 화면 마비 등 복잡한 프론트엔드 상태 오류를 재현합니다.

- **사이트 ID**: site016
- **포트 번호**: 9235
- **기술 스택**: React, Vite, Express, CSS

## 실행 방법
```bash
cd site016
npm install
npm run build
npm start
```

## API 엔드포인트 목록
- `GET /api/health` : 서버 상태 확인
- `GET /api/account` : 계좌 정보 및 잔액 조회
- `GET /api/transactions` : 최근 거래 내역 조회
- `POST /api/transfer` : 이체 실행 (실패 시나리오 포함)

## 정상 작동 기능 목록
- **탭 전환**: 입출금/예적금/대출 탭 간 이동.
- **상세 모달**: 거래 내역 클릭 시 상세 정보 모달 오픈.
- **검색**: 거래 내역 내 키워드 검색 기능.
- **미구현 피드백**: 대출 신청, 보안 설정 등 미구현 메뉴 클릭 시 "준비 중" 토스트 표시.

## 의도된 GUI 오류
1. **site016-bug01** (하이드레이션 불일치): 초기 로드 시 환율 카드 레이아웃 깨짐.
2. **site016-bug02** (상태 불일치): 이체 실패 후 잔액 롤백 미작동.
3. **site016-bug03** (화면 마비): 내역 새로고침 클릭 시 JS 에러로 인한 UI 프리징.

## PPO 에이전트 기대 행동
- 레이아웃 깨짐(Overlap, Missing tags) 탐지.
- 비즈니스 로직과 화면 상태의 불일치(잔액 계산 오류) 탐지.
- 인터랙션 중단 및 런타임 에러 발생 감지.
