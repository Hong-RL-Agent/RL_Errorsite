🏗️ [제안] SITE-9029: JAWS Admin 인프라 종합 취약점 서버
이 서버는 겉보기엔 평범한 관리자 웹사이트지만, 인프라와 서버 설정 곳곳에 하은님 파트의 오류들을 3중, 4중으로 겹쳐서 심어둘 것입니다.

💣 심어둘 서버/인프라 오류 콤보 (예시)
디렉토리 리스팅 (Nginx 설정 결함)

내용: 웹 서버 설정에 autoindex on;을 실수로 켜두어, 사용자가 특정 URL로 접근하면 서버 내부의 파일 목록(로그 파일, 설정 파일 등)이 브라우저에 훤히 들여다보이는 인프라 오류입니다.

불필요한 서비스 및 디버그 포트 노출 (Docker/Spring Boot)

내용: 외부에 80번 포트만 열어야 하는데, 서버 모니터링용 액추에이터(Actuator) 포트나 디버그용 포트까지 싹 다 열어두어 서버 내부 환경변수와 세션 정보가 줄줄 새어나갑니다.

기본 계정 및 비밀번호 방치 (초기 설정 결함)

내용: 인프라를 처음 세팅할 때 쓰는 admin / admin 혹은 root / 1234 같은 초기 비밀번호를 그대로 방치해 두어 관리자 페이지가 한 번에 뚫립니다.
