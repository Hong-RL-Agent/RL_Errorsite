# Sage Journal - 사적인 기록과 에세이 (site049)

차분한 감성의 에세이 매거진 스타일로 디자인된 개인 블로그 웹사이트입니다. 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위해 제작되었습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site049
- **포트 번호**: 9268
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **주요 테마**: 베이지 / 세이지 그린 / 잉크 블랙 컬러를 사용한 매거진 UI

## 2. 실행 방법
```bash
cd site049
npm install
npm start
```
- 접속 주소: [http://localhost:9268](http://localhost:9268)

## 3. 주요 기능
- **글 목록 탐색**: API에서 받아온 글 데이터를 Grid 형태로 표시
- **태그 필터링**: 태그를 클릭하여 관심 있는 주제의 글만 필터링
- **검색 및 정렬**: 제목/요약 검색 및 최신순/인기순 정렬 지원
- **상세 보기**: 모달 형태의 글 상세 보기 지원
- **미구현 피드백**: 구현되지 않은 기능 클릭 시 "준비 중입니다" alert 제공

## 4. 의도된 프론트엔드 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **태그 필터 불일치 (site049-bug01)**: "여행" 태그 클릭 시 로직 오류로 인해 "일상" 관련 글이 필터링됨.
2. **사이드바 본문 침범 (site049-bug02)**: 화면 너비 축소 시(약 1200px 이하) 우측 사이드바가 본문 글 카드를 덮어버림.
3. **구독 버튼 무반응 (site049-bug03)**: 뉴스레터 구독 버튼의 셀렉터 불일치로 인해 클릭해도 아무런 반응이 없음.

## 5. 프로젝트 구조

- `public/index.html`: 메인 웹사이트 구조

- `public/app.js`: 데이터 로직 및 의도된 상태/이벤트 오류
- `BUGS.md`: 의도된 오류 명세서
