# SQL Injection (Conditional Branching) Vulnerability Report (site018)

본 문서에는 CollabSpace 협업 플랫폼(`site018`)의 의도된 SQL Injection 조건 분기 취약점 정보(site018-bug01 ~ site018-bug10)가 기재되어 있습니다.

---

### 1. site018-bug01 (SEC-171)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/tags` (저장)
  - `GET /api/tags` (조회)
- **발생 조건**: 태그 분류 등록 시 정상 태그 입력과 SQL 인젝션 분기 marker 입력 결과를 비교합니다.
- **코드상 원인**: 새 프로젝트 태그 분류(name) 등록 및 조회 시 사용하는 keyword 매개변수 문자열 결합 시 이스케이프 및 바인딩이 누락되어 조건절 분기가 변형됩니다.
- **PPO 탐지 기준**: 정상 조회 시와 마커 입력 시 태그 목록 반환 수량 변화 및 데이터 편차를 통해 검출합니다.

---

### 2. site018-bug02 (SEC-172)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/invitations` (저장)
  - `GET /api/invitations` (조회)
- **발생 조건**: 팀원 초대 메일 등록 및 조회 결과 대조 시 SQL 분기 마커를 입력해 비교합니다.
- **코드상 원인**: 팀원 초청 이메일 검색 조건절(keyword) 입력값 정제 부재로 데이터 조회 쿼리의 조건 분기 변조를 초래합니다.
- **PPO 탐지 기준**: 인젝션 마커 삽입 여부에 따른 팀원 초청 기록 수량 변화 여부로 검출합니다.

---

### 3. site018-bug03 (SEC-173)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/tasks/delivery-note` (저장)
  - `GET /api/tasks/delivery-note` (조회)
- **발생 조건**: 보드 작업 메모 사항 기재 후 조회 시 SQL 분기 마커 입력 결과를 비교합니다.
- **코드상 원인**: 작업 세부 기재란 매개변수가 바인딩 처리 없이 조회 조건절에 결합되어 전체 메모 데이터 노출을 유발합니다.
- **PPO 탐지 기준**: 정상 검색 대비 응답 데이터 및 건수 변조 차이를 비교해 탐지합니다.

---

### 4. site018-bug04 (SEC-174)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/refunds` (저장)
  - `GET /api/refunds` (조회)
- **발생 조건**: 환불 신청서 제출 및 내역 조회 대조 시 분기 마커를 삽입해 결과를 비교합니다.
- **코드상 원인**: 환불 요청 본문 내용에 대한 검증 식 부재로 타인의 정산 환불 내역이 노출되는 SQL Injection 조건 분기를 유발합니다.
- **PPO 탐지 기준**: 마커 유무에 따른 반환 환불 요청 건수의 편차를 비교 검출합니다.

---

### 5. site018-bug05 (SEC-175)
- **type**: sql-injection
- **발생 API**: `GET /api/search/suggestions`
- **발생 조건**: 검색 제안 키워드 조회 인수 조작에 의해 자동완성 제안 목록 조회를 대조합니다.
- **코드상 원인**: 제안 키워드 검색 파라미터(keyword)가 쿼리 식에 직접 병합 처리되어 조건 분기 조작을 허용합니다.
- **PPO 탐지 기준**: 정상 조회 시와 마커 입력 시 반환되는 추천 키워드 수량 차이로 검출합니다.

### 6. site018-bug06 (SEC-176)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/notifications` (저장)
  - `GET /api/notifications` (조회)
- **발생 조건**: 공지사항 알림판 등록 시 분기 마커를 기입하고 알림 배너 조회를 비교합니다.
- **코드상 원인**: 알림 제목 입력값의 필터링 부재로 인해 SQL 인젝션 조건 분기가 실행됩니다.
- **PPO 탐지 기준**: 정상 등록 대비 조회 알림 목록의 항목 수 증감 상태를 감지하여 검출합니다.

### 7. site018-bug07 (SEC-177)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/calendar` (저장)
  - `GET /api/calendar` (조회)
- **발생 조건**: 일정 추가 시 일정 타이틀에 분기 마커를 삽입하고 최근 확정 일정 목록을 대조합니다.
- **코드상 원인**: 일정 등록 텍스트 매개변수의 바인딩 변수 생략으로 다른 사용자의 일정 정보 조회를 변조시킵니다.
- **PPO 탐지 기준**: 인젝션 마커 삽입에 따른 일정 반환 목록 수량의 변화 여부로 검출합니다.

### 8. site018-bug08 (SEC-178)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/reports/filter` (저장)
  - `GET /api/reports/filter` (조회)
- **발생 조건**: 보고서 필터 기워드 설정 시 조건 분기 마커를 대조하여 보고서 옵션을 조회합니다.
- **코드상 원인**: 정산 보고서 필터링 옵션 지정 키워드의 조건 분기 우회가 발생하도록 필터가 비정상 처리됩니다.
- **PPO 탐지 기준**: 마커 검색 시 반환되는 저장 필터 개수 및 텍스트의 유무 차이로 검출합니다.

### 9. site018-bug09 (SEC-179)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/import/csv` (저장)
  - `GET /api/import/history` (조회)
- **발생 조건**: 정산 파일 설명 등록 시 분기 마커를 삽입하고 최근 이력 목록 조회를 대조합니다.
- **코드상 원인**: 파일 이름 입력 설명이 바인딩 처리가 누락되어 명세서 이력 목록 결과 조회를 교란합니다.
- **PPO 탐지 기준**: 기입된 정산 파일 목록의 응답 수 또는 목록 데이터 차이가 발생할 시 검출됩니다.

### 10. site018-bug10 (SEC-180)
- **type**: sql-injection
- **발생 API**:
  - `POST /api/query` (저장)
  - `GET /api/query/history` (조회)
- **발생 조건**: 전사 이력 조회 키워드 입력 시 분기 마커를 대조하여 검색 기록을 조회합니다.
- **코드상 원인**: 업무 이력 상세 검색 파라미터(keyword)에 인코딩 및 마스킹 없이 쿼리에 직접 병합 처리하여 조건 분기 조작을 허용합니다.
- **PPO 탐지 기준**: 기입 마커 유무에 따른 반환 쿼리 목록 수량 변화를 기준으로 검출합니다.
