# CollabSpace - 기업형 협업 프로젝트 관리 플랫폼 (site018)

CollabSpace는 인디고 블루, 화이트, 슬레이트 그레이 컬러를 조합하여 모던하고 프로페셔널한 분위기를 풍기는 SaaS 스타일의 프로젝트 관리 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 서비스를 구동할 수 있습니다.

```bash
cd site018
npm install
npm start
```

이후 브라우저에서 아래의 주소로 접속 가능합니다.
* **서비스 주소**: [http://localhost:9917](http://localhost:9917)

---

## 🎨 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **스프린트 칸반 보드**: To Do, In Progress, Done 형태의 동적 보드 마운트
- **협업원 초대 및 분류 태그**: 부서원 협업 메일링 초대 및 커스텀 업무 필터용 태그 생성
- **예산 정산 및 환불 접수**: 가용 예산 청구 및 취소 정산 환불 요청
- **부서 정산 파일 등록**: 부서 정산 명세서 이력 관리 및 저장 기능
- **일정 수립 캘린더**: 기획 평가 회의 등 중요 회의 스케줄러 등록
- **배너 공지사항 알림 센터**: 알림 배너 공지 작성 및 전체 피드 출력
- **이력 검색 포털**: 전사 프로젝트 업무 기록 상세 검색 콘솔 제공
- **자동완성 키워드 제안**: 실시간 업무 추천 제안어 키워드 등록기

---

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습 환경을 지원하기 위한 모의 협업 솔루션입니다.
- 실제 데이터베이스, Slack API, Calendar 연동 모듈 등은 동작하지 않으며, 메모리 상의 Mock 데이터 및 가상 인터페이스로 구성되어 있습니다.
