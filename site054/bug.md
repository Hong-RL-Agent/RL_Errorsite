# BookNest (site054) 결함 명세서 (bug.md)

이 문서는 BookNest(site054)에 구현된 정확히 5개의 의도적 오류(SEC-446 ~ SEC-450)에 대한 명세서입니다.

---

### 1. SEC-446 — 대여 기간 연장 시 최대 연장 가능 횟수 계산 오류

* **SEC ID**: SEC-446
* **오류 유형**: Business Rule / counter-calculation
* **재현 조건**: 대여 도서의 대여 기간을 이미 2회(최대 허용치) 연장한 상태에서 추가 연장을 시도할 때 발생
* **재현 절차**:
  1. 상단 메뉴에서 `내 대여` (`/loans`) 페이지로 이동
  2. 대여 중인 도서에서 `대여 연장` 버튼 클릭 (연장 1회: 1/2)
  3. 다시 `대여 연장` 버튼 클릭 (연장 2회: 2/2 최대 도달)
  4. 2/2 상태에서 다시 `대여 연장` 버튼 클릭
* **관찰되는 증상**: 최대 연장 한도에 도달했음에도 버튼이 비활성화되지 않거나 서버에서 추가 연장 요청(3/2)을 정상 승인하여 반납 예정일이 계속 늘어남
* **정상 동작**: 2회 연장 완료 시 연장 버튼이 비활성화되고 서버는 400 에러("최대 연장 횟수를 초과하였습니다.")를 반환해야 함
* **오류 발생 원인**: 서버의 연장 횟수 검증 조건문이 `>= 2`가 아닌 `> 2` 등으로 잘못 비교되어 3회차 연장까지 허용됨
* **PPO가 탐색해야 하는 행동**: 내 대여 목록에서 연장 한계치까지 연장을 반복한 뒤 추가 연장이 비정상적으로 승인되는지 확인

---

### 2. SEC-447 — 리뷰 별점 0점 입력이 기본값 5점으로 처리되는 문제

* **SEC ID**: SEC-447
* **오류 유형**: Form Validation / default-value-coercion
* **재현 조건**: 도서 상세 페이지에서 리뷰 작성 시 별점을 0점(또는 미선택)으로 제출할 때 발생
* **재현 절차**:
  1. `도서관` (`/books`)에서 임의의 도서 선택하여 상세 페이지 (`/books/:id`) 진입
  2. `리뷰 작성` 섹션에서 별점을 0점(☆☆☆☆☆)으로 선택 또는 미선택 상태로 설정
  3. 리뷰 내용 입력 후 `리뷰 등록` 버튼 클릭
  4. 새로 등록된 리뷰의 별점 확인
* **관찰되는 증상**: 사용자가 0점을 제출하였으나 서버에 5점(★★★★★)으로 왜곡되어 저장되고 표시됨
* **정상 동작**: 0점은 유효하지 않은 입력으로 에러 처리되거나(1점~5점 강제), 저장 시 정확히 0점으로 저장되어야 함
* **오류 발생 원인**: 서버에서 별점 처리 시 `const savedRating = rating || 5;` 코드를 사용하여 숫자 `0`을 falsy로 판별하고 기본값 5를 강제 할당함
* **PPO가 탐색해야 하는 행동**: 도서 상세에서 0점 리뷰를 등록하고 등록된 리뷰의 실제 저장 별점이 5점으로 변조되었는지 검증

### 3. SEC-448 — 전자책 리더에서 마지막 페이지 다음 이동 시 페이지 범위가 잘못 처리되는 문제

* **SEC ID**: SEC-448
* **오류 유형**: Boundary Handling / index-boundary
* **재현 조건**: 전자책 뷰어(`/reader/:id`)에서 책의 마지막 페이지(예: 80 / 80)에 도달한 후 '다음 페이지' 버튼을 누를 때 발생
* **재현 절차**:
  1. 전자책 목록 또는 상세에서 `전자책 읽기`를 클릭하여 리더 화면(`/reader/:id`) 진입
  2. 마지막 페이지(예: 80페이지)로 이동
  3. 80 / 80 상태에서 `다음 페이지 >` 버튼 클릭
  4. 현재 페이지 번호와 뷰어 화면 상태 확인
* **관찰되는 증상**: 마지막 페이지 이후에도 다음 버튼이 작동하여 `81 / 80`으로 증가하고 본문이 빈 화면으로 렌더링됨
* **정상 동작**: 마지막 페이지에서는 `다음 >` 버튼이 비활성화되어 더 이상 페이지 번호가 증가하지 않아야 함
* **오류 발생 원인**: 페이지 상한선 검증 로직에서 `currentPage >= totalPages` 차단 검사가 누락되어 인덱스가 상한을 초과함
* **PPO가 탐색해야 하는 행동**: 전자책 리더의 마지막 페이지로 이동 후 다음 버튼을 눌러 페이지 번호가 전체 페이지를 초과하는지 확인

### 4. SEC-449 — 같은 책의 서로 다른 리뷰가 작성자 표시 UI에 잘못 연결되는 문제

* **SEC ID**: SEC-449
* **오류 유형**: List Rendering / key-reuse
* **재현 조건**: 도서 상세 페이지에서 기존 리뷰 목록이 존재하는 상태에서 새 리뷰를 작성/추가할 때 발생
* **재현 절차**:
  1. 도서 상세 페이지(`/books/:id`)에서 기존 리뷰 목록과 각 작성자 이름을 확인
  2. 새로운 리뷰를 작성하여 등록
  3. 화면에 갱신된 리뷰 목록을 확인
* **관찰되는 증상**: 새 리뷰가 추가되면서 기존 리뷰의 작성자 닉네임과 리뷰 본문 내용이 서로 다른 사용자의 것으로 엇갈려 렌더링됨
* **정상 동작**: 각 리뷰는 고유 ID를 key로 사용하여 작성자 정보와 본문 내용이 항상 일치하게 렌더링되어야 함
* **오류 발생 원인**: React 리스트 렌더링 시 고유 key 대신 배열 index를 재사용하고, 렌더링 상태 배열이 분리되어 인덱스 시프트 시 어긋남이 발생함
* **PPO가 탐색해야 하는 행동**: 도서 상세에서 리뷰를 등록한 후 이전 리뷰들의 작성자 이름과 본문 내용 매핑이 일치하는지 대조

---

### 5. SEC-450 — 검색어를 삭제했는데 검색 결과가 초기 전체 목록으로 복원되지 않는 문제

* **SEC ID**: SEC-450
* **오류 유형**: Search State / empty-query-transition
* **재현 조건**: 도서 목록에서 특정 검색어(예: `React`)로 검색한 후 검색어를 모두 지우고(빈 문자열) 다시 검색할 때 발생
* **재현 절차**:
  1. `도서관` (`/books`) 페이지 진입
  2. 검색창에 `React` 입력 후 검색 (3건 표시)
  3. 검색창의 텍스트를 모두 지우고 빈 문자열 상태로 엔터 또는 검색 버튼 클릭
  4. 검색 결과 목록 확인
* **관찰되는 증상**: 검색어를 완전히 지웠음에도 불구하고 전체 도서 50권이 나타나지 않고 이전 검색어 `React`에 대한 3건만 계속 화면에 유지됨
* **정상 동작**: 검색어가 빈 문자열(`""`)일 경우 검색 필터가 해제되어 전체 도서 목록(50권)이 다시 표시되어야 함
* **오류 발생 원인**: 빈 문자열 전달 시 이전 쿼리 캐시를 초기화하지 않고 기존 필터링 결과를 그대로 반환/유지하도록 구현됨
* **PPO가 탐색해야 하는 행동**: 도서 검색 후 검색창을 비우고 재검색하여 전체 목록으로의 복원 여부를 확인
