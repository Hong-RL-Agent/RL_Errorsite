# Intentional Frontend GUI Bugs - site065

PPO 에이전트 탐지용 의도적 GUI 오류 명세입니다.

---

### 1. 예상 금액 불일치
- **Bug ID**: `site065-bug01`
- **CSV 오류명**: 예상 금액 불일치
- **Type**: `estimated-price-mismatch`
- **화면 위치**: 우측 '예약 요약' 패널의 예상 결제 금액
- **관련 파일**: `public/app.js` (updateSummary 함수)
- **Selector**: `[data-bug-id="site065-bug01"]`
- **사용자 경험 증상**: 사용자가 여러 세탁 품목을 선택하면 요약 리스트에는 모든 품목이 정상적으로 나타나지만, 하단의 '예상 결제 금액'에는 마지막으로 선택한 품목의 가격이 합산에서 제외되어 실제 합계보다 적은 금액이 표시됩니다.
- **의도된 원인**: `updateSummary` 함수에서 합계를 계산하는 반복문의 범위를 `selectedItems.length - 1`로 설정하여 마지막 항목을 누락시켰습니다.
- **기대 탐지 행동**: 화면에 렌더링된 품목들의 개별 가격 합계와 최종 표시된 예상 금액이 일치하는지 검증하여 수치 불일치를 탐지해야 합니다.

---

### 2. 예약 폼 레이아웃 깨짐
- **Bug ID**: `site065-bug02`
- **CSV 오류명**: 예약 폼 깨짐
- **Type**: `reservation-form-layout-break`
- **화면 위치**: 중앙 '수거 정보 입력' 폼 영역
- **관련 파일**: `public/styles.css` (@media 구간)
- **Selector**: `[data-bug-id="site065-bug02"]`
- **사용자 경험 증상**: 브라우저 가로 너비가 1024px에서 1200px 사이일 때, '수거 주소' 입력 칸과 '수거 희망 날짜 및 시간' 선택 칸이 서로 겹쳐서 나타나 텍스트를 읽거나 클릭하기 어렵습니다.
- **의도된 원인**: 특정 미디어 쿼리 구간에서 Grid의 컬럼 폭을 고의로 매우 좁게(`100px`) 설정하고 내부 요소의 `width`를 강제하여 오버랩을 유도했습니다.
- **기대 탐지 행동**: 시각적 렌더링 결과에서 서로 다른 입력 필드 요소들의 경계면(Bounding Box)이 겹치는지 탐지해야 합니다.

---

### 3. 예약 버튼 무반응
- **Bug ID**: `site065-bug03`
- **CSV 오류명**: 예약 버튼 무반응
- **Type**: `laundry-reserve-button-no-response`
- **화면 위치**: 우측 패널 하단 '수거 예약하기' 버튼
- **관련 파일**: `public/app.js` (initEventListeners 함수)
- **Selector**: `button[data-bug-id="site065-bug03"]`
- **사용자 경험 증상**: 품목 선택과 주소 입력을 모두 마친 후 '수거 예약하기' 버튼을 클릭해도 예약 완료 모달이 뜨지 않고 아무런 반응이 없습니다.
- **의도된 원인**: JavaScript에서 버튼을 선택할 때 사용한 ID(`reserve-button`)와 HTML의 실제 버튼 ID(`reserve-btn`)를 다르게 설정하여 이벤트 리스너가 연결되지 않았습니다.
- **기대 탐지 행동**: 활성화된 버튼에 대한 클릭 인터랙션 이후에 기대되는 DOM 변화(모달 노출)가 발생하는지 확인하여 결함을 탐지해야 합니다.
