## 📋 정상 기능 요약

- **학원 입학 상담 대장**: 30개 이상의 국어, 영어, 수학, 과학, 사회 입학/수능 상담 일시 조정 및 진행 관리.
- **학생 등록 및 목표 관리**: 25명 이상의 학생 프로필, 목푤 대학 및 수강 상태 관리.
- **강좌 등록 및 수강 신청**: 15개 이상의 마감임박 수능 파이널/내신 대비 강좌 수강 신청 및 수강료 집계.
- **일일 출결 체킹 및 대시보드**: 40개 이상의 출석/지각/결석 레코드 조치 및 상담사 세션 스위칭.

## ⚠️ 의도적으로 삽입된 복합 오류 목록

1. **Frontend + Backend 요청 순서 충돌**
   - **설명**: 상담 시간을 변경(3초 지연 완료)한 직후 상담 상태를 변경(0.1초 완료)하면, 상태 변경 API는 먼저 성공하지만 3초 뒤 완료되는 시간 변경 API 내부에 이전 상담 상태(`status`)가 동봉 저장되어 새로고침 시 새 시간과 이전 상태 조합이 저장됩니다.

2. **Backend + JSON DB 상태 충돌**
   - **설명**: 수강 취소(0.5초 완료) 직후 출결 체크 API를 호출(4초 지연 완료)하면, 수강 취소는 먼저 0.5초 만에 성공하지만 늦게 완료된 출결 체크 요청이 취소된 수강생을 다시 'ENROLLED'(수강중) 상태로 재활성화시킵니다. 수강 목록에서는 취소됨, 출결 화면에서는 수강중으로 불일치하게 됩니다.

3. **Frontend 정렬 인덱스 오류**
   - **설명**: 강좌 목록을 마감임박순으로 정렬한 뒤 수강 신청 버튼을 누르면 UI 알림은 클릭한 강좌명으로 표시되나 backend 저장 수강 신청 데이터는 원본 배열의 다른 index 강좌 id로 저장됩니다.

4. **통계 데이터 불일치**
   - **설명**: 상담 기록을 삭제(`DELETE /api/consultations/:id`) 처리하여 대장에서 소거하더라도, 학생별 상담 횟수(`consultationCount`)와 관리자 상담 전환율 통계 수치에는 차감되지 않고 계속 유지됩니다.

5. **Network stale response 오류**
   - **설명**: 과목 필터('MATH' 3초 지연 ➔ 'ENGLISH' 0.2초 완료)와 학년 필터를 빠르게 변경 시 오래된 응답이 최신 목록을 덮어써 중앙 강좌 목록은 오래된 필터 결과, 오른쪽 수강 요약은 최신 필터 기준 데이터로 서로 불일치합니다.

6. **Session + Cache 잔존 오류**
   - **설명**: 상담사 A가 본 학생 상담 기록을 열어둔 상태에서 상담사 B로 로그인하면 학생 목록은 B 권한 기준으로 바뀌지만, 오른쪽 상담 상세 및 상담 예정 건수 캐시(`cachedStudentDetail`, `cachedPendingConsultCount`)는 A 데이터가 남아 노출됩니다.

7. **Backend 권한 로그 오류**
   - **설명**: 권한 없는 강사/사용자가 학생 출결 수정 API(`PATCH /api/attendance/:id`)를 호출하면 HTTP 403을 반환하지만, 서버 내부 활동 로그에는 '출결 수정 성공 (ATTENDANCE UPDATE SUCCESS - 200 OK)'으로 잘못 기록됩니다.

## 🧪 테스트 시나리오

1. **Error 1 테스트**: 우측 패널에서 상담 일자 선택 후 `시간 변경` 클릭 직후 상담 상태 변경 ➔ 3초 후 새로고침 시 시간은 바뀌었으나 상담 상태는 이전 값으로 롤백됨을 확인.
2. **Error 2 테스트**: 우측 패널에서 `⚡ 수강 취소 후 출결 체크` 클릭 ➔ 0.5초 후 취소 응답 ➔ 4초 후 출결 체크 응답이 완료되며 수강 목록(취소됨)과 출결 체크 화면(수강중) 간 상태 불일치 확인.
3. **Error 3 테스트**: 좌측 사이드바에서 `마감임박순` 정렬 선택 ➔ 상단 강좌의 수강 신청 클릭 ➔ UI 알림과 실제 backend DB 저장 강좌 id가 상이함을 확인.
4. **Error 4 테스트**: 중앙 상담 타임라인 대장에서 `🗑️ 삭제` 클릭 ➔ 대장에서는 삭제되나 학생 상담 횟수 및 관리자 전환율 수치가 유지됨을 확인.
5. **Error 5 테스트**: 좌측 과목 필터를 `수학` 선택 직후 `영어` 선택 ➔ 3초 후 늦은 이전 결과가 최신 목록을 덮어씀을 확인.
6. **Error 6 테스트**: 상단 로그인 상담사를 `박상담 팀장`에서 `최수석 실장`으로 전환 ➔ 학생 목록은 B로 바뀌나 상단 KPI 학생 상담 상세는 A 데이터로 잔존함을 확인.
7. **Error 7 테스트**: 출결 대장에서 `🔒 무권한 수정` 클릭 ➔ UI/API는 HTTP 403 오류 반환 ➔ 백엔드 콘솔 로그에는 SUCCESS (200 OK)로 잘못 작성됨을 확인.
