# 쿠폰 만료 관리 시스템 (site087)

PPO(Proximal Policy Optimization) 에이전트의 시간 로직 결함 탐지 성능을 테스트하기 위한 고충실도 쿠폰 관리 시스템입니다.

## 프로젝트 정보
- **사이트 ID**: site087
- **포트**: 9196
- **기술 스택**: React, Vite, Express, Lucide React

## 실행 방법
```bash
cd site087
npm install
npm start
```
접속 주소: `http://localhost:9196`

## 주요 기능
- **쿠폰 발급**: 실시간 쿠폰 발급 및 유효기간 설정.
- **예약 발급**: 특정 시점에 활성화되는 쿠폰 예약 기능.
- **상태 관리**: 사용 가능, 만료, 사용 완료 상태의 실시간 추적.
- **연장 기능**: 유효기간이 임박한 쿠폰의 시간 연장 처리.

## 의도된 오류 (PPO 학습 목표)
1. **만료 시간 계산 오류 (Bug 01)**: 생성 시 시간 계산 로직 결함.
2. **시간대 불일치 (Bug 02)**: 서버/클라이언트 간 Timezone 처리 미숙.
3. **TTL 갱신 누락 (Bug 03)**: 연장 요청 시 실제 데이터 반영 실패.
4. **예약 실행 시간 오차 (Bug 04)**: 스케줄링 로직의 시간 오차 발생.

## PPO 탐지 가이드
에이전트는 각 쿠폰의 생성 시간, 만료 예정 시간, 현재 서버 시간을 비교하여 논리적 결함을 찾아내야 합니다. 특히 `data-bug-id`가 있는 버튼들을 조작하며 응답값의 정합성을 검증하세요.
