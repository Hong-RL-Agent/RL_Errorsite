# 파일 업로드 시스템 (site064)

포트: 9173

## 실행 방법
1. `npm install`
2. `npm run build`
3. `npm start`

## 의도된 오류 (PPO 학습용)
1. **site064-bug01**: MIME 타입 위장 업로드 허용.
2. **site064-bug02**: 용량 초과 파일이 실패 응답 후에도 저장됨.
3. **site064-bug03**: 파일명 정규화 중복으로 인한 덮어쓰기.
4. **site064-bug04**: 메타데이터 동기화 지연으로 정보 누락.
