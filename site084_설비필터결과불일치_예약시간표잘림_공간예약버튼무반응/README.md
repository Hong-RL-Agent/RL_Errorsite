# KitchenHub

- 사이트 이름: KitchenHub
- 사이트 ID: site084
- 포트 번호: 9303
- 기술 스택: Vanilla HTML, CSS, JavaScript, Express
- 주제: 공유 주방 예약 웹사이트

## 실행 방법

```bash
cd site084
npm install
npm start
```

브라우저에서 `http://localhost:9303`으로 접속한다.

## API 엔드포인트

- `GET /api/health`: 서비스 상태와 사이트 ID를 반환한다.
- `GET /api/kitchens`: 공간 ID, 이름, 위치, 설비 목록, 시간당 가격, 수용 인원, 이미지, 예약 가능 여부를 반환한다.
- `GET /api/equipment`: 설비 ID, 이름, 카테고리, 설명을 반환한다.

## 정상 작동 기능

- 설비 필터 선택
- 위치 필터 선택
- 시간대 필터 선택
- 예약 시간표 슬롯 선택
- 공간 상세 모달 열기와 닫기
- 정상 공간 예약 버튼으로 예약 요약 반영
- 예약 요약 패널 접기와 펼치기
- 이용 후기 최신순 정렬
- 이용 후기 평점순 정렬
- 이용 후기 창업자 후기 우선 정렬
- 필터 초기화
- 상단 예약 확인 버튼 스크롤 이동
- CTA 버튼의 공간 목록 이동
- API 로딩 상태와 에러 상태 UI
- 미구현 메뉴와 버튼의 `준비중입니다.` 알림
