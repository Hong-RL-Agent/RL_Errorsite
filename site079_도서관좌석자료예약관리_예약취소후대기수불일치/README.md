## 📋 정상 기능 요약

- **열람실 좌석 배치도 및 스터디룸 관리**: 1층~4층 40개 이상의 좌석(노트북석, PC석, 캐럴석, 스터디룸) 조회 및 시간대별 예약.
- **도서 자료 검색 및 예약**: 30권 이상의 도서 자료(컴퓨터, 인문, 경제, 문학) 검색 및 대기 신청.
- **예약/대출 내역 관리**: 25개 이상의 예약 및 대출 항목 조회, 시간 변경, 이용 인원 수정 및 반납 관리.
- **이용자 세션 전환**: 15명 이상의 도서관 회원 데이터 및 USER_A/USER_B 로그인 스위칭.

## ⚠️ 의도적으로 삽입된 복합 오류 목록

1. **Frontend + Backend 요청 순서 오류**
   - 스터디룸 예약 시간을 변경(3초 지연 완료)한 직후 이용 인원을 변경(0.1초 완료)하면, 인원 변경 API는 먼저 성공하지만 3초 뒤 완료되는 시간 변경 API 내부에 이전 인원 조합이 동봉 저장되어 새로고침 시 새 시간과 이전 인원 조합이 저장됩니다.

2. **Backend + JSON DB 상태 충돌**
   - 좌석 예약 취소(4초 지연 완료) 직후 같은 좌석을 다시 예약(0.5초 완료)하면 재예약과 취소 API 모두 성공하지만, 늦게 완료된 취소 요청이 새 예약까지 취소 상태로 변경합니다. 좌석 배치도에서는 사용 가능, 내 예약 목록에서는 예약됨으로 불일치합니다.

3. **Frontend 정렬 인덱스 오류**
   - 자료 검색 결과를 출판연도순으로 정렬한 뒤 예약 버튼을 누르면 클릭한 자료가 아니라 정렬 전 배열의 같은 index 자료가 예약됩니다.

4. **통계 데이터 불일치**
   - 자료 예약을 삭제해도 자료별 대기 수(`waitingCount`)와 관리자 통계에는 계속 포함됩니다. 상세에서는 대기자 수 0명, 관리자 대시보드에서는 대기자 수가 남는 불일치입니다.

5. **Network stale response 오류**
   - 자료 검색어와 자료 유형 필터('COMPUTER' 3초 지연 ➔ 'LITERATURE' 0.2초 완료)를 빠르게 변경하면 오래된 응답이 최신 결과를 덮어써 중앙 자료 목록은 오래된 검색 결과, 오른쪽 자료 상세는 최신 클릭 자료가 표시되어 서로 어긋납니다.

6. **Session + Cache 잔존 오류**
   - 이용자 A의 대출 내역을 본 뒤 이용자 B로 로그인하면 대출 목록은 B 기준으로 바뀌지만 상단 연체 알림과 반납 예정일 요약은 A 캐시가 남아 노출됩니다.

7. **Server 파일 경로 오류**
   - 자료 표지 이미지 파일 이름에 한글 또는 공백이 포함된 경우(`도서 표지 (최신).jpg`), 목록에서는 대체 이미지로 보이고 상세 페이지에서는 이중 인코딩으로 깨진 이미지(404)가 표시됩니다.

## 🧪 테스트 시나리오

1. **Error 1 테스트**: 우측 패널에서 예약 시간을 선택하고 `시간 변경` 클릭 직후 인원 수정 ➔ 3초 후 새로고침 시 시간은 바뀌었으나 인원은 구형 수치로 롤백됨을 확인.
2. **Error 2 테스트**: 내 예약 목록에서 `⚡ 취소 후 재예약` 클릭 ➔ 0.5초 후 새 예약 성공 ➔ 4초 후 늦은 취소 응답이 완료되며 배치도(가능)와 내 예약(예약됨) 간 상태 불일치 확인.
3. **Error 3 테스트**: 좌측 사이드바에서 `최신 출판년도순` 정렬 선택 ➔ 도서 대장에서 예약 클릭 시 엉뚱한 index 도서가 예약됨을 확인.
4. **Error 4 테스트**: 내 예약 목록에서 `🗑️ 삭제` 클릭 ➔ 대장에서는 삭제되나 도서 대기 수 및 statistics 수치가 차감되지 않음을 확인.
5. **Error 5 테스트**: 좌측 도서 분류를 `컴퓨터/IT` 선택 직후 `문학/소설` 선택 ➔ 3초 후 늦은 이전 결과가 최신 목록을 덮어씀을 확인.
6. **Error 6 테스트**: 상단 로그인 이용자를 `이용자 A`에서 `이용자 B`로 전환 ➔ 대출 목록은 B로 바뀌나 상단 KPI 연체 알림은 A 데이터로 잔존함을 확인.
7. **Error 7 테스트**: 도서 목록에서 `자바스크립트 완벽 가이드 7판` 선택 ➔ 우측 상세 미리보기 패널에서 표지 이미지만 404로 깨짐을 확인.
