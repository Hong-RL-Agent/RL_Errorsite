# PawCare Desk

- 사이트 이름: PawCare Desk
- 사이트 ID: site031
- 포트 번호: 9250
- 기술 스택: React + Vite + Express

## 실행 방법

```bash
cd site031
npm install
npm run build
npm start
```

브라우저에서 `http://localhost:9250`로 접속한다. PowerShell 실행 정책 문제가 있으면 `npm.cmd install`, `npm.cmd start`를 사용한다.

## API 엔드포인트

- `GET /api/health`: 서버 상태와 사이트 정보를 반환한다.
- `GET /api/providers`: 업체 ID, 업체명, 서비스 유형, 지역, 평점, 거리, 가격대, 가능한 시간, 이미지 데이터를 반환한다.
- `GET /api/pets`: 반려동물 이름, 종류, 나이, 특이사항 mock 데이터를 반환한다.
- `GET /api/reviews`: 업체별 후기, 평점, 작성일, 반려동물 종류 데이터를 반환한다.

## 정상 기능 목록

- 서비스 카테고리 필터가 업체 목록을 정상 갱신한다.
- 지역 검색어 입력 시 업체 목록이 정상 필터링된다.
- 반려동물 종류 필터가 정상 동작한다.
- 업체 카드 클릭 시 우측 예약 요약의 업체 정보가 갱신된다.
- 업체 상세 모달 열기/닫기가 정상 동작한다.
- 상세 모달 탭 버튼의 active 상태가 정상 변경된다.
- 후기 정렬 기능이 최신순/평점순으로 정상 동작한다.
- 예약 요약 패널 접기/펼치기가 정상 동작한다.
- API 로딩 상태와 에러 상태 UI가 존재한다.
- 구현되지 않은 버튼은 모두 `alert("준비중입니다.")`로 처리한다.

## 의도된 프론트엔드 오류 3개

1. `site031-bug01`
   - CSV 오류명: 예약 시간 중복 렌더링
   - 유형: `duplicate-time-slot-render`
   - `data-bug-id="site031-bug01"`
   - 상세 모달 시간 슬롯 grid에서 `14:30` 같은 시간이 중복 표시된다.

2. `site031-bug02`
   - CSV 오류명: 선택된 서비스와 예약 요약 불일치
   - 유형: `selected-service-summary-mismatch`
   - `data-bug-id="site031-bug02"`
   - 중앙 카드 선택 서비스는 바뀌지만 예약 요약의 서비스명은 초기 서비스에 머문다.

3. `site031-bug03`
   - CSV 오류명: 탭 메뉴 레이아웃 깨짐
   - 유형: `tab-menu-layout-break`
   - `data-bug-id="site031-bug03"`
   - 1024px~1280px 데스크톱 폭에서 상세 모달 탭 메뉴가 줄바꿈되지 않아 밀려 보인다.

## PPO 에이전트가 탐지해야 할 기대 행동

- `/api/providers`의 중복 없는 시간 배열과 상세 모달 시간 슬롯 UI를 비교해 중복 렌더링을 탐지한다.
- 서비스 필터/업체 선택 후 중앙 선택 서비스와 우측 예약 요약 서비스명이 일치하는지 확인한다.
- 데스크톱 중간 폭에서 모달 탭 메뉴가 모달 밖으로 밀리거나 겹치는지 관찰한다.

- `npm start`는 자동으로 `npm run build`를 먼저 실행한다.
