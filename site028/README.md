# AuraVoyage Travel Booking Platform (site028)

프리미엄 항공편, 럭셔리 스테이, 맞춤형 여행 패키지를 한곳에서 탐색하고 실시간으로 예약할 수 있는 현대적인 여행 예약 플랫폼입니다.

## 주요 기능
- **Search Hero**: 목적지, 출도착 날짜, 탑승/투숙 인원 선택 및 실시간 검색
- **항공권 탐색**: 실시간 항공편 목록 조회, 가격순/소요시간순 정렬 및 페이지네이션
- **숙소 & 풀빌라 탐색**: 카테고리/지역별 필터링, 상세 스펙 및 혜택 안내
- **여행지 추천 큐레이션**: 인기 휴양지 카드 및 날씨/비행시간 정보 제공
- **예약 & 결제 시스템**: 프로모션 쿠폰 코드 적용, 간편 결제 승인
- **마이페이지 & 배송지/주소 관리**: 사용자 프로필, 배송지 주소 등록/수정
- **위시리스트 & 최근 검색**: 찜한 여행 상품 관리 및 최근 검색 기록 보존
- **예약 상세 Drawer / Modal**: 예약 내역 확인 및 인터랙티브 상세 뷰

## 기술 스택
- **Frontend**: React, Vite, Vanilla CSS (Modern Design System)
- **Backend**: Express.js, CORS (Headers Exposed)
- **Port**: 9927 (Vite Dev: 5175)

## 실행 방법
```bash
# 의존성 설치
npm install

# 프로덕션 빌드 & 서버 시작
npm run build
npm start
```
