# Amore Wedding - 프리미엄 웨딩 플래닝 플랫폼 (site017)

Amore Wedding은 아이보리 화이트, 로즈 골드, 라이트 핑크, 베이지 색상을 바탕으로 고급스럽고 우아한 분위기를 지닌 프리미엄 웨딩 플래닝 예약 플랫폼입니다.

## 🚀 실행 방법

다음 명령어를 차례대로 입력하여 서비스를 구동할 수 있습니다.

```bash
cd site017
npm install
npm start
```

이후 브라우저에서 아래의 주소로 접속 가능합니다.
* **서비스 주소**: [http://localhost:9916](http://localhost:9916)

---

## 🎨 기술 스택
- **Front-end**: React, Vite, Vanilla CSS
- **Back-end**: Express, Node.js

---

## 💡 주요 기능
- **웨딩홀 맞춤 정렬 및 페이징**: 대관료 가격 정렬 필터 및 페이지 조회 제공
- **회원 통합 로그인 & 가입**: 예비 신부/신랑 전용 계정 로그인 및 가입 시스템
- **주소지 및 쿠폰 특전 관리**: 개인 수령 주소지 변경 및 프로모션 할인 쿠폰 등록
- **1:1 전담 플래너 상담**: 플래너 실시간 견적 대화 및 검색 기능
- **계약 증빙 파일 관리**: 예식 가계약 파일 설명 기재 및 목록 관리 포털
- **고객 생생 후기 리뷰**: 실제 아모르 제휴홀 이용자들의 실시간 리뷰 피드 작성
- **홀 투어 예약 일정 캘린더**: 실시간 상담 날짜 예약 및 일정 시뮬레이션
- **스튜디오/드레스/메이크업 컬렉션**: 로즈골드 신상 드레스 및 화보 샘플 정보 제공

---

## ⚠️ 안내 사항
- 본 플랫폼은 강화학습 환경을 지원하기 위한 모의 예식 예약 서비스입니다.
- 실제 계약금 결제, 캘린더 연동, 문자 인증 API 등은 동작하지 않으며, 메모리 상의 Mock 데이터 및 가상 인터페이스로 구성되어 있습니다.
