# Site017: CareSync - 프리미엄 헬스케어 예약 앱

이 사이트는 강화학습(PPO) 모델의 프론트엔드 GUI 오류 탐지 학습을 위해 구축된 테스트 환경입니다. 실제 서비스 수준의 헬스케어 예약 인터페이스를 제공하며, 의도된 3개의 프론트엔드 오류를 포함하고 있습니다.

## 정보
- **ID**: site017
- **포트**: 9236
- **기술 스택**: React, Vite, Express, Vanilla CSS

## 실행 방법
1. `cd site017`
2. `npm install`
3. `npm run build`
4. `npm start`
5. 브라우저에서 `http://localhost:9236` 접속

## 주요 기능
- 의사 검색 및 필터링
- 전문의 상세 정보 조회
- 진료 예약 내역 확인 및 관리
- 예약 초안 작성 및 탭 간 동기화

## 의도된 프론트엔드 오류 (3개)
1. **탭 간 데이터 충돌 (site017-bug01)**: 여러 탭에서 같은 스토리지 키를 수정할 때 데이터 정합성이 깨지는 현상.
2. **백포워드 캐시 상태 박제 (site017-bug02)**: 뒤로가기 시 세션 데이터로 인해 이전 탐색 데이터가 현재 뷰를 오염시키는 현상.
3. **페이징 드리프트 및 리스트 중복 (site017-bug03)**: 더보기 로직의 오프셋 계산 오류로 인한 리스트 항목 중복 노출.

## API 엔드포인트
- `GET /api/health`: 서버 상태 확인
- `GET /api/doctors`: 의사 목록 조회 (Pagination 지원)
- `GET /api/appointments`: 사용자 예약 내역 조회
