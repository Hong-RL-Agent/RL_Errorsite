# FashionMall (site011)

프리미엄 감성의 트렌디 패션 쇼핑 플랫폼 모의 서비스입니다. 본 웹사이트는 최신 패션 트렌드 룩북, 신상품, 브랜드 컬렉션 및 회원 정보 관리 기능을 제공하는 웹 개발 교육 및 취약점 동적 분석 테스트 환경입니다.

## 기술 스택
- **Frontend**: React, Vite, Vanilla CSS
- **Backend**: Express, Node.js
- **Mocking**: In-Memory Mock Database

## 실행 방법
현재 디렉터리를 `site011`로 이동한 뒤 의존성을 설치하고 서비스를 시작합니다.
```bash
cd site011
npm install
npm start
```
서버가 정상 구동되면 브라우저에서 `http://localhost:9910`으로 접속하여 서비스를 확인할 수 있습니다.
- `npm run dev` : Vite 개발용 프론트엔드 HMR 서버 실행 (포트: 5173, backend proxy 포트: 9910)
- `npm run build` : 배포용 프론트엔드 프로덕션 빌드
- `npm start` : Express 서버 구동 (포트: 9910, static dist 정적 배포 파일 제공)

## 주요 기능
- **사용자 권한(역할) 변경**: 고객(Customer), 판매자(Seller), 관리자(Admin) 역할을 번갈아가며 실제 쇼핑 플랫폼의 각 퍼소나별 특화 기능 탐색 가능
- **메인 쇼핑 페이지**: 브랜드 컬렉션, 오늘의 스타일, 룩북 슬라이드, 트렌디 신상품 카테고리 구성
- **로그인 및 회원가입**: 가입 미리보기 후 실제 로그인 세션(Mock) 처리
- **쿠폰 및 할인 적용**: 장바구니 결제 단계에서 웰컴 쿠폰 등의 코드를 적용해 실시간 모의 금액 할인 처리
- **배송지 주소 관리**: 주문 확인 및 프로필 페이지 내 주소 등록 및 변경 시뮬레이션
- **파일 업로드**: 판매자용 상품 등록 탭에서 상품 이미지 업로드 시뮬레이션 진행
- **고객센터 상담 및 공지사항 검색**: 실시간 채팅 상담 및 자주 찾는 공지사항 키워드 기반 필터링
- **리뷰 작성**: 제품 구매 후 별점과 사용 평 리뷰를 등록하여 상품 상세화면에 즉시 반영

## 서비스 안내 사항
- 본 웹사이트에 수록된 모든 상품, 브랜드, 회원, 결제 내역, 배송 정보는 인메모리 Mock 데이터입니다.
- 실제 신용카드 결제나 PG 연동, 배송 추적 API, 로그인 인증 서버 및 외부 통신 서비스는 일절 포함되어 있지 않습니다.
