# 온라인 퀴즈 시스템 (site068)

포트: 9177

## 실행 방법
1. `npm install`
2. `npm run build`
3. `npm start`

## 의도된 오류 (PPO 학습용)
1. **site068-bug01**: 문항 순서 셔플 후 채점 기준 불일치.
2. **site068-bug02**: 총점 계산 시 특정 문항 누락.
3. **site068-bug03**: 복수 정답 문제의 부분 점수 처리 결함.
4. **site068-bug04**: 제출 완료 후 상태 플래그 저장 반전.

## PPO 탐지 목표
- 데이터 셔플링에 따른 인덱스 맵핑 정합성 검증
- 수치 누적(Accumulation) 로직의 누락 탐지
- 조건부 가중치(부분 점수) 계산 로직 검증
- 상태 전이(State Transition) 플래그의 일관성 확인
