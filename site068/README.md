# Melody Institute - 음악 학원 레슨 예약 서비스 (site068)

당신만의 음악적 감각을 깨워줄 체계적인 1:1 맞춤 레슨 예약 플랫폼입니다. 클래식하고 현대적인 디자인과 함께, 강화학습(PPO) 에이전트의 GUI 오류 탐지 학습을 위한 3가지 의도적 결함이 포함되어 있습니다.

## 1. 프로젝트 정보
- **사이트 ID**: site068
- **포트 번호**: 9287
- **기술 스택**: Vanilla HTML, CSS, JavaScript, Node.js (Express)
- **디자인 테마**: 화이트, 딥 퍼플, 골드 기반의 품격 있는 교육 서비스 디자인

## 2. 실행 방법
```bash
cd site068
npm install
npm start
```
- 접속 주소: [http://localhost:9287](http://localhost:9287)

## 3. 주요 기능
- **악기별 레슨 필터링**: 피아노, 바이올린, 기타, 플루트 등 원하는 악기별 맞춤 레슨 검색
- **상담 신청 예약**: 관심 있는 레슨을 선택하여 상담 예약 리스트에 추가
- **강사진 상세 정보**: 강사의 경력, 전문 분야 및 학생 평점을 모달로 확인
- **수강료 정책 안내**: 아코디언 인터페이스를 통한 단계별 수강료 안내
- **실시간 요약 패널**: 선택한 레슨 정보를 우측 Sticky 패널에서 실시간 확인

## 4. 의도된 프론트엔드 GUI 오류 (3개)
상세 내용은 [BUGS.md](BUGS.md)를 참조하세요.

1. **강사 정보 undefined (site068-bug01)**: '플루트 입문 레슨' 카드에서 강사 데이터 매칭 실패로 인해 강사명이 `undefined`로 표시됨.
2. **네비게이션 레이아웃 깨짐 (site068-bug02)**: 특정 화면 너비(1100px~1280px)에서 상단 메뉴가 우측 '상담 신청' 버튼을 덮어버림.
3. **상담 신청 버튼 무반응 (site068-bug03)**: '바이올린 중급 레슨' 카드의 상담 신청 버튼 클릭 시 아무런 반응이 없음.

## 5. 프로젝트 구조
- `server.js`: 레슨 및 강사 데이터를 제공하는 Express 서버
- `public/index.html`: 메인 레슨 대시보드 레이아웃
- `public/styles.css`: 딥 퍼플 & 골드 테마 스타일 및 레이아웃 결함 구현
- `public/app.js`: 데이터 바인딩, 필터 로직 및 렌더링/이벤트 결함 구현
