# Intentional Frontend GUI Bugs - site068

PPO 에이전트 탐지용 의도적 GUI 오류 명세입니다.

---

### 1. 강사 정보 undefined
- **Bug ID**: `site068-bug01`
- **CSV 오류명**: 강사 정보 undefined
- **Type**: `undefined-teacher-info`
- **화면 위치**: '플루트 입문 레슨' 카드 하단의 강사 프로필 영역
- **관련 파일**: `public/app.js` (renderLessons 함수)
- **Selector**: `[data-bug-id="site068-bug01"]`
- **사용자 경험 증상**: 특정 레슨 카드(플루트)에서 강사의 이름이 표시되어야 할 자리에 `undefined`라는 텍스트가 노출되어 시스템의 미완성 느낌을 줍니다.
- **의도된 원인**: 서버에서 내려주는 특정 레슨의 `teacherId`는 문자열('4')이나, 강사 데이터의 ID는 숫자(4)입니다. `find` 함수에서 엄격 비교(`===`)를 사용하여 매칭에 실패하고, 결과가 `null`인 상황에서 fallback 없이 렌더링을 시도하여 발생합니다.
- **기대 탐지 행동**: 화면에 `undefined`라는 텍스트가 그대로 노출되는 렌더링 오류를 탐지해야 합니다.

---

### 2. 네비게이션 레이아웃 깨짐
- **Bug ID**: `site068-bug02`
- **CSV 오류명**: nav 깨짐
- **Type**: `desktop-nav-layout-break`
- **화면 위치**: 상단 네비게이션 바 (Header)
- **관련 파일**: `public/styles.css` (@media 구간)
- **Selector**: `[data-bug-id="site068-bug02"]`
- **사용자 경험 증상**: 브라우저 가로 너비가 1100px에서 1280px 사이일 때, 중앙의 메뉴 목록이 우측의 '상담 신청' 및 '로그인' 버튼 영역을 침범하여 겹쳐 보입니다. 이로 인해 메뉴를 클릭하기 어렵거나 시각적으로 불량해 보입니다.
- **의도된 원인**: 특정 구간에서 네비게이션 메뉴 영역에 `white-space: nowrap`과 부모보다 큰 `width`를 부여하여 레이아웃이 겹치도록 유도했습니다.
- **기대 탐지 행동**: 시각적으로 서로 다른 UI 요소들이 겹쳐서 렌더링되는 레이아웃 결함을 탐지해야 합니다.

---

### 3. 상담 신청 버튼 무반응
- **Bug ID**: `site068-bug03`
- **CSV 오류명**: 상담 신청 버튼 무반응
- **Type**: `consultation-button-no-response`
- **화면 위치**: '바이올린 중급 레슨' 카드 내의 '상담 신청하기' 버튼
- **관련 파일**: `public/app.js` (renderLessons 함수 내 버튼 로직)
- **Selector**: `button[data-bug-id="site068-bug03"]`
- **사용자 경험 증상**: 바이올린 레슨 카드의 '상담 신청하기' 버튼을 클릭해도 우측의 '상담 예약 요약' 패널에 아무런 변화가 없습니다. 다른 레슨들은 정상적으로 추가됩니다.
- **의도된 원인**: 특정 레슨 ID(`l2`)인 경우에만 의도적으로 클릭 이벤트 리스너를 바인딩하지 않도록 로직을 작성했습니다.
- **기대 탐지 행동**: 버튼 클릭 인터랙션 이후 예상되는 상태 변화(우측 패널 업데이트)가 발생하지 않음을 탐지해야 합니다.
