# 해솔문화도시 축제 안내 데스크

- 사이트 이름: 해솔문화도시 축제 안내 데스크
- 사이트 ID: site047
- 포트 번호: 9266
- 기술 스택: Vanilla HTML, CSS, JavaScript, Express

## 실행 방법

```bash
cd site047
npm install
npm start
```

브라우저에서 `http://localhost:9266`으로 접속합니다.

개발 실행도 동일하게 사용할 수 있습니다.

```bash
npm run dev
npm run build
```

## API 엔드포인트

- `GET /api/health`: 서버 상태 확인
- `GET /api/events`: 행사 ID, 행사명, 날짜, 시간, 장소, 카테고리, 이미지, 혼잡도 mock 데이터
- `GET /api/notices`: 공지 ID, 제목, 내용, 작성일 mock 데이터

## 정상 작동 기능

- `/api/events` 데이터를 `fetch`로 불러와 행사 카드 grid 렌더링
- `/api/notices` 데이터를 `fetch`로 불러와 공지사항 accordion 렌더링
- 날짜 필터 변경
- 카테고리 필터 변경
- 지역 필터 변경
- 빠른 검색 입력
- 필터 초기화
- 행사 상세 모달 열기
- 상세 모달 닫기 버튼, 배경 클릭, Escape 닫기
- 정상 행사 카드의 일정 저장 및 저장 해제
- 즐겨찾기 패널 열기와 닫기
- 저장 목록에서 개별 일정 제거
- 언어 선택 드롭다운 열기와 닫기
- 지도 mock 핀 선택
- 추천 코스 탭 전환
- 준비되지 않은 보조 버튼은 `준비중입니다.` alert 표시
- API 로딩 상태와 에러 상태 UI 표시
