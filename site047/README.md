# TripNest — Event & Experience Reservation Platform

TripNest는 전국의 다양한 로컬 체험, 원데이 클래스, 아웃도어 액티비티, 프라이빗 투어 및 문화 예술 이벤트를 검색하고 간편하게 예약할 수 있는 올인원 이벤트 & 체험 예약 플랫폼입니다.

---

## 🌟 주요 기능

1. **홈 및 큐레이션 (Home)**
   - 맞춤형 인기 체험 추천 및 카테고리별 테마 탐색
   - 지역별 인기 여행지 및 실시간 신규 오픈 클래스

2. **체험 탐색 및 상세 검색 (Explore)**
   - 키워드, 지역, 카테고리, 가격대, 별점 등 다차원 필터링
   - 실시간 정렬 (인기순, 평점순, 가격순, 리뷰순)

3. **체험 상세 및 실시간 예약 (Experience Detail & Booking)**
   - 호스트 정보, 운영 시간, 포함 사항, 위치 및 환불 정책
   - 날짜 및 회차(시간대) 선택, 참가 인원 설정
   - 할인 쿠폰 조회 및 즉시 적용 기능

4. **예약 내역 및 일정 관리 (My Reservations)**
   - 대기, 확정, 완료, 취소 상태별 예약 내역 관리
   - 예약 일정 변경 및 사전 취소 기능
   - 체험 완료 후 별점 및 포토 후기(리뷰) 작성

5. **호스트 대시보드 (Host Dashboard)**
   - 호스트 전용 신규 체험 등록 및 정보 수정
   - 수락된 예약자 목록 관리 및 리뷰/메시지 모니터링

6. **위시리스트, 메시지 & 실시간 알림 (Wishlist, Messages, Notifications)**
   - 관심 있는 체험 찜하기
   - 호스트와의 1:1 사전 문의 채팅
   - 예약 확정, 쿠폰 발급, 상태 변경 푸시 알림

## 🚀 실행 및 빌드 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 프로덕션 빌드 및 서버 실행
```bash
npm run build
npm start
```

### 3. 개발 모드 실행
```bash
npm run dev
```
