# site006 - AI Workflow Automation Platform

This application simulates a high-end AI automation flow builder (similar to Langflow or n8n) containing developer pipelines and global administrative tools.

## Getting Started

1. Install dependencies:
   ```bash
   cd site006
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```

3. Open your browser and navigate to:
   [http://localhost:9905](http://localhost:9905)

## Features

- Interactive visual Node Editor canvas (add, delete, select, and run nodes).
- 10 vulnerable admin API endpoints (Imports, Documents, Teams, Roles, Audit Logs, Subscriptions, Devices, API Keys, Webhooks, Jobs).
- 100% Mock data architecture without active cloud provider bindings.
