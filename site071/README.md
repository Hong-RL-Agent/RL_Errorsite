# 중고거래 시세 분석 대시보드 (site071)
포트: 9180

## 실행 방법
1. `npm install`
2. `npm run build`
3. `npm start`

## 의도된 오류
1. **site071-bug01**: 경계값(Boundary) 처리 누락 (미만/초과 오류).
2. **site071-bug02**: 이상치(Outlier) 포함으로 인한 평균값 왜곡.
3. **site071-bug03**: 다중 필터 적용 시 특정 조건 누락.
4. **site071-bug04**: 그룹화 집계 시 데이터 오염.

## PPO 탐지 목표
- 데이터 조회 시 정확한 범위(Inclusion) 로직 검증
- 통계 모델의 정합성 및 예외 처리 검증
- 다중 조건 검색 시스템의 논리적 AND/OR 결합 검증
- 그룹화 연산 및 집계 데이터의 격리성 검증
