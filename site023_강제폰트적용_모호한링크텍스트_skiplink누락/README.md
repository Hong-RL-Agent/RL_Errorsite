# CreatorGallery - 사진 작가 포트폴리오

## 정보
- 사이트 ID: site023
- 포트 번호: 9242
- 기술 스택: React, Vite, Express, Lucide-React

## 실행 방법
1. `cd site023`
2. `npm install`
3. `npm run build`
4. `npm start`
5. http://localhost:9242 접속

## API 엔드포인트
- `GET /api/health`: 서버 상태 확인
- `GET /api/photos`: 사진 갤러리 목록 (카테고리 필터 지원)
- `GET /api/projects`: 프로젝트 상세 리스트

## 정상 기능 목록
- 카테고리 필터링(Street, Nature, Portrait 등)
- 사진 상세 라이트박스 팝업
- 좋아요(Heart) 토글 기능
- 메뉴 클릭 시 해당 섹션 부드러운 스크롤 이동
- 테마 토글(다크/라이트) UI 스위칭
- 반응형 갤러리 레이아웃

## 의도된 프론트엔드 오류 3개
1. **[site023-bug01] 강제 폰트 적용**: 프로젝트 설명에 가독성 낮은 장식 폰트 강제 적용.
2. **[site023-bug02] 모호한 링크 텍스트**: 모든 상세 보기 링크가 동일한 텍스트("자세히 보기")로 표시.
3. **[site023-bug03] 건너뛰기 링크 누락**: 반복되는 상단 영역을 건너뛰는 Skip Link 부재.

## PPO 에이전트 기대 행동
에이전트는 텍스트의 가독성 결함과 의미론적 링크 텍스트 부재, 그리고 키보드 내비게이션의 편의성 결여를 정밀하게 탐지해야 합니다. 시각적 화려함 뒤에 숨겨진 접근성 장벽을 식별하는 것이 이번 학습의 핵심입니다.
